Upgrading from 13 to 1413에서 14로 업그레이드하기

Next.js 버전 14로 업데이트하려면 선호하는 package manager로 다음 command를 실행하세요:

To update to Next.js version 14, run the following command using your preferred package manager:

>_Terminal
npm i next@next-14 react@18 react-dom@18 && npm i eslint-config-next@next-14 -D
>_Terminal
yarn add next@next-14 react@18 react-dom@18 && yarn add eslint-config-next@next-14 -D
>_Terminal
pnpm i next@next-14 react@18 react-dom@18 && pnpm i eslint-config-next@next-14 -D
>_Terminal
bun add next@next-14 react@18 react-dom@18 && bun add eslint-config-next@next-14 -D
Good to know

TypeScript를 사용한다면 @types/react와 @types/react-dom도 최신 버전으로 upgrade하세요.

If you are using TypeScript, ensure you also upgrade @types/react and @types/react-dom to their latest versions.

v14 Summaryv14 요약

  • 16.x가 end-of-life에 도달했기 때문에 최소 Node.js 버전이 16.14에서 18.17로 올라갔습니다.
  • next export command가 제거되고 output: 'export' config로 대체되었습니다. 자세한 내용은 문서를 참고하세요.
  • ImageResponse의 next/server import가 next/og로 이름이 바뀌었습니다. import 이름을 안전하고 자동으로 바꿔 주는 codemod가 제공됩니다.
  • @next/font package가 완전히 제거되고 built-in next/font로 대체되었습니다. import 이름을 안전하고 자동으로 바꿔 주는 codemod가 제공됩니다.
  • next-swc의 WASM target이 제거되었습니다.
  • The minimum Node.js version has been bumped from 16.14 to 18.17, since 16.x has reached end-of-life.
  • The next export command has been removed in favor of output: 'export' config. Please see the docs for more information.
  • The next/server import for ImageResponse was renamed to next/og. A codemod is available to safely and automatically rename your imports.
  • The @next/font package has been fully removed in favor of the built-in next/font. A codemod is available to safely and automatically rename your imports.
  • The WASM target for next-swc has been removed.

Review migration checklistmigration checklist 검토하기

  • [ ] 앱이 Node.js 18.17 이상과 호환되는 React 18 dependency 및 type을 사용합니다.
  • [ ] static export가 next export 대신 output: 'export'와 next build를 사용합니다.
  • [ ] ImageResponse import가 next/server 대신 next/og를 사용합니다.
  • [ ] font import가 @next/font 대신 next/font를 사용합니다.
  • [ ] 앱이 제거된 next-swc WASM target에 의존하지 않습니다.
  • [ ] 앱이 지원하는 check와 영향을 받는 runtime 동작이 모두 통과합니다.
  • [ ] The app uses Node.js 18.17 or later and compatible React 18 dependencies and types.
  • [ ] Static exports use output: 'export' and next build instead of next export.
  • [ ] ImageResponse imports use next/og instead of next/server.
  • [ ] Font imports use next/font instead of @next/font.
  • [ ] The app does not rely on the removed next-swc WASM target.
  • [ ] The app's supported checks and affected runtime behavior pass.
