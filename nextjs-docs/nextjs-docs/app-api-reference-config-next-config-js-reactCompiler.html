reactCompilerreactCompiler

Next.js는 component rendering을 자동으로 최적화해 성능을 개선하도록 설계된 도구인 React Compiler를 지원합니다. 이를 통해 useMemo와 useCallback을 사용한 수동 memoization의 필요성이 줄어듭니다.

Next.js includes support for the React Compiler, a tool designed to improve performance by automatically optimizing component rendering. This reduces the need for manual memoization using useMemo and useCallback.

Next.js에는 React Compiler를 더 효율적으로 만드는, SWC로 작성된 custom 성능 최적화가 포함되어 있습니다. 모든 파일에 compiler를 실행하는 대신, Next.js는 프로젝트를 분석해 관련 있는 파일에만 React Compiler를 적용합니다. 이렇게 하면 불필요한 작업을 피할 수 있어, Babel plugin을 단독으로 사용할 때보다 build가 빨라집니다.

Next.js includes a custom performance optimization written in SWC that makes the React Compiler more efficient. Instead of running the compiler on every file, Next.js analyzes your project and only applies the React Compiler to relevant files. This avoids unnecessary work and leads to faster builds compared to using the Babel plugin on its own.

How It Works동작 방식

React Compiler는 Babel plugin을 통해 실행됩니다. build를 빠르게 유지하기 위해 Next.js는 JSX나 React Hook이 있는 파일처럼 관련 있는 파일에만 React Compiler를 적용하는 custom SWC 최적화를 사용합니다.

The React Compiler runs through a Babel plugin. To keep builds fast, Next.js uses a custom SWC optimization that only applies the React Compiler to relevant files—like those with JSX or React Hooks.

이렇게 하면 모든 것을 compile하지 않아도 되고 성능 비용이 최소로 유지됩니다. 기본 Rust 기반 compiler에 비해 build가 약간 느려질 수는 있지만, 그 영향은 작고 국소적입니다.

This avoids compiling everything and keeps the performance cost minimal. You may still see slightly slower builds compared to the default Rust-based compiler, but the impact is small and localized.

사용하려면 babel-plugin-react-compiler를 설치하세요:

To use it, install the babel-plugin-react-compiler:

pnpm add -D babel-plugin-react-compiler
npm install -D babel-plugin-react-compiler
yarn add -D babel-plugin-react-compiler
bun add -D babel-plugin-react-compiler

그런 다음 next.config.js에 reactCompiler option을 추가하세요:

Then, add reactCompiler option in next.config.js:

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  reactCompiler: true,
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  reactCompiler: true,
}

module.exports = nextConfig

Annotationsannotation

다음과 같이 compiler가 "opt-in" mode로 실행되도록 설정할 수 있습니다:

You can configure the compiler to run in "opt-in" mode as follows:

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  reactCompiler: {
    compilationMode: 'annotation',
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  reactCompiler: {
    compilationMode: 'annotation',
  },
}

module.exports = nextConfig

그런 다음 React의 "use memo" directive로 특정 component나 hook에 annotation을 달아 opt-in할 수 있습니다:

Then, you can annotate specific components or hooks with the "use memo" directive from React to opt-in:

TSJSapp/page.tsx
export default function Page() {
  'use memo'
  // ...
}
export default function Page() {
  'use memo'
  // ...
}
Note

반대로 React의 "use no memo" directive를 사용해 component나 hook을 opt-out할 수도 있습니다.

You can also use the "use no memo" directive from React for the opposite effect, to opt-out a component or hook.

Existing memoization guarantees기존 memoization 보장

compiler가 useMemo, useCallback, React.memo의 기존 memoization 보장을 유지할지 설정할 수 있습니다:

You can configure whether the compiler preserves existing memoization guarantees from useMemo, useCallback, and React.memo:

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  reactCompiler: {
    environment: {
      enablePreserveExistingMemoizationGuarantees: false,
    },
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  reactCompiler: {
    environment: {
      enablePreserveExistingMemoizationGuarantees: false,
    },
  },
}

module.exports = nextConfig

생략하면 Next.js는 활성화된 React Compiler 구현의 기본값을 사용합니다. 기본값은 compiler 구현과 버전마다 다를 수 있으므로, 일관된 동작을 보장하려면 이 option을 명시적으로 설정하세요.

When omitted, Next.js uses the default from the active React Compiler implementation. Because defaults may differ between compiler implementations and versions, set this option explicitly to ensure consistent behavior.
