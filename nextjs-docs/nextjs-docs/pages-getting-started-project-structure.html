Project Structure and Organization프로젝트 구조와 구성

이 페이지는 Next.js의 모든 폴더·파일 convention(관례)을 한눈에 정리하고, 프로젝트를 구성하는 방법에 대한 권장 사항을 소개합니다.

This page provides an overview of all the folder and file conventions in Next.js, and recommendations for organizing your project.

Folder and file conventions폴더와 파일 convention

Top-level folders최상위 폴더

최상위 폴더는 애플리케이션 코드와 static asset을 정리하는 데 사용합니다.

Top-level folders are used to organize your application's code and static assets.

appApp Router
pagesPages Router
public제공(serve)할 static asset
src선택 사항인 애플리케이션 source 폴더
appApp Router
pagesPages Router
publicStatic assets to be served
srcOptional application source folder

Top-level files최상위 파일

최상위 파일은 애플리케이션 설정, dependency 관리, proxy 실행, monitoring 도구 연동, environment variable 정의에 사용합니다.

Top-level files are used to configure your application, manage dependencies, run proxy, integrate monitoring tools, and define environment variables.
