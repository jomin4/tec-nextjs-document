NextRequestNextRequest

NextRequest는 Web Request API를 확장해 편리한 method를 추가로 제공합니다.

NextRequest extends the Web Request API with additional convenience methods.

cookies

request의 Set-Cookie header를 읽거나 변경합니다.

Read or mutate the Set-Cookie header of the request.

set(name, value)

이름이 주어지면, 주어진 값으로 request에 cookie를 설정합니다.

Given a name, set a cookie with the given value on the request.

// Given incoming request /home
// Set a cookie to hide the banner
// request will have a `Set-Cookie:show-banner=false;path=/home` header
request.cookies.set('show-banner', 'false')

get(name)

cookie 이름이 주어지면 해당 cookie의 값을 반환합니다. cookie를 찾지 못하면 undefined를 반환합니다. 여러 cookie가 발견되면 첫 번째 cookie를 반환합니다.

Given a cookie name, return the value of the cookie. If the cookie is not found, undefined is returned. If multiple cookies are found, the first one is returned.

// Given incoming request /home
// { name: 'show-banner', value: 'false', Path: '/home' }
request.cookies.get('show-banner')

getAll()

cookie 이름이 주어지면 해당 cookie의 값들을 반환합니다. 이름을 주지 않으면 request의 모든 cookie를 반환합니다.

Given a cookie name, return the values of the cookie. If no name is given, return all cookies on the request.

// Given incoming request /home
// [
//   { name: 'experiments', value: 'new-pricing-page', Path: '/home' },
//   { name: 'experiments', value: 'winter-launch', Path: '/home' },
// ]
request.cookies.getAll('experiments')
// Alternatively, get all cookies for the request
request.cookies.getAll()

delete(name)

cookie 이름이 주어지면 request에서 해당 cookie를 삭제합니다.

Given a cookie name, delete the cookie from the request.

// Returns true for deleted, false is nothing is deleted
request.cookies.delete('experiments')

has(name)

cookie 이름이 주어지면, request에 해당 cookie가 있을 경우 true를 반환합니다.

Given a cookie name, return true if the cookie exists on the request.

// Returns true if cookie exists, false if it does not
request.cookies.has('experiments')

clear()

request의 모든 cookie를 제거합니다.

Remove all cookies from the request.

request.cookies.clear()

nextUrl

native URL API를 확장해, Next.js 전용 property를 포함한 편리한 method를 추가로 제공합니다.

Extends the native URL API with additional convenience methods, including Next.js specific properties.

// Given a request to /home, pathname is /home
request.nextUrl.pathname
// Given a request to /home?name=lee, searchParams is { 'name': 'lee' }
request.nextUrl.searchParams

사용할 수 있는 option은 다음과 같습니다:

The following options are available:

PropertyTypeDescription
basePathstringURL의 base path입니다.
buildIdstring | undefinedNext.js 애플리케이션의 build identifier입니다. customize할 수 있습니다.
pathnamestringURL의 pathname입니다.
searchParamsObjectURL의 search parameter입니다.
PropertyTypeDescription
basePathstringThe base path of the URL.
buildIdstring | undefinedThe build identifier of the Next.js application. Can be customized.
pathnamestringThe pathname of the URL.
searchParamsObjectThe search parameters of the URL.
Note

Pages Router의 internationalization property는 App Router에서 사용할 수 없습니다. App Router에서의 internationalization에 대해 더 알아보세요.

The internationalization properties from the Pages Router are not available for usage in the App Router. Learn more about internationalization with the App Router.
