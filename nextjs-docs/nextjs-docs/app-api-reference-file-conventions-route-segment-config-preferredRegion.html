preferredRegion (deprecated)preferredRegion (deprecated)

Deprecated

preferredRegion route segment config는 deprecated되었습니다. route 파일에서 preferredRegion export를 제거하세요. 자세한 내용은 deprecation message를 참고하세요.

The preferredRegion route segment config is deprecated. Remove the preferredRegion export from your route files. See the deprecation message for details.

preferredRegion option을 사용하면 route segment의 선호 deployment region을 지정할 수 있습니다. 이 값은 deployment platform에 전달됩니다.

The preferredRegion option allows you to specify the preferred deployment region for a route segment. This value is passed to your deployment platform.

TSJSlayout.tsx | page.tsx | route.ts
export const preferredRegion = // string || string[]
export const preferredRegion = // string || string[]
  • string: route를 특정 region에 deploy합니다. 사용할 수 있는 region code는 platform마다 다릅니다. 예: 'iad1'.
  • string[]: route를 여러 특정 region에 deploy합니다. 목록에서 하나를 고르는 것이 아니라 나열된 모든 region에 deploy됩니다. 예: ['iad1', 'sfo1'].
  • string: Deploy the route to a specific region. Available region codes are platform-specific. For example, 'iad1'.
  • string[]: Deploy the route to multiple specific regions. The route is deployed to all listed regions, not a single one chosen from the list. For example, ['iad1', 'sfo1'].
Good to know
  • preferredRegion을 지정하지 않으면 가장 가까운 parent layout의 option을 상속합니다. root layout의 default는 'auto'입니다.
  • child segment의 값은 parent의 값을 덮어쓰며, 값이 merge되지 않습니다.
  • Next.js는 region 값을 deployment platform에 그대로 전달합니다. 정확한 동작과 사용할 수 있는 region code는 platform마다 다릅니다. 지원되는 값은 deployment platform의 문서를 참고하세요.
  • If a preferredRegion is not specified, it will inherit the option of the nearest parent layout. The root layout defaults to 'auto'.
  • A child segment's value overrides the parent, values are not merged.
  • Next.js passes the region values through to the deployment platform. The exact behavior and available region codes are platform-specific. Refer to your deployment platform's documentation for supported values.

Vercel

Vercel에 Next.js를 deploy하는 경우, 예전에는 region이 export const runtime = 'edge'에서만 지원되었는데 이는 이제 deprecated되었습니다. 다음 option을 전달할 수 있습니다:

If deploying Next.js on Vercel, regions were previously only supported with export const runtime = 'edge', which is now deprecated. The following options can be passed:

  • 'auto' (default): default region을 사용합니다.
  • 'global': 가능한 모든 region에 route를 deploy하는 것을 선호합니다.
  • 'home': home region에 route를 deploy하는 것을 선호합니다.
  • 'auto' (default): Uses the default region.
  • 'global': Prefer deploying the route to all availableregions.
  • 'home': Prefer deploying the route to the home region.

지원되지 않는 값을 전달하면 error가 발생합니다.

If an unsupported value is passed, an error will be thrown.
