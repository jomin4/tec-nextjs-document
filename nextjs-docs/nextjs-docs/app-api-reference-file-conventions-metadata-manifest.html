manifest.jsonmanifest.json

app directory의 root에 Web Manifest Specification에 맞는 manifest.(json|webmanifest) 파일을 추가하거나 생성해서, 브라우저에 웹 애플리케이션 정보를 제공하세요.

Add or generate a manifest.(json|webmanifest) file that matches the Web Manifest Specification in the root of app directory to provide information about your web application for the browser.

Static Manifest fileStatic Manifest 파일

app/manifest.json | app/manifest.webmanifest
{
  "name": "My Next.js Application",
  "short_name": "Next.js App",
  "description": "An application built with Next.js",
  "start_url": "/"
  // ...
}

Generate a Manifest fileManifest 파일 생성하기

Manifest 객체를 반환하는 manifest.js 또는 manifest.ts 파일을 추가하세요.

Add a manifest.js or manifest.ts file that returns a Manifest object.

Good to know: manifest.js는 특수한 Route Handler로, Request-time API나 dynamic config option을 사용하지 않는 한 기본적으로 cache됩니다.

Good to know: manifest.js is a special Route Handlers that is cached by default unless it uses a Request-time API or dynamic config option.

TSJSapp/manifest.ts
import type { MetadataRoute } from 'next'

export default function manifest(): MetadataRoute.Manifest {
  return {
    name: 'Next.js App',
    short_name: 'Next.js App',
    description: 'Next.js App',
    start_url: '/',
    display: 'standalone',
    background_color: '#fff',
    theme_color: '#fff',
    icons: [
      {
        src: '/favicon.ico',
        sizes: 'any',
        type: 'image/x-icon',
      },
    ],
  }
}
export default function manifest() {
  return {
    name: 'Next.js App',
    short_name: 'Next.js App',
    description: 'Next.js App',
    start_url: '/',
    display: 'standalone',
    background_color: '#fff',
    theme_color: '#fff',
    icons: [
      {
        src: '/favicon.ico',
        sizes: 'any',
        type: 'image/x-icon',
      },
    ],
  }
}

Manifest ObjectManifest 객체

manifest 객체에는 새로운 웹 표준에 따라 업데이트될 수 있는 방대한 option 목록이 들어 있습니다. 현재 사용할 수 있는 모든 option에 대한 정보는, TypeScript를 사용한다면 code editor에서 MetadataRoute.Manifest type을 참고하거나 MDN 문서를 참고하세요.

The manifest object contains an extensive list of options that may be updated due to new web standards. For information on all the current options, refer to the MetadataRoute.Manifest type in your code editor if using TypeScript or see the MDN docs.
