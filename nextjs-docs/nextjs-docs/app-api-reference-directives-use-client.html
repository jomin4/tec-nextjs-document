use clientuse client

'use client' directive는 client side에서 render될 component의 entry point를 선언합니다. state 관리, event 처리, browser API 접근처럼 client-side JavaScript 기능이 필요한 interactive user interface(UI)를 만들 때 사용해야 합니다. 이것은 React 기능입니다.

The 'use client' directive declares an entry point for the components to be rendered on the client side and should be used when creating interactive user interfaces (UI) that require client-side JavaScript capabilities, such as state management, event handling, and access to browser APIs. This is a React feature.

Good to know

Client Component를 포함하는 모든 파일에 'use client' directive를 추가할 필요는 없습니다. Server Component 안에서 직접 render하려는 component가 있는 파일에만 추가하면 됩니다. 'use client' directive는 server와 client boundary를 정의하며, 그런 파일에서 export된 component가 client로 들어가는 entry point 역할을 합니다.

You do not need to add the 'use client' directive to every file that contains Client Components. You only need to add it to the files whose components you want to render directly within Server Components. The 'use client' directive defines the server and client boundary, and the components exported from such a file serve as entry points to the client.

Usage사용법

Client Component의 entry point를 선언하려면 파일 맨 위, 즉 모든 import보다 앞에 'use client' directive를 추가하세요. 이 directive는 module 전체에 적용되며 component나 function 안에 둘 수 없습니다:

To declare an entry point for the Client Components, add the 'use client' directive at the top of the file, before any imports. The directive applies to the entire module and cannot be placed inside a component or function:

TSJSapp/components/counter.tsx
'use client'

import { useState } from 'react'

export default function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  )
}
'use client'

import { useState } from 'react'

export default function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  )
}

'use client' directive를 사용할 때 Client Component의 props는 serializable해야 합니다. 즉, server에서 client로 데이터를 보낼 때 React가 serialize할 수 있는 형식이어야 합니다.

When using the 'use client' directive, the props of the Client Components must be serializable. This means the props need to be in a format that React can serialize when sending data from the server to the client.

TSJSapp/components/counter.tsx
'use client'

export default function Counter({
  onClick /* ❌ Function is not serializable */,
}) {
  return (
    <div>
      <button onClick={onClick}>Increment</button>
    </div>
  )
}
'use client'

export default function Counter({
  onClick /* ❌ Function is not serializable */,
}) {
  return (
    <div>
      <button onClick={onClick}>Increment</button>
    </div>
  )
}

Nesting Client Components within Server ComponentsServer Component 안에 Client Component 중첩하기

Server Component와 Client Component를 함께 사용하면 성능이 좋으면서도 interactive한 애플리케이션을 만들 수 있습니다:

Combining Server and Client Components allows you to build applications that are both performant and interactive:

  1. Server Components: static 콘텐츠, data fetching, SEO 친화적인 요소에 사용하세요.
  2. Client Components: state, effect, browser API가 필요한 interactive 요소에 사용하세요.
  3. Component composition: server 로직과 client 로직을 명확히 분리하기 위해 필요에 따라 Client Component를 Server Component 안에 중첩하세요.
  1. Server Components: Use for static content, data fetching, and SEO-friendly elements.
  2. Client Components: Use for interactive elements that require state, effects, or browser APIs.
  3. Component composition: Nest Client Components within Server Components as needed for a clear separation of server and client logic.

다음 예시에서:

In the following example:

  • Header는 static 콘텐츠를 다루는 Server Component입니다.
  • Counter는 page 안에서 interactivity를 가능하게 하는 Client Component입니다.
  • Header is a Server Component handling static content.
  • Counter is a Client Component enabling interactivity within the page.
TSJSapp/page.tsx
import Header from './header'
import Counter from './counter' // This is a Client Component

export default function Page() {
  return (
    <div>
      <Header />
      <Counter />
    </div>
  )
}
import Header from './header'
import Counter from './counter' // This is a Client Component

export default function Page() {
  return (
    <div>
      <Header />
      <Counter />
    </div>
  )
}
