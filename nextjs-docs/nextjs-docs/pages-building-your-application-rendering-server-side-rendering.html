Server-side Rendering (SSR)Server-side Rendering (SSR)

"SSR" 또는 "Dynamic Rendering"이라고도 합니다.

Also referred to as "SSR" or "Dynamic Rendering".

page가 Server-side Rendering을 사용하면, page HTML은 각 request마다 생성됩니다.

If a page uses Server-side Rendering, the page HTML is generated on each request.

page에 Server-side Rendering을 사용하려면 getServerSideProps라는 async 함수를 export해야 합니다. 이 함수는 모든 request마다 server에서 호출됩니다.

To use Server-side Rendering for a page, you need to export an async function called getServerSideProps. This function will be called by the server on every request.

예를 들어 page가 (외부 API에서 fetch한) 자주 업데이트되는 data를 prerender해야 한다고 가정해 봅시다. 아래처럼 이 data를 fetch해서 Page에 전달하는 getServerSideProps를 작성할 수 있습니다:

For example, suppose that your page needs to prerender frequently updated data (fetched from an external API). You can write getServerSideProps which fetches this data and passes it to Page like below:

export default function Page({ data }) {
  // Render data...
}

// This gets called on every request
export async function getServerSideProps() {
  // Fetch data from external API
  const res = await fetch(`https://.../data`)
  const data = await res.json()

  // Pass data to the page via props
  return { props: { data } }
}

보다시피 getServerSideProps는 getStaticProps와 비슷하지만, getServerSideProps는 build 시점이 아니라 모든 request마다 실행된다는 차이가 있습니다.

As you can see, getServerSideProps is similar to getStaticProps, but the difference is that getServerSideProps is run on every request instead of on build time.

getServerSideProps의 동작 방식을 더 알아보려면 Data Fetching 문서를 확인하세요.

To learn more about how getServerSideProps works, check out our Data Fetching documentation.
