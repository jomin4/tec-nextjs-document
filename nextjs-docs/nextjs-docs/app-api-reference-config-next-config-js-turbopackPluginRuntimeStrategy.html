turbopackPluginRuntimeStrategyexperimentalturbopackPluginRuntimeStrategy

experimental.turbopackPluginRuntimeStrategy option은 Turbopack이 Node.js evaluation을 child process에서 실행할지 worker thread에서 실행할지 선택합니다.

The experimental.turbopackPluginRuntimeStrategy option chooses whether Turbopack runs Node.js evaluation in child processes or worker threads.

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    turbopackPluginRuntimeStrategy: 'workerThreads',
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    turbopackPluginRuntimeStrategy: 'workerThreads',
  },
}

module.exports = nextConfig

이 runtime은 webpack loader, Babel, PostCSS 등 Node.js 기반 도구를 실행합니다.

This runtime executes Node.js-based tools, including webpack loaders, Babel, and PostCSS.

Reference레퍼런스

ValueDefaultDescription
'childProcesses'Yeschild process pool에서 Node.js evaluation을 실행하고 socket으로 통신합니다.
'workerThreads'NoNext.js process 안의 worker thread에서 Node.js evaluation을 실행합니다. child process pool에 비해 메모리와 CPU overhead를 줄일 수 있습니다.
'forceWorkerThreads'No현재 Node.js 버전이 아래에서 설명하는 worker-thread teardown 문제의 영향을 받더라도 worker thread를 사용합니다. process가 abort될 수 있습니다.
ValueDefaultDescription
'childProcesses'YesRuns Node.js evaluation in a pool of child processes and communicates with them over sockets.
'workerThreads'NoRuns Node.js evaluation in worker threads within the Next.js process. This can reduce memory and CPU overhead compared with a child process pool.
'forceWorkerThreads'NoUses worker threads even when the current Node.js version is affected by the worker-thread teardown issue described below. This can abort the process.

Node.js compatibilityNode.js 호환성

Node.js 24.13.1 이상에서는, native addon이 살아 있는 Node-API thread-safe function을 가진 상태에서 worker가 종료되면 Node.js worker-thread teardown 문제로 인해 process가 abort될 수 있습니다.

On Node.js 24.13.1 and newer, a Node.js worker-thread teardown issue can abort the process when a worker exits while a native addon has a live Node-API thread-safe function.

영향을 받는 Node.js 버전에서 turbopackPluginRuntimeStrategy를 'workerThreads'로 설정하면, Next.js는 warning을 출력하고 'childProcesses'로 fallback합니다. process가 abort될 위험을 감수하고 fallback을 우회하려면 'forceWorkerThreads'로 설정하세요.

When turbopackPluginRuntimeStrategy is set to 'workerThreads' on an affected Node.js version, Next.js prints a warning and falls back to 'childProcesses'. Set 'forceWorkerThreads' to bypass the fallback at the risk of aborting the process.
