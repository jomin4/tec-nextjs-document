How to use CSS-in-JS librariesCSS-in-JS library 사용하기

예시
  • Styled JSX
  • Styled Components
  • Emotion
  • Linaria
  • Cxs
  • Fela
  • Stitches

기존의 어떤 CSS-in-JS 솔루션이든 사용할 수 있습니다. 가장 간단한 것은 inline style입니다:

It's possible to use any existing CSS-in-JS solution. The simplest one is inline styles:

function HiThere() {
  return <p style={{ color: 'red' }}>hi there</p>
}

export default HiThere

격리된 scoped CSS를 지원하기 위해 styled-jsx를 함께 bundle합니다. 목표는 Web Components와 비슷한 "shadow CSS"를 지원하는 것인데, 안타깝게도 Web Components는 server-rendering을 지원하지 않고 JS 전용입니다.

We bundle styled-jsx to provide support for isolated scoped CSS. The aim is to support "shadow CSS" similar to Web Components, which unfortunately do not support server-rendering and are JS-only.

다른 인기 있는 CSS-in-JS 솔루션(Styled Components 등)은 위의 예시를 참고하세요.

See the above examples for other popular CSS-in-JS solutions (like Styled Components).

styled-jsx를 사용하는 component는 다음과 같습니다:

A component using styled-jsx looks like this:

function HelloWorld() {
  return (
    <div>
      Hello world
      <p>scoped!</p>
      <style jsx>{`
        p {
          color: blue;
        }
        div {
          background: red;
        }
        @media (max-width: 600px) {
          div {
            background: blue;
          }
        }
      `}</style>
      <style global jsx>{`
        body {
          background: black;
        }
      `}</style>
    </div>
  )
}

export default HelloWorld

더 많은 예시는 styled-jsx 문서를 참고하세요.

Please see the styled-jsx documentation for more examples.

Disabling JavaScriptJavaScript 비활성화하기

네, JavaScript를 비활성화해도 production build(next start)에서는 CSS가 여전히 로드됩니다. development 중에는 Fast Refresh로 최상의 개발자 경험을 제공하기 위해 JavaScript가 활성화되어 있어야 합니다.

Yes, if you disable JavaScript the CSS will still be loaded in the production build (next start). During development, we require JavaScript to be enabled to provide the best developer experience with Fast Refresh.
