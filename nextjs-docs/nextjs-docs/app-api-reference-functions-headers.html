headersheaders

headers는 Server Component에서 들어오는 HTTP request header를 읽을 수 있게 해 주는 async 함수입니다.

headers is an async function that allows you to read the HTTP incoming request headers from a Server Component.

TSJSapp/page.tsx
import { headers } from 'next/headers'

export default async function Page() {
  const headersList = await headers()
  const userAgent = headersList.get('user-agent')
}
import { headers } from 'next/headers'

export default async function Page() {
  const headersList = await headers()
  const userAgent = headersList.get('user-agent')
}

Reference

Parameters

headers는 parameter를 받지 않습니다.

headers does not take any parameters.

Returns

headers는 read-only Web Headers object를 반환합니다.

headers returns a read-only Web Headers object.

  • Headers.entries(): 이 object에 담긴 모든 key/value 쌍을 순회할 수 있는 iterator를 반환합니다.
  • Headers.forEach(): 이 Headers object의 각 key/value 쌍마다 주어진 함수를 한 번씩 실행합니다.
  • Headers.get(): Headers object 안에서 주어진 이름을 가진 header의 모든 값을 String 형태로 반환합니다.
  • Headers.has(): Headers object에 특정 header가 포함되어 있는지 나타내는 boolean을 반환합니다.
  • Headers.keys(): 이 object에 담긴 key/value 쌍의 모든 key를 순회할 수 있는 iterator를 반환합니다.
  • Headers.values(): 이 object에 담긴 key/value 쌍의 모든 value를 순회할 수 있는 iterator를 반환합니다.
  • Headers.entries(): Returns an iterator allowing to go through all key/value pairs contained in this object.
  • Headers.forEach(): Executes a provided function once for each key/value pair in this Headers object.
  • Headers.get(): Returns a String sequence of all the values of a header within a Headers object with a given name.
  • Headers.has(): Returns a boolean stating whether a Headers object contains a certain header.
  • Headers.keys(): Returns an iterator allowing you to go through all keys of the key/value pairs contained in this object.
  • Headers.values(): Returns an iterator allowing you to go through all values of the key/value pairs contained in this object.

Good to know

  • headers는 promise를 반환하는 asynchronous 함수입니다. async/await나 React의 use 함수를 사용해야 합니다.
    • 버전 14 이하에서 headers는 synchronous 함수였습니다. 하위 호환성을 위해 Next.js 15에서도 여전히 synchronous하게 접근할 수 있지만, 이 동작은 앞으로 deprecated될 예정입니다.
  • headers는 read-only이므로 나가는 request header를 set하거나 delete할 수 없습니다.
  • headers는 반환값을 미리 알 수 없는 Request-time API입니다. 이를 사용하면 해당 route는 dynamic rendering 방식으로 전환됩니다.
  • Cache Components를 사용할 때 <Suspense> boundary 바깥에서 headers()를 호출하면 route가 prerender되지 않습니다. 해결 방법은 Next.js encountered runtime data during prerendering을 참고하세요.
  • headers is an asynchronous function that returns a promise. You must use async/await or React's use function.
    • In version 14 and earlier, headers was a synchronous function. To help with backwards compatibility, you can still access it synchronously in Next.js 15, but this behavior will be deprecated in the future.
  • Since headers is read-only, you cannot set or delete the outgoing request headers.
  • headers is a Request-time API whose returned values cannot be known ahead of time. Using it in will opt a route into dynamic rendering.
  • With Cache Components, calling headers() outside of a <Suspense> boundary prevents the route from being prerendered. See Next.js encountered runtime data during prerendering for fix options.

Examples예제

Using the Authorization headerAuthorization header 사용하기

JSapp/page.js
import { headers } from 'next/headers'

export default async function Page() {
  const authorization = (await headers()).get('authorization')
  const res = await fetch('...', {
    headers: { authorization }, // Forward the authorization header
  })
  const user = await res.json()

  return <h1>{user.name}</h1>
}
