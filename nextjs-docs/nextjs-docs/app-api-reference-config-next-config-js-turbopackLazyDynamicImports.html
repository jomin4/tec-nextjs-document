turbopackLazyDynamicImportsexperimentalturbopackLazyDynamicImports

experimental.turbopackLazyDynamicImports option은 next dev 중에 client-side dynamic import() target의 compile을 브라우저가 처음 요청할 때까지 미룹니다.

The experimental.turbopackLazyDynamicImports option defers compiling client-side dynamic import() targets until the browser first requests them during next dev.

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    turbopackLazyDynamicImports: true,
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    turbopackLazyDynamicImports: true,
  },
}

module.exports = nextConfig

How it works동작 방식

turbopackLazyDynamicImports를 활성화하면 Turbopack은 브라우저가 해당 chunk를 요청할 때까지 client-side dynamic import() target의 compile을 기다립니다. 애플리케이션이 한 번도 import하지 않는 코드는 development session 동안 compile되지 않은 상태로 남습니다.

With turbopackLazyDynamicImports enabled, Turbopack waits to compile the target of a client-side dynamic import() until the browser requests its chunk. Code that the application never imports remains uncompiled during the development session.

예를 들어 이 Client Component의 module은 방문자가 버튼을 선택할 때 compile됩니다:

For example, the module in this Client Component is compiled when the visitor selects the button:

TSJSapp/greeting-button.tsx
'use client'

import { useState } from 'react'

export function GreetingButton() {
  const [message, setMessage] = useState('')

  async function showGreeting() {
    const { getGreeting } = await import('./get-greeting')
    setMessage(getGreeting('Ada'))
  }

  return (
    <>
      <button onClick={showGreeting}>Show greeting</button>
      <p>{message}</p>
    </>
  )
}
'use client'

import { useState } from 'react'

export function GreetingButton() {
  const [message, setMessage] = useState('')

  async function showGreeting() {
    const { getGreeting } = await import('./get-greeting')
    setMessage(getGreeting('Ada'))
  }

  return (
    <>
      <button onClick={showGreeting}>Show greeting</button>
      <p>{message}</p>
    </>
  )
}
Good to know
  • 이 option의 기본값은 false이며 next dev 중의 Turbopack에만 영향을 줍니다. production build는 바뀌지 않습니다.
  • 지연된 module의 error는 Turbopack이 그 module을 처음 compile할 때 나타납니다.
  • 일부 next/dynamic target은 여전히 즉시(eagerly) compile됩니다.
  • server에서 Client Component를 rendering하는 중에 도달하는 dynamic import를 지연하려면 turbopackLazyDynamicImportsSSR을 사용하세요.
  • The option defaults to false and only affects Turbopack during next dev. It does not change production builds.
  • Errors in a deferred module appear when Turbopack first compiles that module.
  • Some next/dynamic targets are still compiled eagerly.
  • To defer dynamic imports reached while rendering Client Components on the server, use turbopackLazyDynamicImportsSSR.
