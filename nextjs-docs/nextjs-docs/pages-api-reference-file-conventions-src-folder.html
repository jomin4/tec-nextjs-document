src Directorysrc 폴더

프로젝트 루트에 Next.js의 special app 또는 pages 디렉터리를 두는 대신, Next.js는 애플리케이션 코드를 src 폴더 아래에 두는 일반적인 패턴도 지원합니다.

As an alternative to having the special Next.js app or pages directories in the root of your project, Next.js also supports the common pattern of placing application code under the src folder.

이렇게 하면 주로 프로젝트 루트에 있는 프로젝트 설정 파일과 애플리케이션 코드가 분리되며, 일부 개인과 팀은 이 방식을 선호합니다.

This separates application code from project configuration files which mostly live in the root of a project, which is preferred by some individuals and teams.

src 폴더를 사용하려면 app Router 폴더 또는 pages Router 폴더를 각각 src/app 또는 src/pages로 옮기세요.

To use the src folder, move the app Router folder or pages Router folder to src/app or src/pages respectively.

Good to know
  • /public 디렉터리는 프로젝트 루트에 그대로 두어야 합니다.
  • package.json, next.config.js, tsconfig.json 같은 config 파일은 프로젝트 루트에 그대로 두어야 합니다.
  • .env.* 파일은 프로젝트 루트에 그대로 두어야 합니다.
  • 루트 디렉터리에 app 또는 pages가 있으면 src/app 또는 src/pages는 무시됩니다.
  • src를 사용한다면 /components나 /lib 같은 다른 애플리케이션 폴더도 함께 옮기게 될 것입니다.
  • Proxy를 사용한다면 src 폴더 안에 두어야 합니다.
  • Tailwind CSS를 사용한다면 tailwind.config.js 파일의 content section에 /src prefix를 추가해야 합니다.
  • @/* 같은 import용 TypeScript paths를 사용한다면 tsconfig.json의 paths 객체에 src/가 포함되도록 수정해야 합니다.
  • The /public directory should remain in the root of your project.
  • Config files like package.json, next.config.js and tsconfig.json should remain in the root of your project.
  • .env.* files should remain in the root of your project.
  • src/app or src/pages will be ignored if app or pages are present in the root directory.
  • If you're using src, you'll probably also move other application folders such as /components or /lib.
  • If you're using Proxy, ensure it is placed inside the src folder.
  • If you're using Tailwind CSS, you'll need to add the /src prefix to the tailwind.config.js file in the content section.
  • If you are using TypeScript paths for imports such as @/*, you should update the paths object in tsconfig.json to include src/.
