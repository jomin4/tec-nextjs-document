How to use Sass in Next.jsSass 사용하기

Next.js는 package를 설치하면 .scss와 .sass 확장자 모두로 Sass를 통합할 수 있도록 기본(built-in) 지원합니다. CSS Modules와 .module.scss 또는 .module.sass 확장자를 사용하면 component 수준의 Sass를 사용할 수 있습니다.

Next.js has built-in support for integrating with Sass after the package is installed using both the .scss and .sass extensions. You can use component-level Sass via CSS Modules and the .module.scss or .module.sass extension.

먼저 sass를 설치하세요:

First, install sass:

pnpm add -D sass
npm install --save-dev sass
yarn add -D sass
bun add -D sass
Good to know

Sass는 두 가지 syntax를 지원하며, 각각 고유한 확장자를 가집니다. .scss 확장자는 SCSS syntax를 사용해야 하고, .sass 확장자는 Indented Syntax ("Sass")를 사용해야 합니다.

어느 쪽을 골라야 할지 모르겠다면, CSS의 superset이라서 Indented Syntax ("Sass")를 따로 배울 필요가 없는 .scss 확장자로 시작하세요.

Sass supports two different syntaxes, each with their own extension. The .scss extension requires you use the SCSS syntax, while the .sass extension requires you use the Indented Syntax ("Sass").

If you're not sure which to choose, start with the .scss extension which is a superset of CSS, and doesn't require you learn the Indented Syntax ("Sass").

Customizing Sass OptionsSass option 커스터마이징

Sass option을 설정하려면 next.config에서 sassOptions를 사용하세요.

If you want to configure your Sass options, use sassOptions in next.config.

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  sassOptions: {
    additionalData: `$var: red;`,
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */

const nextConfig = {
  sassOptions: {
    additionalData: `$var: red;`,
  },
}

module.exports = nextConfig

Implementation

implementation property로 사용할 Sass implementation을 지정할 수 있습니다. 기본적으로 Next.js는 sass package를 사용합니다.

You can use the implementation property to specify the Sass implementation to use. By default, Next.js uses the sass package.

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  sassOptions: {
    implementation: 'sass-embedded',
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */

const nextConfig = {
  sassOptions: {
    implementation: 'sass-embedded',
  },
}

module.exports = nextConfig

Sass VariablesSass 변수

Next.js는 CSS Module 파일에서 export한 Sass 변수를 지원합니다.

Next.js supports Sass variables exported from CSS Module files.

예를 들어, export한 primaryColor Sass 변수를 사용하는 방법은 다음과 같습니다:

For example, using the exported primaryColor Sass variable:

app/variables.module.scss
$primary-color: #64ff00;

:export {
  primaryColor: $primary-color;
}
JSpages/_app.js
import variables from '../styles/variables.module.scss'

export default function MyApp({ Component, pageProps }) {
  return (
    <Layout color={variables.primaryColor}>
      <Component {...pageProps} />
    </Layout>
  )
}
