trailingSlashtrailingSlash

기본적으로 Next.js는 trailing slash가 있는 URL을 trailing slash가 없는 URL로 redirect합니다. 예를 들어 /about/은 /about으로 redirect됩니다. 이 동작을 반대로 설정해서, trailing slash가 없는 URL을 trailing slash가 있는 URL로 redirect하도록 할 수 있습니다.

By default Next.js will redirect URLs with trailing slashes to their counterpart without a trailing slash. For example /about/ will redirect to /about. You can configure this behavior to act the opposite way, where URLs without trailing slashes are redirected to their counterparts with trailing slashes.

next.config.js를 열고 trailingSlash config를 추가하세요:

Open next.config.js and add the trailingSlash config:

JSnext.config.js
module.exports = {
  trailingSlash: true,
}

이 option을 설정하면 /about 같은 URL이 /about/으로 redirect됩니다.

With this option set, URLs like /about will redirect to /about/.

trailingSlash: true를 사용할 때, 일부 URL은 예외로 trailing slash가 추가되지 않습니다:

When using trailingSlash: true, certain URLs are exceptions and will not have a trailing slash appended:

  • 확장자가 있는 파일 같은 static 파일 URL.
  • .well-known/ 아래의 모든 경로.
  • Static file URLs, such as files with extensions.
  • Any paths under .well-known/.

예를 들어 다음 URL은 바뀌지 않고 그대로 유지됩니다: /file.txt, images/photos/picture.png, .well-known/subfolder/config.json.

For example, the following URLs will remain unchanged: /file.txt, images/photos/picture.png, and .well-known/subfolder/config.json.

output: "export" configuration과 함께 사용하면 /about page는 (기본값인 /about.html 대신) /about/index.html로 출력됩니다.

When used with output: "export" configuration, the /about page will output /about/index.html (instead of the default /about.html).
