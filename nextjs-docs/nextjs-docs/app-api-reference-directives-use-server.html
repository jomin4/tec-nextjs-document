use serveruse server

use server directive는 function이나 파일이 server side에서 실행되도록 지정합니다. 파일 맨 위에 사용하면 파일 안의 모든 function이 server-side임을 나타내고, function 맨 위에 inline으로 사용하면 해당 function을 Server Function으로 표시합니다. 이것은 React 기능입니다.

The use server directive designates a function or file to be executed on the server side. It can be used at the top of a file to indicate that all functions in the file are server-side, or inline at the top of a function to mark the function as a Server Function. This is a React feature.

Next.js 고유의 Server Action 동작(response model, 보안, configuration, deployment)은 Server Actions and Mutations를 참고하세요.

For Next.js-specific Server Action behaviors (response model, security, configuration, deployment), see Server Actions and Mutations.

Using use server at the top of a file파일 맨 위에 use server 사용하기

다음 예시는 맨 위에 use server directive가 있는 파일을 보여 줍니다. 파일 안의 모든 function은 server에서 실행됩니다.

The following example shows a file with a use server directive at the top. All functions in the file are executed on the server.

TSJSapp/actions.ts
'use server'
import { db } from '@/lib/db' // Your database client
import { auth } from '@/lib/auth'

export async function createUser(data: { name: string; email: string }) {
  const session = await auth()
  if (!session?.user) {
    throw new Error('Unauthorized')
  }

  const user = await db.user.create({ data })
  return { id: user.id, name: user.name }
}
'use server'
import { db } from '@/lib/db' // Your database client
import { auth } from '@/lib/auth'

export async function createUser(data) {
  const session = await auth()
  if (!session?.user) {
    throw new Error('Unauthorized')
  }

  const user = await db.user.create({ data })
  return { id: user.id, name: user.name }
}

Using Server Functions in a Client ComponentClient Component에서 Server Function 사용하기

Client Component에서 Server Function을 사용하려면, 파일 맨 위에 use server directive를 둔 전용 파일에 Server Function을 만들어야 합니다. 그러면 이 Server Function을 Client Component와 Server Component에서 import해 실행할 수 있습니다.

To use Server Functions in Client Components you need to create your Server Functions in a dedicated file using the use server directive at the top of the file. These Server Functions can then be imported into Client and Server Components and executed.

actions.ts에 fetchUsers Server Function이 있다고 가정해 봅시다:

Assuming you have a fetchUsers Server Function in actions.ts:

TSJSapp/actions.ts
'use server'
import { db } from '@/lib/db' // Your database client
import { auth } from '@/lib/auth'

export async function fetchUsers() {
  const session = await auth()
  if (!session?.user) {
    throw new Error('Unauthorized')
  }

  const users = await db.user.findMany({
    select: { id: true, name: true, email: true },
  })
  return users
}
'use server'
import { db } from '@/lib/db' // Your database client
import { auth } from '@/lib/auth'

export async function fetchUsers() {
  const session = await auth()
  if (!session?.user) {
    throw new Error('Unauthorized')
  }

  const users = await db.user.findMany({
    select: { id: true, name: true, email: true },
  })
  return users
}

그러면 fetchUsers Server Function을 Client Component로 import해 client-side에서 실행할 수 있습니다.

Then you can import the fetchUsers Server Function into a Client Component and execute it on the client-side.

TSJSapp/components/my-button.tsx
'use client'
import { fetchUsers } from '../actions'

export default function MyButton() {
  return <button onClick={() => fetchUsers()}>Fetch Users</button>
}
'use client'
import { fetchUsers } from '../actions'

export default function MyButton() {
  return <button onClick={() => fetchUsers()}>Fetch Users</button>
}

Using use server inlineuse server를 inline으로 사용하기

다음 예시에서는 use server를 function 맨 위에 inline으로 사용해 해당 function을 Server Function으로 표시합니다:

In the following example, use server is used inline at the top of a function to mark it as a Server Function:

TSJSapp/posts/[id]/page.tsx
import { EditPost } from './edit-post'
import { revalidatePath } from 'next/cache'

export default async function PostPage({ params }: PageProps<'/posts/[id]'>) {
  const { id } = await params
  const post = await getPost(id)

  async function updatePost(formData: FormData) {
    'use server'
    // Verify auth before saving (e.g. inside savePost)
    await savePost(id, formData)
    revalidatePath(`/posts/${id}`)
  }

  return <EditPost updatePostAction={updatePost} post={post} />
}
import { EditPost } from './edit-post'
import { revalidatePath } from 'next/cache'

export default async function PostPage({ params }) {
  const { id } = await params
  const post = await getPost(id)

  async function updatePost(formData) {
    'use server'
    // Verify auth before saving (e.g. inside savePost)
    await savePost(id, formData)
    revalidatePath(`/posts/${id}`)
  }

  return <EditPost updatePostAction={updatePost} post={post} />
}

Security considerations보안 고려 사항

data access function은 안전한 primitive로 설계하세요: input을 검증하고, authentication과 authorization을 확인하고, return type을 호출하는 쪽에 필요한 것만으로 제한하세요. Server Function이 Data Access Layer에 작업을 위임하면, 이러한 보장이 한곳에 모여 일관되게 적용됩니다.

Design your data access functions as secure primitives: validate inputs, check authentication and authorization, and constrain return types to only what the caller needs. When Server Functions delegate to a Data Access Layer, these guarantees live in one place and apply consistently.

Authentication and authorizationAuthentication과 authorization

민감한 server-side 작업을 수행하기 전에는 항상 사용자를 authenticate하고 authorize하세요. token을 function parameter로 받지 말고 cookie나 header에서 authentication 정보를 읽으세요.

Always authenticate and authorize users before performing sensitive server-side operations. Read authentication from cookies or headers rather than accepting tokens as function parameters.

TSJSapp/actions.ts
'use server'

import { db } from '@/lib/db' // Your database client
import { auth } from '@/lib/auth' // Your authentication library

export async function createUser(data: { name: string; email: string }) {
  const session = await auth()
  if (!session?.user) {
    throw new Error('Unauthorized')
  }
  const newUser = await db.user.create({ data })
  return { id: newUser.id, name: newUser.name }
}
'use server'

import { db } from '@/lib/db' // Your database client
import { auth } from '@/lib/auth' // Your authentication library

  const session = await auth()
  if (!session?.user) {
    throw new Error('Unauthorized')
  }
  const newUser = await db.user.create({ data })
  return { id: newUser.id, name: newUser.name }
}

Return values반환 값

Server Function의 return value는 serialize되어 client로 전송됩니다. 가공하지 않은 database record가 아니라 UI에 필요한 데이터만 반환하세요. 자세한 내용은 Data Security 가이드를 참고하세요.

Server Function return values are serialized and sent to the client. Only return data the UI needs, not raw database records. See the Data Security guide for more details.
