How to use fonts폰트 최적화

next/font module은 font를 자동으로 최적화하고 외부 network request를 제거해 privacy와 performance를 향상시킵니다.

The next/font module automatically optimizes your fonts and removes external network requests for improved privacy and performance.

모든 font 파일에 대해 built-in self-hosting 기능을 제공합니다. 즉, layout shift 없이 web font를 최적으로 로드할 수 있습니다.

It includes built-in self-hosting for any font file. This means you can optimally load web fonts with no layout shift.

next/font를 사용하려면 next/font/local 또는 next/font/google에서 import하고, 적절한 option과 함께 함수로 호출한 다음, font를 적용할 element의 className을 설정하세요. 예를 들어 Custom App(pages/_app)에서 font를 global하게 적용할 수 있습니다:

To start using next/font, import it from next/font/local or next/font/google, call it as a function with the appropriate options, and set the className of the element you want to apply the font to. For example, you can apply fonts globally in your Custom App (pages/_app):

TSJSpages/_app.tsx
import { Geist } from 'next/font/google'
import type { AppProps } from 'next/app'

const geist = Geist({
  subsets: ['latin'],
})

export default function MyApp({ Component, pageProps }: AppProps) {
  return (
    <main className={geist.className}>
      <Component {...pageProps} />
    </main>
  )
}
import { Geist } from 'next/font/google'

const geist = Geist({
  subsets: ['latin'],
})

export default function MyApp({ Component, pageProps }) {
  return (
    <main className={geist.className}>
      <Component {...pageProps} />
    </main>
  )
}

Google fontsGoogle font

모든 Google Font를 자동으로 self-host할 수 있습니다. font는 static asset으로 포함되어 deployment와 같은 domain에서 제공되므로, 사용자가 사이트를 방문할 때 브라우저가 Google로 request를 보내지 않습니다.

You can automatically self-host any Google Font. Fonts are included as static assets and served from the same domain as your deployment, meaning no requests are sent to Google by the browser when the user visits your site.

Google Font를 사용하려면 next/font/google에서 원하는 font를 import하세요:

To start using a Google Font, import your chosen font from next/font/google:

TSJSpages/_app.tsx
import { Geist } from 'next/font/google'
import type { AppProps } from 'next/app'

const geist = Geist({
  subsets: ['latin'],
})

export default function MyApp({ Component, pageProps }: AppProps) {
  return (
    <main className={geist.className}>
      <Component {...pageProps} />
    </main>
  )
}
import { Geist } from 'next/font/google'

const geist = Geist({
  subsets: ['latin'],
})

export default function MyApp({ Component, pageProps }) {
  return (
    <main className={geist.className}>
      <Component {...pageProps} />
    </main>
  )
}

최상의 performance와 유연성을 위해 variable font 사용을 권장합니다. 하지만 variable font를 사용할 수 없다면 weight를 지정해야 합니다:

We recommend using variable fonts for the best performance and flexibility. But if you can't use a variable font, you will need to specify a weight:

TSJSpages/_app.tsx
import { Roboto } from 'next/font/google'
import type { AppProps } from 'next/app'

const roboto = Roboto({
  weight: '400',
  subsets: ['latin'],
})

export default function MyApp({ Component, pageProps }: AppProps) {
  return (
    <main className={roboto.className}>
      <Component {...pageProps} />
    </main>
  )
}
import { Roboto } from 'next/font/google'

const roboto = Roboto({
  weight: '400',
  subsets: ['latin'],
})

export default function MyApp({ Component, pageProps }) {
  return (
    <main className={roboto.className}>
      <Component {...pageProps} />
    </main>
  )
}

Local fonts로컬 font

로컬 font를 사용하려면 next/font/local에서 font를 import하고 로컬 font 파일의 src를 지정하세요. font는 public 폴더나 pages 폴더 안에 저장할 수 있습니다. 예를 들면 다음과 같습니다:

To use a local font, import your font from next/font/local and specify the src of your local font file. Fonts can be stored in the public folder or inside the pages folder. For example:

TSJSpages/_app.tsx
import localFont from 'next/font/local'
import type { AppProps } from 'next/app'

const myFont = localFont({
  src: './my-font.woff2',
})

export default function MyApp({ Component, pageProps }: AppProps) {
  return (
    <main className={myFont.className}>
      <Component {...pageProps} />
    </main>
  )
}
import localFont from 'next/font/local'

const myFont = localFont({
  src: './my-font.woff2',
})

export default function MyApp({ Component, pageProps }) {
  return (
    <main className={myFont.className}>
      <Component {...pageProps} />
    </main>
  )
}

하나의 font family에 여러 파일을 사용하려면 src를 배열로 지정할 수 있습니다:

If you want to use multiple files for a single font family, src can be an array:

const roboto = localFont({
  src: [
    {
      path: './Roboto-Regular.woff2',
      weight: '400',
      style: 'normal',
    },
    {
      path: './Roboto-Italic.woff2',
      weight: '400',
      style: 'italic',
    },
    {
      path: './Roboto-Bold.woff2',
      weight: '700',
      style: 'normal',
    },
    {
      path: './Roboto-BoldItalic.woff2',
      weight: '700',
      style: 'italic',
    },
  ],
})
