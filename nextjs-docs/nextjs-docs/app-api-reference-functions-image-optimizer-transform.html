next/image-optimizer-transformnext/image-optimizer-transform

next/image-optimizer-transform module은 Next.js Image Optimization의 변환(transformation) 단계를 dependency graph가 작은 독립형 Node.js module로 제공합니다. 덕분에 (sharp 기반의) 이미지 resizing과 format 변환을 main server process 밖에서 실행할 수 있습니다.

The next/image-optimizer-transform module exposes the transformation step of Next.js Image Optimization as a standalone Node.js module with a small dependency graph, so image resizing and format conversion (powered by sharp) can run outside the main server process.

TSJSoptimize.ts
import { imageOptimizerTransform } from 'next/image-optimizer-transform'

const result = await imageOptimizerTransform(
  {
    buffer: upstreamBuffer, // Buffer of the source image
    contentType: null,
    cacheControl: 'public, max-age=120',
    etag: 'source-etag',
  },
  { href: '/me.png', width: 64, quality: 75, mimeType: 'image/webp' },
  {
    images: { dangerouslyAllowSVG: false, minimumCacheTTL: 60 },
    experimental: {
      imgOptConcurrency: null,
      imgOptOperationCache: null,
      imgOptMaxInputPixels: 268402689,
      imgOptSequentialRead: null,
      imgOptTimeoutInSeconds: 7,
      imgOptMozjpeg: true,
    },
  }
)
// result.contentType === 'image/webp'

imageOptimizerTransform

  imageUpstream: ImageUpstream,
  paramsResult: ImageOptimizerTransformParams,

upstream 이미지를 검증하고, sharp로 최적화한 뒤, caching metadata와 함께 결과를 반환합니다.

Validates an upstream image, optimizes it with sharp, and returns the result with caching metadata.

이 함수는 다음 단계를 순서대로 실행합니다:

The function runs the following steps in order:

  1. images.minimumCacheTTL과 upstream Cache-Control의 s-maxage 또는 max-age directive 중 더 큰 값으로 maxAge를 계산합니다.
  2. imageUpstream.buffer의 magic byte로 content type을 감지합니다.
  3. buffer가 인식 가능한 이미지가 아니거나, 이미지가 SVG인데 images.dangerouslyAllowSVG가 false이면 statusCode 400인 ImageError를 throw합니다.
  4. animated WebP, PNG, GIF source는 최적화하지 않고 반환하며, logger.warnOnce를 호출합니다.
  5. SVG, ICO, ICNS, BMP, JXL, HEIC source는 수정 없이 그대로 반환합니다.
  6. output type을 선택합니다: paramsResult.mimeType이 비어 있지 않으면 그 값을, 요청된 type이 없고 source가 WebP 또는 AVIF이면 image/jpeg를, 그 외에는 감지된 source type을 사용합니다.
  7. opts.previousOutput이 제공되면 최적화하지 않고 그 값을 반환합니다.
  8. experimental.imgOpt* 값을 사용해 optimizeImage로 최적화한 뒤, opts.handleDevOutput이 제공되었으면 이를 적용합니다.
  9. 실패하면 upstream buffer와 content type을 반환하며, 이때 maxAge는 images.minimumCacheTTL로 설정되고 catch된 값은 result.error에 담깁니다. 실패해도 throw하지 않습니다.
  1. Computes maxAge as the greater of images.minimumCacheTTL and the upstream Cache-Control s-maxage or max-age directive.
  2. Detects the content type from the magic bytes of imageUpstream.buffer.
  3. Throws an ImageError with statusCode 400 when the buffer is not a recognized image, or when the image is SVG and images.dangerouslyAllowSVG is false.
  4. Returns animated WebP, PNG, and GIF sources unoptimized, and calls logger.warnOnce.
  5. Returns SVG, ICO, ICNS, BMP, JXL, and HEIC sources unmodified.
  6. Selects the output type: paramsResult.mimeType when non-empty, image/jpeg for WebP or AVIF sources when no type is requested, otherwise the detected source type.
  7. Returns opts.previousOutput without optimizing when it is provided.
  8. Optimizes with optimizeImage using the experimental.imgOpt* values, then applies opts.handleDevOutput when provided.
  9. On failure, returns the upstream buffer and content type with maxAge set to images.minimumCacheTTL and the caught value on result.error. The failure does not throw.

getMaxAge

function getMaxAge(cacheControl: string | null | undefined): number

Cache-Control header 값을 parse해서 s-maxage directive를, s-maxage가 없으면 max-age directive를 초 단위 정수로 반환합니다. 두 directive가 모두 없거나 값이 숫자가 아니면 0을 반환합니다. 이는 image optimizer가 maxAge를 계산할 때 upstream response에 적용하는 것과 같은 parsing입니다.

Parses a Cache-Control header value and returns the s-maxage directive, or the max-age directive when s-maxage is absent, as an integer number of seconds. Returns 0 when neither directive is present or its value is not a number. This is the same parsing the image optimizer applies to upstream responses when computing maxAge.

const maxAge = getMaxAge('public, max-age=120') // 120

getSharp

function getSharp(
  concurrency: number | null | undefined,
  operationCache: boolean | null | undefined
): typeof import('sharp').default

sharp module을 한 번 load하고 configuration을 적용한 뒤, memoize된 instance를 반환합니다.

Loads the sharp module once, applies configuration, and returns the memoized instance.

ParameterTypeDescription
concurrencynumber | null | undefinedlibvips thread pool 크기입니다. 숫자가 아니면 기본값은 현재 concurrency를 development에서는 4로, production에서는 2로 나눈 값이며 최소값은 1입니다.
operationCacheboolean | null | undefinedboolean이면 sharp.cache()에 전달되어 libvips operation cache를 활성화하거나 비활성화합니다.
ParameterTypeDescription
concurrencynumber | null | undefinedThe libvips thread pool size. When not a number, the default is the current concurrency divided by 4 in development or 2 in production, with a minimum of 1.
operationCacheboolean | null | undefinedWhen a boolean, passed to sharp.cache() to enable or disable the libvips operation cache.

처음 load할 때 getSharp는 libvips image loader를 HEIF(AVIF), JPEG, GIF, PNG, SVG, TIFF, WebP로 제한합니다. sharp가 설치되어 있지 않으면 npm install --cpu=wasm32 sharp 실행을 권하는 error를 throw합니다.

On first load, getSharp restricts libvips image loaders to HEIF (AVIF), JPEG, GIF, PNG, SVG, TIFF, and WebP. If sharp is not installed, it throws an error that suggests running npm install --cpu=wasm32 sharp.

ImageError

class ImageError extends Error {
  statusCode: number
  constructor(statusCode: number, message: string)
}

잘못된 input에 대해 imageOptimizerTransform이 throw하는 error type입니다. statusCode가 400 이상이면 그대로 유지됩니다. 그보다 낮은 값은 500으로 대체됩니다.

The error type thrown by imageOptimizerTransform for invalid input. statusCode is preserved when it is 400 or greater. Any lower value is replaced with 500.

Good to know알아 두면 좋은 점

  • sharp는 필수이며, getSharp 또는 optimizeImage를 처음 호출할 때 lazy하게 load됩니다. 이후에는 같은 instance를 재사용합니다.
  • 이 module은 worker나 child process 같은 별도 process에서 빠르게 load되도록 의도적으로 import를 최소화합니다. 파일 위치와 export는 안정적인 public contract입니다.
  • imageUpstream의 contentType field는 감지에 사용되지 않습니다. content type은 buffer의 첫 byte들로 감지합니다.
  • 최적화 실패는 throw하지 않습니다. imageOptimizerTransform은 결과에 error를 설정하고 upstream buffer를 반환합니다.
  • previousOutput을 전달하면 sharp를 완전히 건너뛰지만, upstream buffer 검증은 여전히 먼저 수행됩니다.
  • animated WebP, PNG, GIF 이미지는 최적화 없이 반환됩니다. SVG, ICO, ICNS, BMP, JXL, HEIC 이미지는 항상 최적화 없이 그대로 통과합니다.
  • sharp is required and is loaded lazily on the first call to getSharp or optimizeImage. The same instance is reused afterwards.
  • The module intentionally imports very little so it loads quickly in a separate process, such as a worker or child process. Its file location and exports are a stable public contract.
  • The contentType field of imageUpstream is not used for detection. The content type is detected from the first bytes of the buffer.
  • Optimization failures do not throw. imageOptimizerTransform returns the upstream buffer with error set on the result.
  • Passing previousOutput skips sharp entirely, but the upstream buffer is still validated first.
  • Animated WebP, PNG, and GIF images are returned unoptimized. SVG, ICO, ICNS, BMP, JXL, and HEIC images are always passed through without optimization.

Examples예시

Optimizing a fetched imagefetch한 이미지 최적화하기

upstream 이미지를 fetch하고, response header를 upstream metadata로 사용해 WebP로 변환합니다.

Fetch an upstream image and convert it to WebP, using the response headers as the upstream metadata.

TSJSoptimize.ts
import { imageOptimizerTransform } from 'next/image-optimizer-transform'

const logger = {
  error: (...args: unknown[]) => console.error(...args),
  warnOnce: (message: string) => console.warn(message),
}

const upstream = await fetch('https://example.com/me.png')

const result = await imageOptimizerTransform(
  {
    buffer: Buffer.from(await upstream.arrayBuffer()),
    contentType: upstream.headers.get('content-type'),
    cacheControl: upstream.headers.get('cache-control'),
    etag: upstream.headers.get('etag') ?? 'unknown',
  },
  {
    href: 'https://example.com/me.png',
    width: 64,
    quality: 75,
    mimeType: 'image/webp',
  },
  {
    images: { dangerouslyAllowSVG: false, minimumCacheTTL: 60 },
    experimental: {
      imgOptConcurrency: null,
      imgOptOperationCache: null,
      imgOptMaxInputPixels: 268402689,
      imgOptSequentialRead: null,
      imgOptTimeoutInSeconds: 7,
      imgOptMozjpeg: true,
    },
  },
  { logger }
)

if (result.error) {
  // Optimization failed. result.buffer contains the upstream image.
}

Reusing a previously cached result이전에 cache된 결과 재사용하기

cache된 결과가 이미 있을 때 previousOutput을 전달해 최적화를 건너뜁니다.

Pass previousOutput to skip optimization when a cached result already exists.

TSJSoptimize.ts
const result = await imageOptimizerTransform(
  imageUpstream,
  params,
  nextConfig,
  {
    previousOutput: {
      buffer: cachedBuffer,
      maxAge: 90,
      etag: 'optimized-etag',
      upstreamEtag: 'source-etag',
    },
  }
)
// result.buffer === cachedBuffer, sharp is not invoked.
const result = await imageOptimizerTransform(
  imageUpstream,
  params,
  nextConfig,
  {
    previousOutput: {
      buffer: cachedBuffer,
      maxAge: 90,
      etag: 'optimized-etag',
      upstreamEtag: 'source-etag',
    },
  }
)
// result.buffer === cachedBuffer, sharp is not invoked.
