How to set up Playwright with Next.jsNext.js에 Playwright 설정하기

Playwright는 하나의 API로 Chromium, Firefox, WebKit을 자동화할 수 있게 해 주는 testing framework입니다. 이를 사용해 End-to-End (E2E) test를 작성할 수 있습니다. 이 가이드에서는 Next.js에 Playwright를 설정하고 첫 test를 작성하는 방법을 보여 줍니다.

Playwright is a testing framework that lets you automate Chromium, Firefox, and WebKit with a single API. You can use it to write End-to-End (E2E) testing. This guide will show you how to set up Playwright with Next.js and write your first tests.

Quickstart빠른 시작

가장 빠르게 시작하는 방법은 with-playwright example과 함께 create-next-app을 사용하는 것입니다. 이렇게 하면 Playwright 설정이 완료된 Next.js 프로젝트가 만들어집니다.

The fastest way to get started is to use create-next-app with the with-playwright example. This will create a Next.js project complete with Playwright configured.

pnpm create next-app --example with-playwright with-playwright-app
npx create-next-app@latest --example with-playwright with-playwright-app
yarn create next-app --example with-playwright with-playwright-app
bun create next-app --example with-playwright with-playwright-app

Manual setup수동 설정

Playwright를 설치하려면 다음 command를 실행하세요:

To install Playwright, run the following command:

pnpm create playwright
npm init playwright
yarn create playwright
bun create playwright

일련의 prompt를 거치며 프로젝트에 Playwright를 설치하고 설정하게 되며, playwright.config.ts 파일도 추가됩니다. 단계별 안내는 Playwright 설치 가이드를 참고하세요.

This will take you through a series of prompts to set up and configure Playwright for your project, including adding a playwright.config.ts file. Please refer to the Playwright installation guide for the step-by-step guide.

Creating your first Playwright E2E test첫 Playwright E2E test 만들기

새 Next.js page 두 개를 만드세요:

Create two new Next.js pages:

TSapp/page.tsx
import Link from 'next/link'

export default function Page() {
  return (
    <div>
      <h1>Home</h1>
      <Link href="/about">About</Link>
    </div>
  )
}
TSapp/about/page.tsx
import Link from 'next/link'

export default function Page() {
  return (
    <div>
      <h1>About</h1>
      <Link href="/">Home</Link>
    </div>
  )
}

그런 다음 navigation이 올바르게 동작하는지 검증하는 test를 추가하세요:

Then, add a test to verify that your navigation is working correctly:

TStests/example.spec.ts
import { test, expect } from '@playwright/test'

test('should navigate to the about page', async ({ page }) => {
  // Start from the index page (the baseURL is set via the webServer in the playwright.config.ts)
  await page.goto('http://localhost:3000/')
  // Find an element with the text 'About' and click on it
  await page.click('text=About')
  // The new URL should be "/about" (baseURL is used there)
  await expect(page).toHaveURL('http://localhost:3000/about')
  // The new page should contain an h1 with "About"
  await expect(page.locator('h1')).toContainText('About')
})
Good to know

playwright.config.ts configuration 파일에 "baseURL": "http://localhost:3000"을 추가하면 page.goto("http://localhost:3000/") 대신 page.goto("/")를 사용할 수 있습니다.

You can use page.goto("/") instead of page.goto("http://localhost:3000/"), if you add "baseURL": "http://localhost:3000" to the playwright.config.ts configuration file.

Testing instant navigationsinstant navigation test하기

Cache Components를 사용한다면 @next/playwright의 instant() helper로 navigation 직후, dynamic 콘텐츠가 stream되어 들어오기 전에 무엇이 보이는지 assert할 수 있습니다. 설정 방법과 예제는 Instant navigation 가이드와 instant API reference를 참고하세요.

If you're using Cache Components, the instant() helper from @next/playwright lets you assert what is visible immediately after a navigation, before any dynamic content streams in. See the Instant navigation guide and the instant API reference for setup and examples.

Running your Playwright testsPlaywright test 실행하기

Playwright는 Chromium, Firefox, WebKit 세 가지 브라우저로 사용자가 애플리케이션을 탐색하는 것을 시뮬레이션하므로 Next.js server가 실행 중이어야 합니다. 애플리케이션이 실제로 동작하는 방식과 더 비슷하도록 production 코드를 대상으로 test를 실행하는 것을 권장합니다.

Playwright will simulate a user navigating your application using three browsers: Chromium, Firefox and WebKit, this requires your Next.js server to be running. We recommend running your tests against your production code to more closely resemble how your application will behave.

npm run build와 npm run start를 실행한 다음, 다른 terminal 창에서 npx playwright test를 실행해 Playwright test를 실행하세요.

Run npm run build and npm run start, then run npx playwright test in another terminal window to run the Playwright tests.

Good to know

또는 webServer 기능을 사용해 Playwright가 development server를 시작하고 완전히 사용 가능해질 때까지 기다리게 할 수 있습니다.

Alternatively, you can use the webServer feature to let Playwright start the development server and wait until it's fully available.

Running Playwright on Continuous Integration (CI)CI에서 Playwright 실행하기

Playwright는 기본적으로 headless mode로 test를 실행합니다. Playwright dependency를 모두 설치하려면 npx playwright install-deps를 실행하세요.

Playwright will by default run your tests in the headless mode. To install all the Playwright dependencies, run npx playwright install-deps.
