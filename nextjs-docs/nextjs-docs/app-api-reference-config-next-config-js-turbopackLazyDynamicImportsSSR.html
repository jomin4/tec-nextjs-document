turbopackLazyDynamicImportsSSRexperimentalturbopackLazyDynamicImportsSSR

experimental.turbopackLazyDynamicImportsSSR option은 next dev 중 server rendering이 dynamic import에 처음 도달할 때까지 해당 import의 compile을 미룹니다.

The experimental.turbopackLazyDynamicImportsSSR option defers compiling dynamic imports until server rendering first reaches them during next dev.

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    turbopackLazyDynamicImportsSSR: true,
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    turbopackLazyDynamicImportsSSR: true,
  },
}

module.exports = nextConfig

How it works동작 방식

Client Component는 lazy를 사용해 component를 동적으로 load할 수 있습니다. turbopackLazyDynamicImportsSSR를 활성화하면, Turbopack은 server render가 import된 component에 처음 도달할 때 그 component를 compile합니다. render되지 않은 target은 compile되지 않은 채로 남습니다.

Client Components can use lazy to load a component dynamically. With turbopackLazyDynamicImportsSSR enabled, Turbopack compiles the imported component when a server render first reaches it. A target that is not rendered remains uncompiled.

다음 예제에서 Turbopack은 server rendering 중 showPreview가 true일 때 Preview를 compile합니다:

In the following example, Turbopack compiles Preview when showPreview is true during server rendering:

TSJSapp/preview.tsx
'use client'

import { lazy } from 'react'

const Preview = lazy(() => import('./preview-panel'))

export function MaybePreview({ showPreview }: { showPreview: boolean }) {
  return showPreview ? <Preview /> : null
}
'use client'

import { lazy } from 'react'

const Preview = lazy(() => import('./preview-panel'))

export function MaybePreview({ showPreview }) {
  return showPreview ? <Preview /> : null
}
Good to know
  • 이 option의 기본값은 false이며, next dev 중 Turbopack을 사용하는 Node.js runtime에만 영향을 줍니다. production build는 바뀌지 않습니다.
  • client-side dynamic import를 브라우저가 요청할 때까지 미루려면 turbopackLazyDynamicImports를 사용하세요.
  • The option defaults to false and only affects the Node.js runtime with Turbopack during next dev. It does not change production builds.
  • To defer client-side dynamic imports until the browser requests them, use turbopackLazyDynamicImports.
