How to optimize third-party librariesthird-party library 최적화하기

@next/third-parties library는 Next.js 애플리케이션에서 인기 있는 third-party library를 로드할 때 성능과 개발자 경험을 개선해 주는 component와 utility 모음을 제공합니다.

@next/third-parties is a library that provides a collection of components and utilities that improve the performance and developer experience of loading popular third-party libraries in your Next.js application.

@next/third-parties가 제공하는 모든 third-party integration은 성능과 사용 편의성을 위해 최적화되어 있습니다.

All third-party integrations provided by @next/third-parties have been optimized for performance and ease of use.

Getting Started시작하기

시작하려면 @next/third-parties library를 설치하세요:

To get started, install the @next/third-parties library:

pnpm add @next/third-parties@latest next@latest
npm install @next/third-parties@latest next@latest
yarn add @next/third-parties@latest next@latest
bun add @next/third-parties@latest next@latest

@next/third-parties는 현재 활발히 개발 중인 experimental library입니다. third-party integration을 더 추가하는 동안에는 latest 또는 canary flag로 설치하는 것을 권장합니다.

@next/third-parties is currently an experimental library under active development. We recommend installing it with the latest or canary flags while we work on adding more third-party integrations.

Google Third-PartiesGoogle third-party

Google에서 지원하는 모든 third-party library는 @next/third-parties/google에서 import할 수 있습니다.

All supported third-party libraries from Google can be imported from @next/third-parties/google.

Google Tag Manager

GoogleTagManager component를 사용하면 페이지에 Google Tag Manager container를 instance화할 수 있습니다. 기본적으로 페이지에서 hydration이 일어난 뒤 원래의 inline script를 가져옵니다.

The GoogleTagManager component can be used to instantiate a Google Tag Manager container to your page. By default, it fetches the original inline script after hydration occurs on the page.

모든 route에서 Google Tag Manager를 로드하려면 custom _app에 component를 직접 넣고 GTM container ID를 전달하세요:

To load Google Tag Manager for all routes, include the component directly in your custom _app and pass in your GTM container ID:

JSpages/_app.js
import { GoogleTagManager } from '@next/third-parties/google'

export default function MyApp({ Component, pageProps }) {
  return (
    <>
      <Component {...pageProps} />
      <GoogleTagManager gtmId="GTM-XYZ" />
    </>
  )
}

하나의 route에서만 Google Tag Manager를 로드하려면 page 파일에 component를 넣으세요:

To load Google Tag Manager for a single route, include the component in your page file:

JSpages/index.js
import { GoogleTagManager } from '@next/third-parties/google'

export default function Page() {
  return <GoogleTagManager gtmId="GTM-XYZ" />
}

Sending Eventsevent 보내기

sendGTMEvent function은 dataLayer object를 사용해 event를 보내는 방식으로 페이지의 사용자 상호작용을 추적하는 데 사용할 수 있습니다. 이 function이 동작하려면 <GoogleTagManager /> component가 상위 layout, page, component 중 하나에 포함되어 있거나 같은 파일에 직접 포함되어 있어야 합니다.

The sendGTMEvent function can be used to track user interactions on your page by sending events using the dataLayer object. For this function to work, the <GoogleTagManager /> component must be included in either a parent layout, page, or component, or directly in the same file.

JSpages/index.js
import { sendGTMEvent } from '@next/third-parties/google'

export function EventButton() {
  return (
    <div>
      <button
        onClick={() => sendGTMEvent({ event: 'buttonClicked', value: 'xyz' })}
      >
        Send Event
      </button>
    </div>
  )
}

function에 전달할 수 있는 다양한 variable과 event에 대해 알아보려면 Tag Manager developer documentation을 참고하세요.

Refer to the Tag Manager developer documentation to learn about the different variables and events that can be passed into the function.

Server-side Tagging

server-side tag manager를 사용하면서 tagging server에서 gtm.js script를 제공한다면, gtmScriptUrl option으로 script의 URL을 지정할 수 있습니다.

If you're using a server-side tag manager and serving gtm.js scripts from your tagging server you can use gtmScriptUrl option to specify the URL of the script.

Options

Google Tag Manager에 전달할 option입니다. 전체 option 목록은 Google Tag Manager 문서를 참고하세요.

Options to pass to the Google Tag Manager. For a full list of options, read the Google Tag Manager docs.

NameTypeDescription

gtmScriptUrlOptional*GTM script URL입니다. 기본값은 https://www.googletagmanager.com/gtm.js입니다.
dataLayerOptionalcontainer를 instance화할 때 사용할 data layer object입니다.
dataLayerNameOptionaldata layer의 이름입니다. 기본값은 dataLayer입니다.
authOptionalenvironment snippet용 인증 parameter(gtm_auth)의 값입니다.
previewOptionalenvironment snippet용 preview parameter(gtm_preview)의 값입니다.
NameTypeDescription
gtmIdRequired*Your GTM container ID. Usually starts with GTM-.
gtmScriptUrlOptional*GTM script URL. Defaults to https://www.googletagmanager.com/gtm.js.
dataLayerOptionalData layer object to instantiate the container with.
dataLayerNameOptionalName of the data layer. Defaults to dataLayer.

*Google tag gateway for advertisers를 지원하기 위해 gtmScriptUrl을 제공하는 경우에는 gtmId를 생략할 수 있습니다.

*gtmId can be omitted when gtmScriptUrl is provided to support Google tag gateway for advertisers.

Google Analytics

GoogleAnalytics component를 사용하면 Google tag(gtag.js)를 통해 페이지에 Google Analytics 4를 포함할 수 있습니다. 기본적으로 페이지에서 hydration이 일어난 뒤 원래의 script를 가져옵니다.

The GoogleAnalytics component can be used to include Google Analytics 4 to your page via the Google tag (gtag.js). By default, it fetches the original scripts after hydration occurs on the page.

Recommendation

애플리케이션에 이미 Google Tag Manager가 포함되어 있다면, Google Analytics를 별도 component로 포함하는 대신 Google Tag Manager를 사용해 Google Analytics를 직접 설정할 수 있습니다. Tag Manager와 gtag.js의 차이에 대해 더 알아보려면 문서를 참고하세요.

If Google Tag Manager is already included in your application, you can configure Google Analytics directly using it, rather than including Google Analytics as a separate component. Refer to the documentation to learn more about the differences between Tag Manager and gtag.js.

모든 route에서 Google Analytics를 로드하려면 custom _app에 component를 직접 넣고 measurement ID를 전달하세요:

To load Google Analytics for all routes, include the component directly in your custom _app and pass in your measurement ID:

JSpages/_app.js
import { GoogleAnalytics } from '@next/third-parties/google'

export default function MyApp({ Component, pageProps }) {
  return (
    <>
      <Component {...pageProps} />
      <GoogleAnalytics gaId="G-XYZ" />
    </>
  )
}

하나의 route에서만 Google Analytics를 로드하려면 page 파일에 component를 넣으세요:

To load Google Analytics for a single route, include the component in your page file:

JSpages/index.js
import { GoogleAnalytics } from '@next/third-parties/google'

export default function Page() {
  return <GoogleAnalytics gaId="G-XYZ" />
}

Sending Eventsevent 보내기

sendGAEvent function은 dataLayer object를 사용해 event를 보내는 방식으로 페이지의 사용자 상호작용을 측정하는 데 사용할 수 있습니다. 이 function이 동작하려면 <GoogleAnalytics /> component가 상위 layout, page, component 중 하나에 포함되어 있거나 같은 파일에 직접 포함되어 있어야 합니다.

The sendGAEvent function can be used to measure user interactions on your page by sending events using the dataLayer object. For this function to work, the <GoogleAnalytics /> component must be included in either a parent layout, page, or component, or directly in the same file.

JSpages/index.js
import { sendGAEvent } from '@next/third-parties/google'

export function EventButton() {
  return (
    <div>
      <button
        onClick={() => sendGAEvent('event', 'buttonClicked', { value: 'xyz' })}
      >
        Send Event
      </button>
    </div>
  )
}

event parameter에 대해 더 알아보려면 Google Analytics developer documentation을 참고하세요.

Refer to the Google Analytics developer documentation to learn more about event parameters.

Tracking Pageviewspageview 추적하기

Google Analytics는 브라우저 history state가 바뀔 때 pageview를 자동으로 추적합니다. 즉 Next.js route 간의 client-side navigation은 별도 설정 없이도 pageview 데이터를 보냅니다.

Google Analytics automatically tracks pageviews when the browser history state changes. This means that client-side navigations between Next.js routes will send pageview data without any configuration.

client-side navigation이 올바르게 측정되도록 하려면, Admin 패널에서 _“Enhanced Measurement”_ 속성이 활성화되어 있고 “Page changes based on browser history events” checkbox가 선택되어 있는지 확인하세요.

To ensure that client-side navigations are being measured correctly, verify that the _“Enhanced Measurement”_ property is enabled in your Admin panel and the “Page changes based on browser history events” checkbox is selected.

Note

pageview event를 수동으로 보내기로 했다면, 데이터가 중복되지 않도록 기본 pageview 측정을 비활성화하세요. 자세한 내용은 Google Analytics developer documentation을 참고하세요.

If you decide to manually send pageview events, make sure to disable the default pageview measurement to avoid having duplicate data. Refer to the Google Analytics developer documentation to learn more.

Google Maps Embed

GoogleMapsEmbed component를 사용하면 페이지에 Google Maps Embed를 추가할 수 있습니다. 기본적으로 loading attribute를 사용해 화면 아래쪽(below the fold)에 있는 embed를 lazy-load합니다.

The GoogleMapsEmbed component can be used to add a Google Maps Embed to your page. By default, it uses the loading attribute to lazy-load the embed below the fold.

JSpages/index.js
import { GoogleMapsEmbed } from '@next/third-parties/google'

export default function Page() {
  return (
    <GoogleMapsEmbed
      apiKey="XYZ"
      height={200}
      width="100%"
      mode="place"
      q="Brooklyn+Bridge,New+York,NY"
    />
  )
}

YouTube Embed

YouTubeEmbed component를 사용하면 YouTube embed를 로드하고 표시할 수 있습니다. 이 component는 내부적으로 lite-youtube-embed를 사용해 더 빠르게 로드됩니다.

The YouTubeEmbed component can be used to load and display a YouTube embed. This component loads faster by using lite-youtube-embed under the hood.

JSpages/index.js
import { YouTubeEmbed } from '@next/third-parties/google'

export default function Page() {
  return <YouTubeEmbed videoid="ogfYd705cRs" height={400} params="controls=0" />
}

paramsOptional여기에 정의된 video player params입니다.
params는 query param 문자열로 전달됩니다.
