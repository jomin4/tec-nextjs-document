unauthorized.jsexperimentalunauthorized.js

unauthorized 파일은 unauthorized 함수가 호출될 때 UI를 rendering합니다.

The unauthorized file renders UI when the unauthorized function is invoked.

streaming이 시작되기 전에는 Next.js가 401 status code를 반환합니다. streaming이 시작된 후에는 status code가 200으로 유지되고 unauthorized UI가 response 안에서 rendering됩니다. 두 경우 모두 Next.js는 <meta name="robots" content="noindex" /> tag를 삽입합니다. 자세한 내용은 Status codes를 참고하세요.

Before streaming starts, Next.js returns a 401 status code. After streaming starts, the status code remains 200 and the unauthorized UI renders in the response. Next.js injects a <meta name="robots" content="noindex" /> tag in both cases. See Status codes for details.

TSJSapp/unauthorized.tsx
import Login from '@/app/components/Login'

export default function Unauthorized() {
  return (
    <main>
      <h1>401 - Unauthorized</h1>
      <p>Please log in to access this page.</p>
      <Login />
    </main>
  )
}

Examples예시

Displaying login UI to unauthenticated users인증되지 않은 사용자에게 로그인 UI 표시하기

unauthorized 함수를 사용해 로그인 UI가 있는 unauthorized.js 파일을 rendering할 수 있습니다.

You can use unauthorized function to render the unauthorized.js file with a login UI.

TSJSapp/dashboard/page.tsx
import { verifySession } from '@/app/lib/dal'
import { unauthorized } from 'next/navigation'

export default async function DashboardPage() {
  const session = await verifySession()

  if (!session) {
    unauthorized()
  }

  return <div>Dashboard</div>
}
