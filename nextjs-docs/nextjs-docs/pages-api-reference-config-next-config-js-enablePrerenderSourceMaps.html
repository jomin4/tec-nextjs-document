enablePrerenderSourceMapsenablePrerenderSourceMaps

enablePrerenderSourceMaps option을 사용하면 next build의 prerender 단계에서 Node.js가 기존 source map을 사용할 수 있습니다. source map이 있으면 error stack trace가 원래 source code를 가리킵니다. 기본값은 true입니다.

The enablePrerenderSourceMaps option lets Node.js use existing source maps during the prerender phase of next build. When source maps are available, error stack traces point to the original source code. It defaults to true.

이 option은 source map을 생성하지 않습니다. Webpack은 기본적으로 server source map을 생성하지 않습니다. prerender error를 조사할 때 source map을 생성하려면 next build --debug-prerender를 사용하세요.

This option does not generate source maps. Webpack does not generate server source maps by default. To generate them when investigating prerender errors, use next build --debug-prerender.

비활성화하려면 enablePrerenderSourceMaps를 false로 설정하세요:

To disable it, set enablePrerenderSourceMaps to false:

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  enablePrerenderSourceMaps: false,
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  enablePrerenderSourceMaps: false,
}

module.exports = nextConfig

enablePrerenderSourceMapsbooleantrue

prerendering 중 source map을 비활성화하면 build memory 사용량을 줄일 수 있지만, prerendering error를 debug하기가 더 어려워집니다.

Disabling source maps during prerendering can reduce build memory usage, but makes prerendering errors harder to debug.
