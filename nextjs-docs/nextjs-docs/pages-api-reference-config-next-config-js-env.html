envenv

Next.js 9.4가 release된 이후로 environment variable 추가를 더 직관적이고 편리하게 할 수 있게 되었습니다. 한번 사용해 보세요!

Since the release of Next.js 9.4 we now have a more intuitive and ergonomic experience for adding environment variables. Give it a try!

Good to know

이 방식으로 지정한 environment variable은 항상 JavaScript bundle에 포함됩니다. environment variable 이름에 NEXT_PUBLIC_ prefix를 붙이는 것은 environment나 .env 파일을 통해 지정할 때만 효과가 있습니다.

environment variables specified in this way will always be included in the JavaScript bundle, prefixing the environment variable name with NEXT_PUBLIC_ only has an effect when specifying them through the environment or .env files.

JavaScript bundle에 environment variable을 추가하려면 next.config.js를 열고 env config를 추가하세요:

To add environment variables to the JavaScript bundle, open next.config.js and add the env config:

JSnext.config.js
module.exports = {
  env: {
    customKey: 'my-value',
  },
}

이제 코드에서 process.env.customKey에 접근할 수 있습니다. 예를 들면 다음과 같습니다:

Now you can access process.env.customKey in your code. For example:

function Page() {
  return <h1>The value of customKey is: {process.env.customKey}</h1>
}

export default Page

Next.js는 build 시점에 process.env.customKey를 'my-value'로 치환합니다. webpack DefinePlugin의 특성상 process.env 변수를 destructure하는 방식은 동작하지 않습니다.

Next.js will replace process.env.customKey with 'my-value' at build time. Trying to destructure process.env variables won't work due to the nature of webpack DefinePlugin.

예를 들어 다음 줄은:

For example, the following line:

return <h1>The value of customKey is: {process.env.customKey}</h1>

다음과 같이 바뀝니다:

Will end up being:

return <h1>The value of customKey is: {'my-value'}</h1>
