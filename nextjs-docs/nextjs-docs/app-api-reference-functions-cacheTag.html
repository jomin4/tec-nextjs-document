cacheTagcacheTag

cacheTag 함수를 사용하면 on-demand 무효화를 위해 cache된 데이터에 tag를 붙일 수 있습니다. cache entry에 tag를 연결하면 다른 cache 데이터에 영향을 주지 않고 특정 cache entry만 선택적으로 purge하거나 revalidate할 수 있습니다.

The cacheTag function allows you to tag cached data for on-demand invalidation. By associating tags with cache entries, you can selectively purge or revalidate specific cache entries without affecting other cached data.

Usage사용법

cacheTag를 사용하려면 next.config.js 파일에서 cacheComponents flag를 활성화하세요:

To use cacheTag, enable the cacheComponents flag in your next.config.js file:

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  cacheComponents: true,
}

export default nextConfig
const nextConfig = {
  cacheComponents: true,
}

module.exports = nextConfig

cacheTag 함수는 하나 이상의 문자열 값을 받습니다.

The cacheTag function takes one or more string values.

TSJSapp/data.ts
import { cacheTag } from 'next/cache'

export async function getData() {
  'use cache'
  cacheTag('my-data')
  const res = await fetch('https://api.example.com/data')
  const data = await res.json()
  return data
}
import { cacheTag } from 'next/cache'

export async function getData() {
  'use cache'
  cacheTag('my-data')
  const res = await fetch('https://api.example.com/data')
  const data = await res.json()
  return data
}

그런 다음 Server Function이나 Route Handler에서 on-demand로 cache를 purge할 수 있습니다:

You can then purge the cache on-demand from a Server Function or Route Handler:

  • 사용자가 변경을 하고 다음 읽기에서 즉시 새 데이터를 가져와야 하는 form 등 사용자가 trigger하는 mutation 같은 read-your-own-writes 시나리오에는 updateTag를 사용하세요. updateTag는 Server Function 안에서만 사용할 수 있습니다.
  • background에서 revalidation이 일어나는 동안 stale 데이터를 제공해도 괜찮은 경우, 또는 Route Handler나 다른 context에서 revalidate하는 경우에는 revalidateTag를 사용하세요.
  • Use updateTag for read-your-own-writes scenarios, such as forms and other user-triggered mutations, where a user makes a change and the next read should fetch fresh data immediately. updateTag is only available inside Server Functions.
  • Use revalidateTag when it is acceptable to serve stale data while revalidation happens in the background, or when revalidating from a Route Handler or other context.

예를 들어 다음 Server Function은 post를 추가한 뒤 'my-data' tag가 붙은 모든 cache entry를 purge하여 다음 읽기에 변경 사항이 반영되도록 합니다:

For example, this Server Function adds a post and then purges every cache entry tagged 'my-data' so the next read reflects the change:

TSJSapp/action.ts
'use server'

import { updateTag } from 'next/cache'

export default async function submit() {
  await addPost()
  updateTag('my-data')
}
'use server'

import { updateTag } from 'next/cache'

export default async function submit() {
  await addPost()
  updateTag('my-data')
}

Good to know

  • Idempotent Tags: 같은 tag를 여러 번 적용해도 추가 효과는 없습니다.
  • Multiple Tags: cacheTag에 여러 문자열 값을 전달하면 하나의 cache entry에 여러 tag를 지정할 수 있습니다.
  • Idempotent Tags: Applying the same tag multiple times has no additional effect.
  • Multiple Tags: You can assign multiple tags to a single cache entry by passing multiple string values to cacheTag.
cacheTag('tag-one', 'tag-two')
  • Limits: 한 번의 cacheTag() 호출은 최대 128개의 tag를 받으며, 각 tag의 최대 길이는 256자입니다. 256자보다 긴 tag는 건너뛰고, 한 호출에서 128번째 이후의 tag는 버려집니다. 두 경우 모두 console warning이 기록됩니다.
  • Limits: A single cacheTag() call accepts up to 128 tags, each with a maximum length of 256 characters. Tags longer than 256 characters are skipped, and any tags past the 128th in one call are dropped. Both cases log a console warning.

Examples예시

Tagging components or functionsComponent나 함수에 tag 붙이기

cache된 함수나 component 안에서 cacheTag를 호출해 cache된 데이터에 tag를 붙이세요:

Tag your cached data by calling cacheTag within a cached function or component:

TSJSapp/components/bookings.tsx
import { cacheTag } from 'next/cache'

interface BookingsProps {
  type: string
}

export async function Bookings({ type = 'haircut' }: BookingsProps) {
  'use cache'
  cacheTag('bookings-data')

  async function getBookingsData() {
    const response = await fetch(
      `https://api.example.com/bookings?type=${encodeURIComponent(type)}`
    )
    const data = await response.json()
    return data
  }

  return //...
}
import { cacheTag } from 'next/cache'

export async function Bookings({ type = 'haircut' }) {
  'use cache'
  cacheTag('bookings-data')

  async function getBookingsData() {
    const response = await fetch(
      `https://api.example.com/bookings?type=${encodeURIComponent(type)}`
    )
    const data = await response.json()
    return data
  }

  return //...
}

Creating tags from external data외부 데이터로 tag 만들기

async 함수가 반환한 데이터를 사용해 cache entry에 tag를 붙일 수 있습니다.

You can use the data returned from an async function to tag the cache entry.

TSJSapp/components/bookings.tsx
import { cacheTag } from 'next/cache'

interface BookingsProps {
  type: string
}

export async function Bookings({ type = 'haircut' }: BookingsProps) {
  async function getBookingsData() {
    'use cache'
    const response = await fetch(
      `https://api.example.com/bookings?type=${encodeURIComponent(type)}`
    )
    const data = await response.json()
    cacheTag('bookings-data', data.id)
    return data
  }
  return //...
}
import { cacheTag } from 'next/cache'

export async function Bookings({ type = 'haircut' }) {
  async function getBookingsData() {
    'use cache'
    const response = await fetch(
      `https://api.example.com/bookings?type=${encodeURIComponent(type)}`
    )
    const data = await response.json()
    cacheTag('bookings-data', data.id)
    return data
  }
  return //...
}

Invalidating tagged cacheTag가 붙은 cache 무효화하기

revalidateTag를 사용하면 필요할 때 특정 tag의 cache를 무효화할 수 있습니다:

Using revalidateTag, you can invalidate the cache for a specific tag when needed:

TSJSapp/actions.ts
'use server'

import { revalidateTag } from 'next/cache'

export async function updateBookings() {
  await updateBookingData()
  revalidateTag('bookings-data', 'max')
}
'use server'

import { revalidateTag } from 'next/cache'

export async function updateBookings() {
  await updateBookingData()
  revalidateTag('bookings-data', 'max')
}
