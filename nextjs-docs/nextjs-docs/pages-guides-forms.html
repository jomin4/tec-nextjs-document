How to create forms with API RoutesAPI Routes로 form 만들기

form을 사용하면 웹 애플리케이션에서 data를 만들고 업데이트할 수 있습니다. Next.js는 API Routes를 사용해 data mutation을 처리하는 강력한 방법을 제공합니다. 이 가이드에서는 server에서 form 제출을 처리하는 방법을 단계별로 안내합니다.

Forms enable you to create and update data in web applications. Next.js provides a powerful way to handle data mutations using API Routes. This guide will walk you through how to handle form submission on the server.

Server FormsServer Form

server에서 form 제출을 처리하려면 data를 안전하게 mutate하는 API endpoint를 만드세요.

To handle form submissions on the server, create an API endpoint that securely mutates data.

TSJSpages/api/submit.ts
import type { NextApiRequest, NextApiResponse } from 'next'

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  const data = req.body
  const id = await createItem(data)
  res.status(200).json({ id })
}

그다음 client에서 event handler로 API Route를 호출합니다:

Then, call the API Route from the client with an event handler:

TSJSpages/index.tsx
import { SubmitEvent } from 'react'

export default function Page() {
  async function onSubmit(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault()

    const formData = new FormData(event.currentTarget)
    const response = await fetch('/api/submit', {
      method: 'POST',
      body: formData,
    })

    // Handle response if necessary
    const data = await response.json()
    // ...
  }

  return (
    <form onSubmit={onSubmit}>
      <input type="text" name="name" />
      <button type="submit">Submit</button>
    </form>
  )
}

Good to know
  • API Routes는 CORS header를 지정하지 않습니다. 즉, 기본적으로 same-origin에서만 사용할 수 있습니다.
  • API Routes는 server에서 실행되므로, (API key 같은) 민감한 값을 client에 노출하지 않고 Environment Variables로 사용할 수 있습니다. 이는 애플리케이션의 보안에 매우 중요합니다.
  • API Routes do not specify CORS headers, meaning they are same-origin only by default.
  • Since API Routes run on the server, we're able to use sensitive values (like API keys) through Environment Variables without exposing them to the client. This is critical for the security of your application.

Form validationForm 유효성 검사

기본적인 client-side form validation에는 required, type="email" 같은 HTML validation을 사용하는 것을 권장합니다.

We recommend using HTML validation like required and type="email" for basic client-side form validation.

더 고급 server-side validation이 필요하다면 Zod나 Valibot 같은 schema validation library를 사용해 data를 mutate하기 전에 form field를 검증할 수 있습니다:

For more advanced server-side validation, you can use a schema validation library like Zod or Valibot to validate the form fields before mutating the data:

Error handling에러 처리

form 제출이 실패했을 때 React state를 사용해 error message를 보여 줄 수 있습니다:

You can use React state to show an error message when a form submission fails:

TSJSpages/index.tsx
import React, { useState, SubmitEvent } from 'react'

export default function Page() {
  const [isLoading, setIsLoading] = useState<boolean>(false)
  const [error, setError] = useState<string | null>(null)

  async function onSubmit(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault()
    setIsLoading(true)
    setError(null) // Clear previous errors when a new request starts

    try {
      const formData = new FormData(event.currentTarget)
      const response = await fetch('/api/submit', {
        method: 'POST',
        body: formData,
      })

      if (!response.ok) {
        throw new Error('Failed to submit the data. Please try again.')
      }

      // Handle response if necessary
      const data = await response.json()
      // ...
    } catch (error) {
      // Capture the error message to display to the user
      setError(error.message)
      console.error(error)
    } finally {
      setIsLoading(false)
    }
  }

  return (
    <div>
      {error && <div style={{ color: 'red' }}>{error}</div>}
      <form onSubmit={onSubmit}>
        <input type="text" name="name" required />
        <button type="submit" disabled={isLoading}>
          {isLoading ? 'Loading...' : 'Submit'}
        </button>
      </form>
    </div>
  )
}

RedirectingRedirect하기

mutation 후 사용자를 다른 route로 redirect하고 싶다면, 절대 또는 상대 URL로 redirect할 수 있습니다:

If you would like to redirect the user to a different route after a mutation, you can redirect to any absolute or relative URL:

TSJSpages/api/submit.ts
import type { NextApiRequest, NextApiResponse } from 'next'

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  const id = await addPost()
  res.redirect(307, `/post/${id}`)
}
