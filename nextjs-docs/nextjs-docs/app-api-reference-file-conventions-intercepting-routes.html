Intercepting RoutesIntercepting Route

Intercepting route를 사용하면 애플리케이션의 다른 부분에 있는 route를 현재 layout 안에서 load할 수 있습니다. 이 routing paradigm은 사용자가 다른 context로 전환하지 않은 채로 어떤 route의 content를 보여 주고 싶을 때 유용합니다.

Intercepting routes allows you to load a route from another part of your application within the current layout. This routing paradigm can be useful when you want to display the content of a route without the user switching to a different context.

예를 들어 feed에서 사진을 클릭하면, feed 위에 겹쳐지는 modal로 사진을 보여 줄 수 있습니다. 이 경우 Next.js는 /photo/123 route를 intercept하고, URL을 가린 뒤, /feed 위에 overlay합니다.

For example, when clicking on a photo in a feed, you can display the photo in a modal, overlaying the feed. In this case, Next.js intercepts the /photo/123 route, masks the URL, and overlays it over /feed.

하지만 공유 가능한 URL을 클릭하거나 page를 새로고침해서 사진으로 이동할 때는 modal 대신 사진 page 전체가 render되어야 합니다. 이때는 route interception이 일어나지 않아야 합니다.

However, when navigating to the photo by clicking a shareable URL or by refreshing the page, the entire photo page should render instead of the modal. No route interception should occur.

Convention규칙

Intercepting route는 (..) convention으로 정의할 수 있습니다. 이는 상대 경로 convention인 ../와 비슷하지만 route segment를 대상으로 합니다.

Intercepting routes can be defined with the (..) convention, which is similar to relative path convention ../ but for route segments.

다음을 사용할 수 있습니다:

You can use:

  • (.): 같은 level의 segment와 match
  • (..): 한 level 위의 segment와 match
  • (..)(..): 두 level 위의 segment와 match
  • (...): root app directory부터의 segment와 match
  • (.) to match segments on the same level
  • (..) to match segments one level above
  • (..)(..) to match segments two levels above
  • (...) to match segments from the root app directory

예를 들어 (..)photo directory를 만들면 feed segment 안에서 photo segment를 intercept할 수 있습니다.

For example, you can intercept the photo segment from within the feed segment by creating a (..)photo directory.

Good to know

(..) convention은 file-system이 아니라 route segment 를 기준으로 합니다. 예를 들어 Parallel Routes의 @slot 폴더는 고려하지 않습니다.

The (..) convention is based on route segments, not the file-system. For example, it does not consider @slot folders in Parallel Routes.

Intercepting Routes can be used together with Parallel Routes to create modals. This allows you to solve common challenges when building modals, such as:

  • modal content를 URL로 공유 가능하게 만들기.
  • page를 새로고침했을 때 modal을 닫지 않고 context를 유지하기.
  • 뒤로 가기 navigation 시 이전 route로 이동하는 대신 modal 닫기.
  • 앞으로 가기 navigation 시 modal 다시 열기.
  • Making the modal content shareable through a URL.
  • Preserving context when the page is refreshed, instead of closing the modal.
  • Closing the modal on backwards navigation rather than going to the previous route.
  • Reopening the modal on forwards navigation.
