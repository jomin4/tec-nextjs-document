turbopack.ignoreIssueturbopack.ignoreIssue

turbopack.ignoreIssue option을 사용하면 특정 Turbopack error와 warning을 걸러내 CLI output이나 error overlay에 나타나지 않게 할 수 있습니다. 의도적으로 resolve하지 않은 optional dependency처럼, 애플리케이션에 영향을 주지 않는 알려진 warning을 숨길 때 유용합니다.

The turbopack.ignoreIssue option allows you to filter out specific Turbopack errors and warnings so they do not appear in the CLI output or the error overlay. This is useful for suppressing known warnings that do not affect your application, such as intentionally unresolved optional dependencies.

이 option은 Turbopack을 사용할 때(next dev --turbopack)만 사용할 수 있습니다.

This option is only available when using Turbopack (next dev --turbopack).

Usage사용법

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  turbopack: {
    ignoreIssue: [
      {
        path: '**/vendor/**',
      },
    ],
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  turbopack: {
    ignoreIssue: [
      {
        path: '**/vendor/**',
      },
    ],
  },
}

module.exports = nextConfig

Options

ignoreIssue 배열의 각 rule은 다음 field를 가진 객체입니다:

Each rule in the ignoreIssue array is an object with the following fields:

FieldTypeRequiredDescription
pathstring | RegExpYesissue의 파일 경로와 match됩니다
titlestring | RegExpNoissue title과 match됩니다
descriptionstring | RegExpNoissue description과 match됩니다
FieldTypeRequiredDescription
pathstring | RegExpYesMatches against the file path of the issue
titlestring | RegExpNoMatches against the issue title
descriptionstring | RegExpNoMatches against the issue description

issue가 rule의 path 그리고 지정된 다른 모든 field와 match되면 숨겨집니다. path만 지정하면 match되는 파일에서 나온 모든 issue가 숨겨집니다.

An issue is suppressed when it matches the path and all other specified fields in a rule. If only path is provided, any issue from a matching file is suppressed.

Good to know

issue title과 description은 Turbopack 버전에 따라 바뀔 수 있습니다. path field는 일반적으로 안정적이지만, 모든 issue type에서 일관되게 유지된다고 보장되지는 않습니다. 가능하면 title이나 description matching보다 더 구체적인 path pattern을 사용하는 것이 좋습니다.

Issue titles and descriptions may change between Turbopack versions. The path field is generally stable, but is not guaranteed to remain consistent for all issue types. When possible, prefer using more specific path patterns over title or description matching.

path

issue가 발생한 파일 경로와 match되는 glob pattern(문자열인 경우) 또는 regular expression입니다.

A glob pattern (when a string) or regular expression that matches against the file path where the issue originated.

JSnext.config.js
module.exports = {
  turbopack: {
    ignoreIssue: [
      // Glob pattern: suppress issues from any file under vendor/
      { path: '**/vendor/**' },
      // RegExp: suppress issues from files matching a pattern
      { path: /node_modules\/legacy-lib/ },
    ],
  },
}

title

issue title과 match되는 정확한 문자열 일치(문자열인 경우) 또는 regular expression입니다.

An exact string match (when a string) or regular expression that matches against the issue title.

JSnext.config.js
module.exports = {
  turbopack: {
    ignoreIssue: [
      {
        path: '**/src/**',
        title: 'Module not found',
      },
    ],
  },
}

description

issue description과 match되는 정확한 문자열 일치(문자열인 경우) 또는 regular expression입니다.

An exact string match (when a string) or regular expression that matches against the issue description.

JSnext.config.js
module.exports = {
  turbopack: {
    ignoreIssue: [
      {
        path: '**/src/**',
        description: /Cannot find module 'optional-dep'/,
      },
    ],
  },
}

Examples예시

Suppressing warnings for optional dependenciesoptional dependency의 warning 숨기기

코드에서 optional require() 호출을 try/catch로 감싸고 있다면 Turbopack이 "Module not found" warning을 보고할 수 있습니다. 다음과 같이 숨길 수 있습니다:

If your code uses try/catch around an optional require() call, Turbopack may report a "Module not found" warning. You can suppress it:

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  turbopack: {
    ignoreIssue: [
      {
        path: '**/lib/optional-feature/**',
        title: 'Module not found',
      },
    ],
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  turbopack: {
    ignoreIssue: [
      {
        path: '**/lib/optional-feature/**',
        title: 'Module not found',
      },
    ],
  },
}

module.exports = nextConfig

Combining multiple rules여러 rule 조합하기

여러 rule을 지정해 서로 다른 issue를 숨길 수 있습니다:

You can specify multiple rules to suppress different issues:

JSnext.config.js
module.exports = {
  turbopack: {
    ignoreIssue: [
      { path: '**/vendor/**' },
      { path: '**/legacy/**', title: 'Module not found' },
      { path: /generated\//, description: /expected identifier/ },
    ],
  },
}
