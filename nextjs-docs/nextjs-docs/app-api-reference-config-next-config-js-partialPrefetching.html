partialPrefetchingpartialPrefetching

partialPrefetching은 앱 수준에서 Partial Prefetching을 활성화합니다. framework는 기본적으로 각 route의 static 부분을 prefetch합니다. 더 많이 fetch하려면 개별 link에 prefetch={true}를 설정해 link별 prefetching을 사용하세요.

partialPrefetching enables Partial Prefetching at the app level. The framework prefetches the static parts of each route by default; set prefetch={true} on individual links to use per-link prefetching and fetch more.

Usage사용법

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  cacheComponents: true,
  partialPrefetching: true,
}

export default nextConfig
module.exports = {
  cacheComponents: true,
  partialPrefetching: true,
}

partialPrefetching에는 cacheComponents가 필요합니다. 이것이 없으면 next dev와 next build가 config 검증 단계에서 error를 throw합니다.

partialPrefetching requires cacheComponents. Without it, next dev and next build throw at config validation.

Reference레퍼런스

값설명
true앱 전체에서 Partial Prefetching을 활성화합니다.
falsePartial Prefetching이 나오기 전에 Cache Components를 도입한 앱을 위해 이전 prefetch 동작을 유지합니다.
ValueDescription
trueEnables Partial Prefetching across the app.
falseKeeps the previous prefetch behavior, for apps that adopted Cache Components before Partial Prefetching was available.

option을 설정하지 않으면 false처럼 동작하며, cacheComponents가 활성화되어 있을 때 warning을 log합니다. 다음 major release에서는 두 기능이 모든 곳에서 활성화되고 이 option들은 제거됩니다.

Leaving the option unset behaves like false and logs a warning when cacheComponents is enabled. Both features will be enabled everywhere in the next major release, and the options will be removed.

How prefetches resolveprefetch가 resolve되는 방식

Partial Prefetching 이전에는 Next.js가 보이는 link마다 prefetch했습니다. N개의 route로 가는 N개의 link가 있는 page는 그 link들이 viewport에 들어올 때 약 N개의 route prefetch를 만들었습니다.

Before Partial Prefetching, Next.js prefetched per visible link: a page with N links to N routes produced ~N route prefetches as those links entered the viewport.

partialPrefetching: true를 사용하면 Next.js는 대신 route마다 재사용 가능한 App Shell 하나를 prefetch합니다. App Shell에는 link의 URL에 의존하지 않는 render 결과가 들어 있습니다. params나 searchParams에 의존하는 콘텐츠를 포함한 URL별 콘텐츠는 기본적으로 navigation 후에 resolve됩니다. App Shell은 client에 cache되므로, 같은 route로 가는 link들은 하나의 prefetch를 재사용합니다.

With partialPrefetching: true, Next.js prefetches one reusable App Shell per route instead. The App Shell contains rendered output that does not depend on a link's URL. URL-specific content, including content that depends on params or searchParams, resolves after navigation by default. App Shells are cached on the client, so links to the same route reuse one prefetch.

이 pattern은 single-page app의 route별 code splitting과 비슷합니다. route마다 하나의 artifact가 있고, 그 route를 가리키는 모든 link가 이를 공유합니다.

The pattern is similar to per-route code splitting in single-page apps: one artifact per route, shared by every link that points to it.

Good to know

cookies()나 headers()를 읽는 route는 session data를 포함하는 App Shell을 만듭니다. framework가 이를 자동으로 감지해 client에서 session별로 shell을 cache합니다.

Routes that read cookies() or headers() produce an App Shell that includes session data. The framework auto-detects this and caches the shell per session on the client.

link는 <Link prefetch={true}>로 App Shell보다 더 많은 것을 요청할 수 있습니다. 이 prefetch는 params, searchParams, 전체 URL 같은 URL data와 그 뒤의 cache된 콘텐츠까지 resolve합니다. Optimizing prefetching을 참고하세요.

A link can ask for more than the App Shell with <Link prefetch={true}>. The prefetch also resolves URL data like params, searchParams, and the full URL, and the cached content behind it. See Optimizing prefetching.

Good to know

Partial Prefetching을 opt-in하지 않은 route로 <Link prefetch={true}>를 사용하면, dev console error가 앱 전체에 partialPrefetching을 활성화하거나 segment에 prefetch = 'partial'을 설정하라고 제안합니다. dev warning Insight에서 각 해결 방법을 자세히 다룹니다.

If you use <Link prefetch={true}> to a route that hasn't opted into Partial Prefetching, a dev console error suggests enabling partialPrefetching app-wide or prefetch = 'partial' on the segment. The dev warning Insight covers each fix in detail.

Per-segment overridessegment별 override

명시적인 prefetch 값을 export하는 segment는 해당 route에 대해 앱 수준 기본값을 override합니다.

A segment that exports an explicit prefetch value overrides the app-level default for that route.
