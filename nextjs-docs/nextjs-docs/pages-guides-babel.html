How to configure Babel in Next.jsNext.js에서 Babel 설정하기

예제
  • babel configuration 커스터마이징

Next.js는 앱에 next/babel preset을 포함하며, 여기에는 React 애플리케이션과 server-side 코드를 compile하는 데 필요한 모든 것이 들어 있습니다. 하지만 기본 Babel config를 확장하고 싶다면 그것도 가능합니다.

Next.js includes the next/babel preset to your app, which includes everything needed to compile React applications and server-side code. But if you want to extend the default Babel configs, it's also possible.

Adding Presets and PluginsPreset과 Plugin 추가하기

시작하려면 프로젝트 root directory에 .babelrc 파일(또는 babel.config.js)만 정의하면 됩니다. 이런 파일이 있으면 그 파일이 source of truth(유일한 기준)로 간주되므로, Next.js에 필요한 것, 즉 next/babel preset도 함께 정의해야 합니다.

To start, you only need to define a .babelrc file (or babel.config.js) in the root directory of your project. If such a file is found, it will be considered as the source of truth, and therefore it needs to define what Next.js needs as well, which is the next/babel preset.

다음은 .babelrc 파일 예시입니다:

Here's an example .babelrc file:

.babelrc
{
  "presets": ["next/babel"],
  "plugins": []
}

next/babel에 포함된 preset에 대해 알아보려면 이 파일을 살펴보세요.

You can take a look at this file to learn about the presets included by next/babel.

preset/plugin을 별도 설정 없이 추가하려면 다음과 같이 하면 됩니다:

To add presets/plugins without configuring them, you can do it this way:

.babelrc
{
  "presets": ["next/babel"],
  "plugins": ["@babel/plugin-proposal-do-expressions"]
}

Customizing Presets and PluginsPreset과 Plugin 커스터마이징하기

preset/plugin을 custom configuration과 함께 추가하려면 다음과 같이 next/babel preset에서 설정하세요:

To add presets/plugins with custom configuration, do it on the next/babel preset like so:

.babelrc
{
  "presets": [
    [
      "next/babel",
      {
        "preset-env": {},
        "transform-runtime": {},
        "styled-jsx": {},
        "class-properties": {}
      }
    ]
  ],
  "plugins": []
}

각 config에서 사용할 수 있는 option에 대해 더 알아보려면 babel 문서 사이트를 방문하세요.

To learn more about the available options for each config, visit babel's documentation site.

Good to know
  • Next.js는 server-side compilation에 current Node.js 버전을 사용합니다.
  • "preset-env"의 modules option은 false로 유지해야 합니다. 그렇지 않으면 webpack code splitting이 꺼집니다.
  • Next.js uses the current Node.js version for server-side compilations.
  • The modules option on "preset-env" should be kept to false, otherwise webpack code splitting is turned off.
