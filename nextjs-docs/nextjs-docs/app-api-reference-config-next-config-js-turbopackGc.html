turbopackGcexperimentalturbopackGc

experimental.turbopackGc option은 Turbopack의 in-memory cache와 persistent cache에 대한 garbage collection을 활성화합니다.

The experimental.turbopackGc option enables garbage collection for Turbopack's in-memory and persistent caches.

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    turbopackGc: true,
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    turbopackGc: true,
  },
}

module.exports = nextConfig

Reference레퍼런스

turbopackGc의 기본값은 false이며 boolean 또는 객체를 받습니다:

turbopackGc defaults to false and accepts a boolean or an object:

ValueDescription
falsegarbage collection을 비활성화합니다.
true기본 timing으로 garbage collection을 활성화합니다.
{ minProgressMs?, rootTtlMs? }garbage collection을 활성화하고 기본 timing 중 하나 이상을 override합니다.
ValueDescription
falseDisables garbage collection.
trueEnables garbage collection with the default timings.
{ minProgressMs?, rootTtlMs? }Enables garbage collection and overrides one or more of the default timings.

활성화하면 Turbopack은 memory와 persistent cache에서 도달할 수 없는 작업을 제거합니다. 이 option은 Turbopack을 사용하는 next dev와 next build 모두에 적용됩니다.

When enabled, Turbopack removes unreachable work from memory and its persistent cache. The option applies to both next dev and next build when they use Turbopack.

Good to know
  • garbage collection에는 Turbopack FileSystem Cache가 필요합니다. 현재 command에서 cache가 비활성화되어 있으면 이 option은 아무 효과가 없습니다.
  • 오래 실행되는 read-write session에서는 turbopackMemoryEviction이 false로 설정되어 있으면 Turbopack이 garbage collection을 비활성화합니다.
  • Garbage collection requires the Turbopack FileSystem Cache. The option has no effect when the cache is disabled for the current command.
  • In long-running read-write sessions, Turbopack disables garbage collection when turbopackMemoryEviction is set to false.

Options

객체 형식은 다음 property를 받습니다:

The object form accepts the following properties:

PropertyTypeDefaultDescription
minProgressMs음수가 아닌 number100garbage collection pass가 중단 요청을 받아들이기 전에 최소한으로 실행되는 시간입니다.
rootTtlMs음수가 아닌 number259200000 (3일)garbage collection root가 anchor되지 않은 상태로 남아 있을 수 있는 시간으로, 이 시간이 지나면 Turbopack이 제거합니다.
PropertyTypeDefaultDescription
minProgressMsNon-negative number100Minimum time a garbage collection pass runs before it honors an interruption.
rootTtlMsNon-negative number259200000 (3 days)Time a garbage collection root can remain unanchored before Turbopack removes it.

다음 configuration은 garbage collection pass가 양보(yield)하기 전에 최소 200밀리초 동안 실행되도록 하고, anchor되지 않은 root를 하루 뒤에 만료시킵니다:

The following configuration lets a garbage collection pass run for at least 200 milliseconds before yielding and expires unanchored roots after one day:

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    turbopackGc: {
      minProgressMs: 200,
      rootTtlMs: 24 * 60 * 60 * 1000,
    },
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    turbopackGc: {
      minProgressMs: 200,
      rootTtlMs: 24 * 60 * 60 * 1000,
    },
  },
}

module.exports = nextConfig
