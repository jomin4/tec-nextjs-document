useParamsuseParams

useParams는 현재 URL로 채워진 route의 dynamic params를 읽을 수 있게 해 주는 hook입니다.

useParams is a hook that lets you read a route's dynamic params filled in by the current URL.

TSJSpages/shop/[slug].tsx
import { useParams } from 'next/navigation'

export default function ShopPage() {
  const params = useParams<{ slug: string }>()

  if (!params) {
    // Render fallback UI while params are not yet available
    return null
  }

  // Route -> /shop/[slug]
  // URL -> /shop/shoes
  // `params` -> { slug: 'shoes' }
  return <>Shop: {params.slug}</>
}

}

Parameters

const params = useParams()

useParams는 parameter를 받지 않습니다.

useParams does not take any parameters.

Returns

useParams는 현재 route의 채워진 dynamic parameter를 담은 object를 반환하며, prerendering 중에는 null을 반환합니다.

useParams returns an object containing the current route's filled in dynamic parameters, or null during prerendering.

  • object의 각 property는 활성화된 dynamic segment입니다.
  • property 이름은 segment의 이름이고, property 값은 그 segment에 채워진 값입니다.
  • property 값은 dynamic segment의 종류에 따라 string 또는 string 배열입니다.
  • route에 dynamic parameter가 없으면 useParams는 빈 object를 반환합니다.
  • Each property in the object is an active dynamic segment.
  • The property name is the segment's name, and the property value is what the segment is filled in with.
  • The property value will either be a string or array of strings depending on the type of dynamic segment.
  • If the route contains no dynamic parameters, useParams returns an empty object.

예를 들면 다음과 같습니다:

For example:

RouteURLuseParams()
pages/shop/page.js/shop{}
pages/shop/[slug].js/shop/1{ slug: '1' }
pages/shop/[tag]/[item].js/shop/1/2{ tag: '1', item: '2' }
pages/shop/[...slug].js/shop/1/2{ slug: ['1', '2'] }

pages/shop/[slug].js/shop/1{ slug: '1' }

Good to know

useParams는 React Hook이므로 class와 함께 사용할 수 없습니다.

useParams is a React Hook and cannot be used with classes.

Behavior동작

Behavior during prerenderingprerendering 중 동작

statically optimized된 page에서는 useParams가 초기 render 시 null을 반환합니다. hydration 이후 router가 준비되면 값이 실제 params로 업데이트됩니다.

For pages that are statically optimized, useParams will return null on the initial render. After hydration, the value will be updated to the actual params once the router is ready.

dynamic route의 static generation 중에는 params를 알 수 없기 때문입니다.

This is because params cannot be known during static generation for dynamic routes.

TSJSpages/shop/[slug].tsx
import { useParams } from 'next/navigation'

export default function ShopPage() {
  const params = useParams<{ slug: string }>()

  if (!params) {
    // Return a fallback UI while params are loading
    // This prevents hydration mismatches
    return <ShopPageSkeleton />
  }

  return <>Shop: {params.slug}</>
}
import { useParams } from 'next/navigation'

export default function ShopPage() {
  const params = useParams()

  if (!params) {
    // Return a fallback UI while params are loading
    // This prevents hydration mismatches
    return <ShopPageSkeleton />
  }

  return <>Shop: {params.slug}</>
}

Using with getServerSidePropsgetServerSideProps와 함께 사용하기

getServerSideProps를 사용하면 page가 매 request마다 server-render되므로 useParams는 실제 params를 즉시 반환합니다:

When using getServerSideProps, the page is server-rendered on each request and useParams will return the actual params immediately:

TSJSpages/shop/[slug].tsx
import { useParams } from 'next/navigation'

export default function ShopPage() {
  const params = useParams<{ slug: string }>()

  // With getServerSideProps, this fallback is never rendered because
  // params is always available on the server. However, keeping
  // the fallback allows this component to be reused on other pages
  // that may not use getServerSideProps.
  if (!params) {
    return null
  }

  return <>Shop: {params.slug}</>
}

export async function getServerSideProps() {
  return { props: {} }
}
import { useParams } from 'next/navigation'

export default function ShopPage() {
  const params = useParams()

  // With getServerSideProps, this fallback is never rendered because
  // params is always available on the server. However, keeping
  // the fallback allows this component to be reused on other pages
  // that may not use getServerSideProps.

    return null
  }

  return <>Shop: {params.slug}</>
}

export async function getServerSideProps() {
  return { props: {} }
}

Comparison with router.queryrouter.query와의 비교

useParams는 dynamic route parameter만 반환하는 반면, useRouter의 router.query는 dynamic parameter와 query string parameter를 모두 포함합니다.

useParams only returns the dynamic route parameters, whereas router.query from useRouter includes both dynamic parameters and query string parameters.

TSJSpages/shop/[slug].tsx
import { useRouter } from 'next/router'
import { useParams } from 'next/navigation'

export default function ShopPage() {
  const router = useRouter()
  const params = useParams()

  // URL -> /shop/shoes?color=red

  // router.query -> { slug: 'shoes', color: 'red' }
  // params -> { slug: 'shoes' }

  // ...
}
import { useRouter } from 'next/router'
import { useParams } from 'next/navigation'

export default function ShopPage() {
  const router = useRouter()
  const params = useParams()

  // URL -> /shop/shoes?color=red

  // router.query -> { slug: 'shoes', color: 'red' }
  // params -> { slug: 'shoes' }

  // ...
}

Sharing components with App RouterApp Router와 component 공유하기

next/navigation의 useParams는 Pages Router와 App Router 모두에서 동작합니다. 그래서 어느 쪽 context에서도 동작하는 공유 component를 만들 수 있습니다:

useParams from next/navigation works in both the Pages Router and App Router. This allows you to create shared components that work in either context:

TSJScomponents/breadcrumb.tsx
import { useParams } from 'next/navigation'

// This component works in both pages/ and app/
export function Breadcrumb() {
  const params = useParams<{ slug: string }>()

  if (!params) {
    // Fallback for Pages Router during prerendering
    return <nav>Home / ...</nav>
  }

  return <nav>Home / {params.slug}</nav>
}
import { useParams } from 'next/navigation'

// This component works in both pages/ and app/
export function Breadcrumb() {
  const params = useParams()

  if (!params) {
    // Fallback for Pages Router during prerendering
    return <nav>Home / ...</nav>
  }

  return <nav>Home / {params.slug}</nav>
}
Good to know

이 component를 App Router에서 사용하면 useParams가 절대 null을 반환하지 않으므로 fallback 분기는 render되지 않습니다.

When using this component in the App Router, useParams never returns null, so the fallback branch will not be rendered.
