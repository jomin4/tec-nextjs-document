Testing테스트

React와 Next.js에서는 몇 가지 다른 유형의 test를 작성할 수 있으며, 각각 고유한 목적과 사용 사례가 있습니다. 이 페이지는 애플리케이션을 test하는 데 사용할 수 있는 test 유형과 자주 쓰이는 도구를 개괄합니다.

In React and Next.js, there are a few different types of tests you can write, each with its own purpose and use cases. This page provides an overview of types and commonly used tools you can use to test your application.

Types of teststest 유형

  • Unit Testing은 개별 unit(또는 코드 블록)을 고립된 상태로 test하는 것입니다. React에서 unit은 하나의 function, hook, 또는 component일 수 있습니다.
  • Component Testing은 unit testing을 더 좁힌 형태로, test의 주된 대상이 React component입니다. component가 어떻게 render되는지, props와 어떻게 상호작용하는지, 사용자 event에 어떻게 반응하는지 등을 test할 수 있습니다.
  • Integration Testing은 여러 unit이 함께 어떻게 동작하는지 test하는 것입니다. component, hook, function의 조합일 수 있습니다.
  • End-to-End (E2E) Testing은 브라우저처럼 실제 사용자 시나리오를 시뮬레이션하는 환경에서 사용자 흐름을 test하는 것입니다. 즉 production과 비슷한 환경에서 특정 작업(예: 회원가입 흐름)을 test합니다.
  • Snapshot Testing은 component의 render 결과를 캡처해 snapshot 파일로 저장하는 것입니다. test가 실행되면 component의 현재 render 결과를 저장된 snapshot과 비교합니다. snapshot의 변경은 동작이 예상치 않게 바뀌었음을 나타내는 데 사용됩니다.
  • Unit Testing involves testing individual units (or blocks of code) in isolation. In React, a unit can be a single function, hook, or component.
  • Component Testing is a more focused version of unit testing where the primary subject of the tests is React components. This may involve testing how components are rendered, their interaction with props, and their behavior in response to user events.
  • Integration Testing involves testing how multiple units work together. This can be a combination of components, hooks, and functions.
  • End-to-End (E2E) Testing involves testing user flows in an environment that simulates real user scenarios, like the browser. This means testing specific tasks (e.g. signup flow) in a production-like environment.
  • Snapshot Testing involves capturing the rendered output of a component and saving it to a snapshot file. When tests run, the current rendered output of the component is compared against the saved snapshot. Changes in the snapshot are used to indicate unexpected changes in behavior.

Async Server Components

async Server Component는 React ecosystem에서 새로운 개념이라 일부 도구는 이를 완전히 지원하지 않습니다. 당분간은 async component에 대해 Unit Testing보다 End-to-End Testing을 사용하는 것을 권장합니다.

Since async Server Components are new to the React ecosystem, some tools do not fully support them. In the meantime, we recommend using End-to-End Testing over Unit Testing for async components.
