cacheLifecacheLife

cacheLife option을 사용하면 component나 function 안에서, 그리고 use cache directive의 scope 안에서 cacheLife function을 사용할 때 쓸 custom cache profiles 항목을 정의할 수 있습니다.

The cacheLife option allows you to define custom cache profiles when using the cacheLife function inside components or functions, and within the scope of the use cache directive.

Usage사용법

profile을 정의하려면 cacheComponents flag를 활성화하고 next.config.js 파일의 cacheLife object에 cache profile을 추가하세요. 예를 들어 blog profile은 다음과 같습니다:

To define a profile, enable the cacheComponents flag and add the cache profile in the cacheLife object in the next.config.js file. For example, a blog profile:

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  cacheComponents: true,
  cacheLife: {
    blog: {
      stale: 3600, // 1 hour
      revalidate: 900, // 15 minutes
      expire: 86400, // 1 day
    },
  },
}

export default nextConfig
module.exports = {
  cacheComponents: true,
  cacheLife: {
    blog: {
      stale: 3600, // 1 hour
      revalidate: 900, // 15 minutes
      expire: 86400, // 1 day
    },
  },
}

이제 이 custom blog configuration을 component나 function에서 다음과 같이 사용할 수 있습니다:

You can now use this custom blog configuration in your component or function as follows:

TSJSapp/actions.ts
import { cacheLife } from 'next/cache'

export async function getCachedData() {
  'use cache'
  cacheLife('blog')
  const res = await fetch('https://api.example.com/data')
  const data = await res.json()
  return data
}
import { cacheLife } from 'next/cache'

export async function getCachedData() {
  'use cache'
  cacheLife('blog')
  const res = await fetch('https://api.example.com/data')
  const data = await res.json()
  return data
}

같은 이름(default, seconds, minutes, hours, days, weeks, max)으로 profile을 정의하여 built-in profile을 override할 수도 있습니다. Overriding the default cache profiles를 참고하세요.

You can also override a built-in profile by defining one with the same name (default, seconds, minutes, hours, days, weeks, or max). See Overriding the default cache profiles.

Reference레퍼런스

configuration object는 다음 형식의 key 값을 가집니다:

The configuration object has key values with the following format:

PropertyValueDescriptionRequirement
stalenumberclient가 server를 확인하지 않고 value를 cache하는 기간.Optional
revalidatenumberserver에서 cache를 refresh하는 빈도. revalidate하는 동안 stale value가 제공될 수 있습니다.Optional
expirenumbervalue가 dynamic으로 전환되기 전까지 stale 상태로 유지될 수 있는 최대 기간.Optional - revalidate보다 길어야 합니다
PropertyValueDescriptionRequirement
stalenumberDuration the client should cache a value without checking the server.Optional
revalidatenumberFrequency at which the cache should refresh on the server; stale values may be served while revalidating.Optional
expirenumberMaximum duration for which a value can remain stale before switching to dynamic.Optional - Must be longer than revalidate
