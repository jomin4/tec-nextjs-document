Supported Browsers지원 브라우저

Next.js는 별도 설정 없이(zero configuration) 최신 브라우저를 지원합니다.

Next.js supports modern browsers with zero configuration.

  • Chrome 111+
  • Edge 111+
  • Firefox 111+
  • Safari 16.4+
  • Chrome 111+
  • Edge 111+
  • Firefox 111+
  • Safari 16.4+

Browserslist

특정 브라우저나 기능을 target으로 지정하고 싶다면, Next.js는 package.json 파일의 Browserslist configuration을 지원합니다. Next.js는 기본적으로 다음 Browserslist configuration을 사용합니다:

If you would like to target specific browsers or features, Next.js supports Browserslist configuration in your package.json file. Next.js uses the following Browserslist configuration by default:

package.json
{
  "browserslist": ["chrome 111", "edge 111", "firefox 111", "safari 16.4"]
}

Polyfills

다음을 포함한 널리 사용되는 polyfill을 주입합니다:

We inject widely used polyfills, including:

  • fetch() — 대체 대상: whatwg-fetch와 unfetch.
  • URL — 대체 대상: url package (Node.js API).
  • Object.assign() — 대체 대상: object-assign, object.assign, core-js/object/assign.
  • fetch() — Replacing: whatwg-fetch and unfetch.
  • URL — Replacing: the url package (Node.js API).
  • Object.assign() — Replacing: object-assign, object.assign, and core-js/object/assign.

dependency 중에 이 polyfill들을 포함하는 것이 있다면, 중복을 피하기 위해 production build에서 자동으로 제거됩니다.

If any of your dependencies include these polyfills, they’ll be eliminated automatically from the production build to avoid duplication.

또한 bundle 크기를 줄이기 위해, Next.js는 이 polyfill이 필요한 브라우저에서만 polyfill을 load합니다. 전 세계 웹 트래픽의 대부분은 이 polyfill을 다운로드하지 않습니다.

In addition, to reduce bundle size, Next.js will only load these polyfills for browsers that require them. The majority of the web traffic globally will not download these polyfills.

Custom PolyfillsCustom polyfill

직접 작성한 코드나 외부 npm dependency가 target 브라우저(예: IE 11)에서 지원하지 않는 기능을 필요로 한다면, polyfill을 직접 추가해야 합니다.

If your own code or any external npm dependencies require features not supported by your target browsers (such as IE 11), you need to add polyfills yourself.

In App RouterApp Router에서

polyfill을 포함하려면 instrumentation-client.js 파일에서 import하면 됩니다.

To include polyfills, you can import them into the instrumentation-client.js file.

TSinstrumentation-client.ts
import './polyfills'

In Pages RouterPages Router에서

이 경우 Custom <App>이나 개별 component에서 필요한 특정 polyfill을 top-level import로 추가해야 합니다.

In this case, you should add a top-level import for the specific polyfill you need in your Custom <App> or the individual component.

TSJSpages/_app.tsx
import './polyfills'

import type { AppProps } from 'next/app'

export default function MyApp({ Component, pageProps }: AppProps) {
  return <Component {...pageProps} />
}
import './polyfills'

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}

Conditionally loading polyfillspolyfill 조건부 load

가장 좋은 방법은 지원되지 않는 기능을 특정 UI 영역으로 격리하고, 필요한 경우에만 polyfill을 조건부로 load하는 것입니다.

The best approach is to isolate unsupported features to specific UI sections and conditionally load the polyfill if needed.

TSJShooks/analytics.ts
import { useCallback } from 'react'

export const useAnalytics = () => {
  const tracker = useCallback(async (data: unknown) => {
    if (!('structuredClone' in globalThis)) {
      const mod = await import('polyfills/structured-clone')
      globalThis.structuredClone = mod.default
    }

    /* Do some work that uses structured clone */
  }, [])

  return tracker
}

JavaScript Language FeaturesJavaScript 언어 기능

Next.js에서는 최신 JavaScript 기능을 별도 설정 없이 사용할 수 있습니다. ES6 기능 외에도 Next.js는 다음을 지원합니다:

Next.js allows you to use the latest JavaScript features out of the box. In addition to ES6 features, Next.js also supports:

  • Async/await (ES2017)
  • Object Rest/Spread Properties (ES2018)
  • Dynamic import() (ES2020)
  • Optional Chaining (ES2020)
  • Nullish Coalescing (ES2020)
  • Class Fields와 Static Properties (ES2022)
  • 그 밖에도 더 있습니다!
