agentUpgradeexperimentalagentUpgrade

experimental.agentUpgrade option은 next upgrade --agent의 기본 policy를 선택하고, next dev와 next build 중의 upgrade reminder를 제어합니다. 기본적으로 security policy를 사용합니다.

The experimental.agentUpgrade option selects the default policy for next upgrade --agent and controls upgrade reminders during next dev and next build. It uses the security policy by default.

TSJSnext.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    agentUpgrade: 'latest',
  },
}

export default nextConfig
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    agentUpgrade: 'latest',
  },
}

module.exports = nextConfig

이 option은 다음 값을 받습니다:

The option accepts these values:

ValueBehavior
falseupgrade reminder를 비활성화합니다.
security (default)stable 설치본에 security advisory가 있는지 확인하고, 안전한 upgrade가 있으면 이를 권장합니다.
latest앱의 현재 stable 또는 canary channel에서 더 새로운 major 또는 minor release를 권장합니다.
experimental-futurelatest policy를 사용하며, 적용 가능한 Future Defaults도 함께 권장합니다.
ValueBehavior
falseDisables upgrade reminders.
security (default)Checks stable installations for security advisories and recommends a safe upgrade when one is available.
latestRecommends a newer major or minor release on the app's current stable or canary channel.
experimental-futureUses the latest policy and also recommends applicable Future Defaults.

이 option은 앱을 자동으로 upgrade하지 않습니다. reminder와, next upgrade --agent에 값이 포함되지 않았을 때 사용되는 policy만 제어합니다.

The option does not upgrade the app automatically. It only controls reminders and the policy used when next upgrade --agent does not include a value.

Reminder behaviorReminder 동작

interactive terminal에서는 next dev 또는 next build 중에 조건에 맞는 reminder가 다음 action을 제시합니다. 사용자가 결정하는 동안 command는 prompt 뒤에서 계속 실행되며 output을 buffer에 저장합니다.

In an interactive terminal, an eligible reminder during next dev or next build offers these actions. The command continues behind the prompt and buffers its output while you decide.

  • Upgrade now는 현재 command를 중지하고 설정된 policy로 next upgrade --agent를 시작합니다.
  • Skip은 실행 중인 command로 돌아가 buffer에 저장된 output을 다시 출력합니다.
  • Skip until next version은 설치된 버전과 policy에 대해 dismiss 상태를 저장합니다.
  • Upgrade now stops the current command and starts next upgrade --agent with the configured policy.
  • Skip returns to the running command and replays its buffered output.
  • Skip until next version saves the dismissal for the installed version and policy.

10초 안에 선택하지 않거나 buffer에 저장된 output이 약 10 MiB를 넘으면 reminder는 자동으로 skip됩니다.

If you don't choose within ten seconds, or the buffered output grows past about 10 MiB, the reminder skips automatically.

coding agent가 next dev 또는 next build를 실행하면, 처음 조건에 맞는 reminder가 upgrade를 보고하라는 지침과 함께 command를 중지합니다. 같은 command를 곧바로 다시 실행하면 warning과 함께 원래 작업이 계속됩니다.

When a coding agent runs next dev or next build, the first eligible reminder stops the command with instructions to report the upgrade. Retrying the same command promptly continues the original task with a warning.

next dev가 coding agent를 감지하면 AGENTS.md에 별도의 managed upgrade block도 작성합니다. 이 block은 설치된 CLI의 reminder 처리를 위임합니다:

When next dev detects a coding agent, it also writes a separate managed upgrade block to AGENTS.md. This block delegates handling of the installed CLI's reminders:

AGENTS.md
<!-- BEGIN:nextjs-agent-upgrade -->

## Next.js upgrade reminders

Upgrade reminders emitted by this project's installed Next.js CLI during `next dev` or `next build` are part of the `experimental.agentUpgrade` workflow. Follow these reminders' instructions while respecting user instructions declining upgrades.

<!-- END:nextjs-agent-upgrade -->

experimental.agentUpgrade: false로 설정하면 agent가 감지되지 않더라도 다음 next dev 실행 시 이 block이 제거됩니다. documentation rules(agentRules)와 feedback 지침(experimental.agentFeedback)은 독립적으로 유지됩니다. create-next-app은 기본 security policy를 사용하는 새 앱에 upgrade block을 포함합니다.

Setting experimental.agentUpgrade: false removes this block on the next next dev run, even when no agent is detected. Documentation rules (agentRules) and feedback instructions (experimental.agentFeedback) remain independent. create-next-app includes the upgrade block for new apps using the default security policy.

reminder가 동작하려면 설치된 Next.js 버전이 experimental.agentUpgrade를 지원해야 합니다. 현재 canary upgrade CLI를 실행해도 이전 버전 설치본에는 reminder가 추가되지 않습니다.

Reminders require the installed Next.js version to support experimental.agentUpgrade. Running the current canary upgrade CLI does not add reminders to an older installation.

next dev 중에 설치된 버전이 알려진 security vulnerability의 영향을 받는 경우, Next.js DevTools는 Vulnerability Insight도 표시할 수 있습니다. 이 insight는 coding agent로 security upgrade를 시작할 수 있는 복사 가능한 prompt를 제공합니다.

During next dev, Next.js DevTools can also show a Vulnerability Insight when the installed version is affected by a known security vulnerability. The insight provides a copyable prompt for starting a security upgrade with a coding agent.
