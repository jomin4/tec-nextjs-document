draftModedraftMode

draftMode는 Draft Mode를 활성화·비활성화하고, Server Component에서 Draft Mode가 활성화되어 있는지 확인할 수 있게 해 주는 async 함수입니다.

draftMode is an async function allows you to enable and disable Draft Mode, as well as check if Draft Mode is enabled in a Server Component.

TSJSapp/page.ts
import { draftMode } from 'next/headers'

export default async function Page() {
  const { isEnabled } = await draftMode()
}
import { draftMode } from 'next/headers'

export default async function Page() {
  const { isEnabled } = await draftMode()
}

Reference

다음 method와 property를 사용할 수 있습니다:

The following methods and properties are available:

MethodDescription
isEnabledDraft Mode가 활성화되어 있는지 나타내는 boolean 값입니다.
enable()Route Handler에서 cookie(__prerender_bypass)를 설정해 Draft Mode를 활성화합니다.
disable()Route Handler에서 cookie를 삭제해 Draft Mode를 비활성화합니다.
MethodDescription
isEnabledA boolean value that indicates if Draft Mode is enabled.
enable()Enables Draft Mode in a Route Handler by setting a cookie (__prerender_bypass).
disable()Disables Draft Mode in a Route Handler by deleting a cookie.

Good to know

  • draftMode는 promise를 반환하는 asynchronous 함수입니다. async/await나 React의 use 함수를 사용해야 합니다.
    • 버전 14 이하에서 draftMode는 synchronous 함수였습니다. 하위 호환성을 위해 Next.js 15에서도 여전히 synchronous하게 접근할 수 있지만, 이 동작은 앞으로 deprecated될 예정입니다.
  • next build를 실행할 때마다 새로운 bypass cookie 값이 생성됩니다. 이렇게 해서 bypass cookie를 추측할 수 없도록 합니다.
  • HTTP로 로컬에서 Draft Mode를 테스트하려면 브라우저가 third-party cookie와 local storage 접근을 허용해야 합니다.
  • isEnabled는 caching directive scope 안에서 읽을 수 있습니다. cookies(), headers() 같은 다른 runtime API는 Draft Mode가 활성화되어 있더라도 caching directive scope 안에서 사용할 수 없습니다.
  • caching directive scope 안에서 enable()이나 disable()을 호출하면 error가 발생합니다.
  • Draft Mode가 활성화되면 caching directive scope 아래의 모든 함수와 component가 매 request마다 다시 실행되며, 결과는 cache에 저장되지 않습니다. 이렇게 해서 draft 콘텐츠가 항상 최신 상태로 유지됩니다.
  • draftMode is an asynchronous function that returns a promise. You must use async/await or React’s use function.
    • In version 14 and earlier, draftMode was a synchronous function. To help with backwards compatibility, you can still access it synchronously in Next.js 15, but this behavior will be deprecated in the future.
  • A new bypass cookie value will be generated each time you run next build. This ensures that the bypass cookie can’t be guessed.
  • To test Draft Mode locally over HTTP, your browser will need to allow third-party cookies and local storage access.
  • isEnabled is readable inside a caching directive scope. Other runtime APIs like cookies() and headers() are not allowed inside caching directive scopes, even when Draft Mode is active.
  • Calling enable() or disable() inside a caching directive scope will throw an error.
  • When Draft Mode is enabled, all functions and components under a caching directive scope re-execute on every request and results are not saved to the cache. This ensures draft content is always fresh.

Examples예제

Enabling Draft ModeDraft Mode 활성화하기

Draft Mode를 활성화하려면 새 Route Handler를 만들고 enable() method를 호출하세요:

To enable Draft Mode, create a new Route Handler and call the enable() method:

TSJSapp/draft/route.ts
import { draftMode } from 'next/headers'

export async function GET(request: Request) {
  const draft = await draftMode()
  draft.enable()
  return new Response('Draft mode is enabled')
}
import { draftMode } from 'next/headers'

export async function GET(request) {
  const draft = await draftMode()
  draft.enable()
  return new Response('Draft mode is enabled')
}

Disabling Draft ModeDraft Mode 비활성화하기

기본적으로 Draft Mode session은 브라우저를 닫으면 종료됩니다.

By default, the Draft Mode session ends when the browser is closed.

Draft Mode를 수동으로 비활성화하려면 Route Handler에서 disable() method를 호출하세요:

To disable Draft Mode manually, call the disable() method in your Route Handler:

TSJSapp/draft/route.ts
import { draftMode } from 'next/headers'

export async function GET(request: Request) {
  const draft = await draftMode()
  draft.disable()
  return new Response('Draft mode is disabled')
}
import { draftMode } from 'next/headers'

export async function GET(request) {
  const draft = await draftMode()
  draft.disable()
  return new Response('Draft mode is disabled')
}

그런 다음 request를 보내 Route Handler를 호출하세요. <Link> component로 route를 호출한다면, prefetch 시 실수로 cookie가 삭제되지 않도록 prefetch={false}를 전달해야 합니다.

Then, send a request to invoke the Route Handler. If calling the route using the <Link> component, you must pass prefetch={false} to prevent accidentally deleting the cookie on prefetch.

Checking if Draft Mode is enabledDraft Mode 활성화 여부 확인하기

Server Component에서 isEnabled property로 Draft Mode가 활성화되어 있는지 확인할 수 있습니다:

You can check if Draft Mode is enabled in a Server Component with the isEnabled property:

TSJSapp/page.ts
import { draftMode } from 'next/headers'

export default async function Page() {
  const { isEnabled } = await draftMode()
  return (
    <main>
      <h1>My Blog Post</h1>
      <p>Draft Mode is currently {isEnabled ? 'Enabled' : 'Disabled'}</p>
    </main>
  )
}
import { draftMode } from 'next/headers'

export default async function Page() {
  const { isEnabled } = await draftMode()
  return (
    <main>
      <h1>My Blog Post</h1>
      <p>Draft Mode is currently {isEnabled ? 'Enabled' : 'Disabled'}</p>
    </main>
  )
}
