Dynamic RoutesDynamic Route

segment 이름을 미리 정확히 알 수 없고 dynamic data로 route를 만들고 싶다면, request 시점에 채워지거나 build 시점에 prerender되는 Dynamic Segment를 사용할 수 있습니다.

When you don't know the exact segment names ahead of time and want to create routes from dynamic data, you can use Dynamic Segments that are filled in at request time or prerendered at build time.

Convention

Dynamic Segment는 파일 또는 폴더 이름을 대괄호로 감싸서 만들 수 있습니다: [segmentName]. 예: [id] 또는 [slug].

A Dynamic Segment can be created by wrapping a file or folder name in square brackets: [segmentName]. For example, [id] or [slug].

Dynamic Segment는 useRouter로 접근할 수 있습니다.

Dynamic Segments can be accessed from useRouter.

Example예시

예를 들어 블로그에 pages/blog/[slug].js route를 둘 수 있으며, 여기서 [slug]는 블로그 글을 위한 Dynamic Segment입니다.

For example, a blog could include the following route pages/blog/[slug].js where [slug] is the Dynamic Segment for blog posts.

import { useRouter } from 'next/router'

export default function Page() {
  const router = useRouter()
  return <p>Post: {router.query.slug}</p>
}
Route예시 URLparams
pages/blog/[slug].js/blog/a{ slug: 'a' }
pages/blog/[slug].js/blog/b{ slug: 'b' }
pages/blog/[slug].js/blog/c{ slug: 'c' }
RouteExample URLparams
pages/blog/[slug].js/blog/a{ slug: 'a' }
pages/blog/[slug].js/blog/b{ slug: 'b' }
pages/blog/[slug].js/blog/c{ slug: 'c' }

Catch-all SegmentsCatch-all Segment

대괄호 안에 줄임표를 추가하면([...segmentName]) Dynamic Segment를 확장해 이후의 segment를 모두 catch하도록 만들 수 있습니다.

Dynamic Segments can be extended to catch-all subsequent segments by adding an ellipsis inside the brackets [...segmentName].

예를 들어 pages/shop/[...slug].js는 /shop/clothes뿐 아니라 /shop/clothes/tops, /shop/clothes/tops/t-shirts 등에도 match됩니다.

For example, pages/shop/[...slug].js will match /shop/clothes, but also /shop/clothes/tops, /shop/clothes/tops/t-shirts, and so on.

Route예시 URLparams
pages/shop/[...slug].js/shop/a{ slug: ['a'] }
pages/shop/[...slug].js/shop/a/b{ slug: ['a', 'b'] }
pages/shop/[...slug].js/shop/a/b/c{ slug: ['a', 'b', 'c'] }
RouteExample URLparams
pages/shop/[...slug].js/shop/a{ slug: ['a'] }
pages/shop/[...slug].js/shop/a/b{ slug: ['a', 'b'] }
pages/shop/[...slug].js/shop/a/b/c{ slug: ['a', 'b', 'c'] }

Optional Catch-all SegmentsOptional Catch-all Segment

parameter를 이중 대괄호로 감싸면([[...segmentName]]) Catch-all Segment를 optional로 만들 수 있습니다.

Catch-all Segments can be made optional by including the parameter in double square brackets: [[...segmentName]].

예를 들어 pages/shop/[[...slug]].js는 /shop/clothes, /shop/clothes/tops, /shop/clothes/tops/t-shirts에 더해 /shop에도 함께 match됩니다.

For example, pages/shop/[[...slug]].js will also match /shop, in addition to /shop/clothes, /shop/clothes/tops, /shop/clothes/tops/t-shirts.

catch-all segment와 optional catch-all segment의 차이는, optional의 경우 parameter가 없는 route(위 예시의 /shop)도 match된다는 점입니다.

The difference between catch-all and optional catch-all segments is that with optional, the route without the parameter is also matched (/shop in the example above).

Route예시 URLparams
pages/shop/[[...slug]].js/shop{ slug: undefined }
pages/shop/[[...slug]].js/shop/a{ slug: ['a'] }
pages/shop/[[...slug]].js/shop/a/b{ slug: ['a', 'b'] }
pages/shop/[[...slug]].js/shop/a/b/c{ slug: ['a', 'b', 'c'] }
RouteExample URLparams
pages/shop/[[...slug]].js/shop{ slug: undefined }
pages/shop/[[...slug]].js/shop/a{ slug: ['a'] }
pages/shop/[[...slug]].js/shop/a/b{ slug: ['a', 'b'] }
pages/shop/[[...slug]].js/shop/a/b/c{ slug: ['a', 'b', 'c'] }
