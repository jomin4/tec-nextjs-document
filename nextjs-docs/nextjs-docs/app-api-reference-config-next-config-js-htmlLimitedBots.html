htmlLimitedBotshtmlLimitedBots

htmlLimitedBots config를 사용하면 streaming metadata 대신 blocking metadata를 받아야 하는 user agent 목록을 지정할 수 있습니다.

The htmlLimitedBots config allows you to specify a list of user agents that should receive blocking metadata instead of streaming metadata.

TSJSnext.config.ts
import type { NextConfig } from 'next'

const config: NextConfig = {
  htmlLimitedBots: /MySpecialBot|MyAnotherSpecialBot|SimpleCrawler/,
}

export default config
module.exports = {
  htmlLimitedBots: /MySpecialBot|MyAnotherSpecialBot|SimpleCrawler/,
}

Default list기본 목록

Next.js에는 다음을 포함한 HTML limited bot의 기본 목록이 들어 있습니다:

Next.js includes a default list of HTML limited bots, including:

  • Google crawler(예: Mediapartners-Google, AdsBot-Google, Google-PageRenderer)
  • Bingbot
  • Twitterbot
  • Slackbot
  • Google crawlers (e.g. Mediapartners-Google, AdsBot-Google, Google-PageRenderer)
  • Bingbot
  • Twitterbot
  • Slackbot

전체 목록은 여기에서 확인하세요.

See the full list here.

htmlLimitedBots config를 지정하면 Next.js의 기본 목록을 override합니다. 다만 이는 고급 동작이며, 대부분의 경우 기본값으로 충분합니다.

Specifying a htmlLimitedBots config will override the Next.js' default list. However, this is advanced behavior, and the default should be sufficient for most cases.

TSJSnext.config.ts
const config: NextConfig = {
  htmlLimitedBots: /MySpecialBot|MyAnotherSpecialBot|SimpleCrawler/,
}

export default config
module.exports = {
  htmlLimitedBots: /MySpecialBot|MyAnotherSpecialBot|SimpleCrawler/,
}

Disabling비활성화

streaming metadata를 완전히 비활성화하려면:

To fully disable streaming metadata:

TSnext.config.ts
import type { NextConfig } from 'next'

const config: NextConfig = {
  htmlLimitedBots: /.*/,
}

export default config
JSnext.config.js
module.exports = {
  htmlLimitedBots: /.*/,
}
