Font ModuleFont Module

next/font는 font(custom font 포함)를 자동으로 최적화하고, 외부 network request를 없애 privacy와 performance를 개선합니다.

next/font automatically optimizes your fonts (including custom fonts) and removes external network requests for improved privacy and performance.

모든 font 파일에 대해 built-in automatic self-hosting 기능을 제공합니다. 즉, layout shift 없이 web font를 최적으로 load할 수 있습니다.

It includes built-in automatic self-hosting for any font file. This means you can optimally load web fonts with no layout shift.

또한 모든 Google Fonts를 편리하게 사용할 수 있습니다. CSS와 font 파일은 build 시점에 다운로드되어 나머지 static asset과 함께 self-host됩니다. 브라우저는 Google로 어떤 request도 보내지 않습니다.

You can also conveniently use all Google Fonts. CSS and font files are downloaded at build time and self-hosted with the rest of your static assets. No requests are sent to Google by the browser.

모든 page에서 font를 사용하려면, 아래와 같이 /pages 아래의 _app.js 파일에 추가하세요:

To use the font in all your pages, add it to _app.js file under /pages as shown below:

JSpages/_app.js
import { Inter } from 'next/font/google'

// If loading a variable font, you don't need to specify the font weight
const inter = Inter({ subsets: ['latin'] })

export default function MyApp({ Component, pageProps }) {
  return (
    <main className={inter.className}>
      <Component {...pageProps} />
    </main>
  )
}

src

font loader function이 호출되는 directory를 기준으로 한 font 파일 경로입니다. string 또는 object의 array(type은 Array<{path: string, weight?: string, style?: string}>)로 지정합니다.

The path of the font file as a string or an array of objects (with type Array<{path: string, weight?: string, style?: string}>) relative to the directory where the font loader function is called.

weight

font weight이며 다음 값을 사용할 수 있습니다:

The font weight with the following possibilities:

  • 해당 font에서 사용할 수 있는 weight 값을 담은 string, 또는 variable font라면 값의 범위
  • font가 variable google font가 아니라면 weight 값의 array. next/font/google에만 적용됩니다.
  • A string with possible values of the weights available for the specific font or a range of values if it's a variable font
  • An array of weight values if the font is not a variable google font. It applies to next/font/google only.

next/font/google와 next/font/local에서 사용

Used in next/font/google and next/font/local

  • 사용하는 font가 variable font가 아니라면 필수
  • Required if the font being used is not variable

예시:

Examples:

  • weight: '400': 단일 weight 값을 나타내는 string. Inter font의 경우 가능한 값은 '100', '200', '300', '400', '500', '600', '700', '800', '900' 또는 'variable'이며 기본값은 'variable'입니다)
  • weight: '100 900': variable font에서 100부터 900까지의 범위를 나타내는 string
  • weight: ['100','400','900']: variable이 아닌 font에서 가능한 값 3개를 담은 array
  • weight: '400': A string for a single weight value - for the font Inter, the possible values are '100', '200', '300', '400', '500', '600', '700', '800', '900' or 'variable' where 'variable' is the default)
  • weight: '100 900': A string for the range between 100 and 900 for a variable font
  • weight: ['100','400','900']: An array of 3 possible values for a non variable font

  • An array of style values if the font is not a variable google font. It applies to next/font/google only.

subsets

preload하려는 각 subset의 이름을 string 값의 array로 정의한 font subsets입니다. subsets로 지정한 font는 preload option이 true(기본값)일 때 head에 link preload tag가 삽입됩니다.

The font subsets defined by an array of string values with the names of each subset you would like to be preloaded. Fonts specified via subsets will have a link preload tag injected into the head when the preload option is true, which is the default.

Some variable fonts have extra axes that can be included. By default, only the font weight is included to keep the file size down. The possible values of axes depend on the specific font.

  • next/font/google의 경우: Cumulative Layout Shift를 줄이기 위해 자동 fallback font를 사용할지 설정하는 boolean 값입니다. 기본값은 true입니다.

  • For next/font/local: A string or boolean false value that sets whether an automatic fallback font should be used to reduce Cumulative Layout Shift. The possible values are 'Arial', 'Times New Roman' or false. The default is 'Arial'.

An array of font face descriptor key-value pairs that define the generated @font-face further.

font-family를 설정하면 Next.js가 생성하는 이름을 대체합니다. className과 CSS variable이 같은 family를 참조하도록 값을 export한 constant와 같게 유지하세요.

  src: './my-font.woff2',
  declarations: [{ prop: 'font-family', value: 'myFont' }],

To use a Google font, import it from next/font/google as a function. We recommend using variable fonts for the best performance and flexibility.

모든 page에서 font를 사용하려면, 아래와 같이 /pages 아래의 _app.js 파일에 추가하세요:

import { Roboto } from 'next/font/google'

const roboto = Roboto({

Good to know

여러 단어로 된 font 이름에는 underscore(_)를 사용하세요. 예를 들어 Roboto Mono는 Roboto_Mono로 import해야 합니다.

Use an underscore (_) for font names with multiple words. E.g. Roboto Mono should be imported as Roboto_Mono.

Apply the font in <head><head>에 font 적용하기

wrapper와 className 없이, 다음과 같이 <head> 안에 주입해서 font를 사용할 수도 있습니다:

You can also use the font without a wrapper and className by injecting it inside the <head> as follows:

JSpages/_app.js
import { Inter } from 'next/font/google'

const inter = Inter({ subsets: ['latin'] })

export default function MyApp({ Component, pageProps }) {
  return (
    <>
      <style jsx global>{`
        html {
          font-family: ${inter.style.fontFamily};
        }
      `}</style>
      <Component {...pageProps} />
    </>
  )
}

Specifying a subsetsubset 지정하기

Google Fonts는 자동으로 subset 처리됩니다. 이렇게 하면 font 파일 크기가 줄고 performance가 향상됩니다. 이 subset 중 어떤 것을 preload할지 정의해야 합니다. preload가 true인데 subset을 하나도 지정하지 않으면 warning이 발생합니다.

Google Fonts are automatically subset. This reduces the size of the font file and improves performance. You'll need to define which of these subsets you want to preload. Failing to specify any subsets while preload is true will result in a warning.

function 호출에 추가하면 됩니다:

This can be done by adding it to the function call:

JSpages/_app.js
const inter = Inter({ subsets: ['latin'] })

Using Multiple Fonts여러 font 사용하기

애플리케이션에서 여러 font를 import해 사용할 수 있습니다. 두 가지 방법이 있습니다.

You can import and use multiple fonts in your application. There are two approaches you can take.

첫 번째 방법은 font를 export하는 utility function을 만들고, 이를 import해 필요한 곳에 className을 적용하는 것입니다. 이렇게 하면 font가 render될 때만 preload됩니다:

The first approach is to create a utility function that exports a font, imports it, and applies its className where needed. This ensures the font is preloaded only when it's rendered:

TSJSapp/fonts.ts
import { Inter, Roboto_Mono } from 'next/font/google'

export const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
})

export const roboto_mono = Roboto_Mono({
  subsets: ['latin'],
  display: 'swap',
})
import { Inter, Roboto_Mono } from 'next/font/google'

export const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
})

export const roboto_mono = Roboto_Mono({
  subsets: ['latin'],
  display: 'swap',
})

위 예시에서 Inter는 global로 적용되고, Roboto Mono는 필요할 때 import해서 적용할 수 있습니다.

In the example above, Inter will be applied globally, and Roboto Mono can be imported and applied as needed.

또는 CSS variable을 만들어 원하는 CSS 방식과 함께 사용할 수 있습니다:

Alternatively, you can create a CSS variable and use it with your preferred CSS solution:

app/global.css
html {
  font-family: var(--font-inter);
}

h1 {
  font-family: var(--font-roboto-mono);
}

위 예시에서 Inter는 global로 적용되고, 모든 <h1> tag는 Roboto Mono로 styling됩니다.

In the example above, Inter will be applied globally, and any <h1> tags will be styled with Roboto Mono.

Recommendation

새 font 하나하나가 client가 다운로드해야 하는 추가 resource이므로, 여러 font는 신중하게 사용하세요.

Use multiple fonts conservatively since each new font is an additional resource the client has to download.

Local FontsLocal font

With Tailwind CSSTailwind CSS와 함께 사용하기

next/font는 CSS variable을 사용해 Tailwind CSS와 매끄럽게 통합됩니다.

next/font integrates seamlessly with Tailwind CSS using CSS variables.

아래 예시에서는 next/font/google의 Inter와 Roboto_Mono font를 사용합니다(어떤 Google Font나 Local Font든 사용할 수 있습니다). variable option으로 이 font들의 CSS variable 이름을 각각 inter, roboto_mono처럼 정의하세요. 그다음 inter.variable과 roboto_mono.variable을 적용해 HTML document에 CSS variable을 포함시킵니다.

In the example below, we use the Inter and Roboto_Mono fonts from next/font/google (you can use any Google Font or Local Font). Use the variable option to define a CSS variable name, such as inter and roboto_mono for these fonts, respectively. Then, apply inter.variable and roboto_mono.variable to include the CSS variables in your HTML document.

Good to know

취향, styling 요구 사항, 프로젝트 요구 사항에 따라 이 variable들을 <html> 또는 <body> tag에 추가할 수 있습니다.

You can add these variables to the <html> or <body> tag, depending on your preference, styling needs or project requirements.

JSpages/_app.js
import { Inter } from 'next/font/google'

const inter = Inter({
  subsets: ['latin'],
  variable: '--font-inter',
})

const roboto_mono = Roboto_Mono({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-roboto-mono',
})

export default function MyApp({ Component, pageProps }) {
  return (
    <main className={`${inter.variable} ${roboto_mono.variable} font-sans`}>
      <Component {...pageProps} />
    </main>
  )
}

마지막으로 Tailwind CSS config에 CSS variable을 추가하세요:

Finally, add the CSS variable to your Tailwind CSS config:

global.css
@import 'tailwindcss';

@theme inline {
  --font-sans: var(--font-inter);
  --font-mono: var(--font-roboto-mono);
}

이제 font-sans와 font-mono utility class를 사용해 element에 font를 적용할 수 있습니다.

You can now use the font-sans and font-mono utility classes to apply the font to your elements.

<p class="font-sans ...">The quick brown fox ...</p>
<p class="font-mono ...">The quick brown fox ...</p>

Applying StylesStyle 적용하기

font style은 세 가지 방법으로 적용할 수 있습니다:

You can apply the font styles in three ways:

  • className
  • style
  • CSS Variables
  • className
  • style
  • CSS Variables

className

load된 font에 대한 read-only CSS className을 반환하며, 이를 HTML element에 전달합니다.

Returns a read-only CSS className for the loaded font to be passed to an HTML element.

<p className={inter.className}>Hello, Next.js!</p>

style

load된 font에 대한 read-only CSS style object를 반환하며, 이를 HTML element에 전달합니다. font family 이름과 fallback font에 접근할 수 있는 style.fontFamily가 포함됩니다.

Returns a read-only CSS style object for the loaded font to be passed to an HTML element, including style.fontFamily to access the font family name and fallback fonts.

<p style={inter.style}>Hello World</p>

CSS Variables

외부 style sheet에서 style을 설정하고 그곳에서 추가 option을 지정하려면 CSS variable 방식을 사용하세요.

If you would like to set your styles in an external style sheet and specify additional options there, use the CSS variable method.

font를 import하는 것과 함께, CSS variable이 정의된 CSS 파일도 import하고 font loader object의 variable option을 다음과 같이 설정하세요:

In addition to importing the font, also import the CSS file where the CSS variable is defined and set the variable option of the font loader object as follows:

TSJSapp/page.tsx
import { Inter } from 'next/font/google'
import styles from '../styles/component.module.css'

const inter = Inter({
  variable: '--font-inter',
})
import { Inter } from 'next/font/google'
import styles from '../styles/component.module.css'

const inter = Inter({
  variable: '--font-inter',
})

font를 사용하려면, styling하려는 텍스트를 감싸는 parent container의 className을 font loader의 variable 값으로 설정하고, 텍스트의 className은 외부 CSS 파일의 styles property로 설정하세요.

To use the font, set the className of the parent container of the text you would like to style to the font loader's variable value and the className of the text to the styles property from the external CSS file.

TSJSapp/page.tsx
<main className={inter.variable}>
  <p className={styles.text}>Hello World</p>
</main>
<main className={inter.variable}>
  <p className={styles.text}>Hello World</p>
</main>

component.module.css CSS 파일에 text selector class를 다음과 같이 정의하세요:

Define the text selector class in the component.module.css CSS file as follows:

styles/component.module.css
.text {
  font-family: var(--font-inter);
  font-weight: 200;
  font-style: italic;
}

위 예시에서 Hello World 텍스트는 Inter font와 생성된 font fallback을 사용하며 font-weight: 200, font-style: italic으로 styling됩니다.

In the example above, the text Hello World is styled using the Inter font and the generated font fallback with font-weight: 200 and font-style: italic.

Using a font definitions filefont 정의 파일 사용하기

localFont나 Google font function을 호출할 때마다 해당 font는 애플리케이션에서 하나의 instance로 host됩니다. 따라서 같은 font를 여러 곳에서 사용해야 한다면, 한곳에서 load하고 필요한 곳에서 관련 font object를 import해야 합니다. 이를 위해 font 정의 파일을 사용합니다.

Every time you call the localFont or Google font function, that font will be hosted as one instance in your application. Therefore, if you need to use the same font in multiple places, you should load it in one place and import the related font object where you need it. This is done using a font definitions file.

예를 들어 app directory root의 styles 폴더에 fonts.ts 파일을 만드세요.

For example, create a fonts.ts file in a styles folder at the root of your app directory.

그다음 font 정의를 다음과 같이 작성하세요:

Then, specify your font definitions as follows:

TSJSstyles/fonts.ts
import { Inter, Lora, Source_Sans_3 } from 'next/font/google'
import localFont from 'next/font/local'

// define your variable fonts
const inter = Inter()
const lora = Lora()
// define 2 weights of a non-variable font
const sourceCodePro400 = Source_Sans_3({ weight: '400' })
const sourceCodePro700 = Source_Sans_3({ weight: '700' })
// define a custom local font where GreatVibes-Regular.ttf is stored in the styles folder
const greatVibes = localFont({ src: './GreatVibes-Regular.ttf' })

export { inter, lora, sourceCodePro400, sourceCodePro700, greatVibes }
import { Inter, Lora, Source_Sans_3 } from 'next/font/google'
import localFont from 'next/font/local'

// define your variable fonts
const inter = Inter()
const lora = Lora()
// define 2 weights of a non-variable font
const sourceCodePro400 = Source_Sans_3({ weight: '400' })
const sourceCodePro700 = Source_Sans_3({ weight: '700' })
// define a custom local font where GreatVibes-Regular.ttf is stored in the styles folder
const greatVibes = localFont({ src: './GreatVibes-Regular.ttf' })

export { inter, lora, sourceCodePro400, sourceCodePro700, greatVibes }

이제 코드에서 이 정의를 다음과 같이 사용할 수 있습니다:

You can now use these definitions in your code as follows:

TSJSapp/page.tsx
import { inter, lora, sourceCodePro700, greatVibes } from '../styles/fonts'

export default function Page() {
  return (
    <div>
      <p className={inter.className}>Hello world using Inter font</p>
      <p style={lora.style}>Hello world using Lora font</p>
      <p className={sourceCodePro700.className}>
        Hello world using Source_Sans_3 font with weight 700
      </p>
      <p className={greatVibes.className}>My title in Great Vibes font</p>
    </div>
  )
}
import { inter, lora, sourceCodePro700, greatVibes } from '../styles/fonts'

export default function Page() {
  return (
    <div>
      <p className={inter.className}>Hello world using Inter font</p>
      <p style={lora.style}>Hello world using Lora font</p>
      <p className={sourceCodePro700.className}>
        Hello world using Source_Sans_3 font with weight 700
      </p>
      <p className={greatVibes.className}>My title in Great Vibes font</p>
    </div>
  )
}

코드에서 font 정의에 더 쉽게 접근하려면, tsconfig.json 또는 jsconfig.json 파일에 다음과 같이 path alias를 정의할 수 있습니다:

To make it easier to access the font definitions in your code, you can define a path alias in your tsconfig.json or jsconfig.json files as follows:

tsconfig.json
{
  "compilerOptions": {
    "paths": {
      "@/fonts": ["./styles/fonts"]
    }
  }
}

이제 어떤 font 정의든 다음과 같이 import할 수 있습니다:

You can now import any font definition as follows:

TSJSapp/about/page.tsx
import { greatVibes, sourceCodePro400 } from '@/fonts'
import { greatVibes, sourceCodePro400 } from '@/fonts'

Preloading

사이트의 page에서 font function을 호출하면, 그 font는 global로 사용 가능해지거나 모든 route에서 preload되지 않습니다. 대신 font가 사용된 파일 종류에 따라 관련 route에서만 preload됩니다:

When a font function is called on a page of your site, it is not globally available and preloaded on all routes. Rather, the font is only preloaded on the related route/s based on the type of file where it is used:

  • unique page라면 해당 page의 고유 route에서 preload됩니다
  • custom App 안에 있다면 /pages 아래 사이트의 모든 route에서 preload됩니다
  • if it's a unique page, it is preloaded on the unique route for that page
  • if it's in the custom App, it is preloaded on all the routes of the site under /pages
