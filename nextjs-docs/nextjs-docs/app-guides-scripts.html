How to load and optimize scriptsScript 로드와 최적화

Layout ScriptsLayout script

여러 route에서 third-party script를 로드하려면 next/script를 import하고 layout component 안에 script를 직접 포함하세요:

To load a third-party script for multiple routes, import next/script and include the script directly in your layout component:

TSJSapp/dashboard/layout.tsx
import Script from 'next/script'

export default function DashboardLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <>
      <section>{children}</section>
      <Script src="https://example.com/script.js" />
    </>
  )
}
import Script from 'next/script'

export default function DashboardLayout({ children }) {
  return (
    <>
      <section>{children}</section>
      <Script src="https://example.com/script.js" />
    </>
  )
}

third-party script는 사용자가 해당 폴더 route(예: dashboard/page.js)나 그 아래의 nested route(예: dashboard/settings/page.js)에 접근할 때 fetch됩니다. 사용자가 같은 layout 안의 여러 route 사이를 이동하더라도 Next.js는 script가 딱 한 번만 로드되도록 보장합니다.

The third-party script is fetched when the folder route (e.g. dashboard/page.js) or any nested route (e.g. dashboard/settings/page.js) is accessed by the user. Next.js will ensure the script will only load once, even if a user navigates between multiple routes in the same layout.

Application ScriptsApplication script

모든 route에서 third-party script를 로드하려면 next/script를 import하고 root layout 안에 script를 직접 포함하세요:

To load a third-party script for all routes, import next/script and include the script directly in your root layout:

TSJSapp/layout.tsx
import Script from 'next/script'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
      <Script src="https://example.com/script.js" />
    </html>
  )
}
import Script from 'next/script'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
      <Script src="https://example.com/script.js" />
    </html>
  )
}

이 script는 애플리케이션의 어떤 route에 접근하든 로드되어 실행됩니다. 사용자가 여러 page 사이를 이동하더라도 Next.js는 script가 딱 한 번만 로드되도록 보장합니다.

This script will load and execute when any route in your application is accessed. Next.js will ensure the script will only load once, even if a user navigates between multiple pages.

Recommendation

불필요한 성능 영향을 최소화하기 위해 third-party script는 특정 page나 layout에만 포함하는 것을 권장합니다.

We recommend only including third-party scripts in specific pages or layouts in order to minimize any unnecessary impact to performance.

Strategy

next/script의 기본 동작으로도 어떤 page나 layout에서든 third-party script를 로드할 수 있지만, strategy property를 사용해 로딩 동작을 세밀하게 조정할 수 있습니다:

Although the default behavior of next/script allows you to load third-party scripts in any page or layout, you can fine-tune its loading behavior by using the strategy property:

  • beforeInteractive: 모든 Next.js 코드보다 먼저, 그리고 page hydration이 일어나기 전에 script를 로드합니다.
  • afterInteractive: (기본값) script를 일찍 로드하되, page에서 어느 정도 hydration이 일어난 뒤에 로드합니다.
  • lazyOnload: 브라우저가 idle 상태일 때 나중에 script를 로드합니다.
  • worker: (experimental) web worker에서 script를 로드합니다.
  • beforeInteractive: Load the script before any Next.js code and before any page hydration occurs.
  • afterInteractive: (default) Load the script early but after some hydration on the page occurs.
  • lazyOnload: Load the script later during browser idle time.
  • worker: (experimental) Load the script in a web worker.

각 strategy와 사용 사례에 대해 더 알아보려면 next/script API reference 문서를 참고하세요.

Refer to the next/script API reference documentation to learn more about each strategy and their use cases.

Offloading Scripts To A Web Worker (experimental)Script를 Web Worker로 넘기기 (experimental)

Warning

worker strategy는 아직 stable하지 않으며 App Router에서는 아직 동작하지 않습니다. 주의해서 사용하세요.

The worker strategy is not yet stable and does not yet work with the App Router. Use with caution.

worker strategy를 사용하는 script는 Partytown을 통해 web worker로 넘겨져(offload) 실행됩니다. main thread를 애플리케이션의 나머지 코드에 전념하게 해서 사이트 성능을 높일 수 있습니다.

Scripts that use the worker strategy are offloaded and executed in a web worker with Partytown. This can improve the performance of your site by dedicating the main thread to the rest of your application code.

이 strategy는 아직 experimental이며, next.config.js에서 nextScriptWorkers flag를 활성화한 경우에만 사용할 수 있습니다:

This strategy is still experimental and can only be used if the nextScriptWorkers flag is enabled in next.config.js:

JSnext.config.js
module.exports = {
  experimental: {
    nextScriptWorkers: true,
  },
}

그다음 development server를 실행하면 Next.js가 setup을 마치는 데 필요한 package 설치 과정을 안내합니다:

Then, run the development server and Next.js will guide you through the installation of the required packages to finish the setup:

pnpm dev
npm run dev
yarn dev
bun dev

다음과 같은 안내가 표시됩니다: Please install Partytown by running npm install @qwik.dev/partytown

You'll see instructions like these: Please install Partytown by running npm install @qwik.dev/partytown

setup이 끝나면 strategy="worker"를 지정하는 것만으로 애플리케이션에서 Partytown이 자동으로 instantiate되고 script가 web worker로 넘겨집니다.

Once setup is complete, defining strategy="worker" will automatically instantiate Partytown in your application and offload the script to a web worker.

TSJSpages/home.tsx
import Script from 'next/script'

export default function Home() {
  return (
    <>
      <Script src="https://example.com/script.js" strategy="worker" />
    </>
  )
}
import Script from 'next/script'

export default function Home() {
  return (
    <>
      <Script src="https://example.com/script.js" strategy="worker" />
    </>
  )
}

web worker에서 third-party script를 로드할 때는 고려해야 할 trade-off가 여럿 있습니다. 자세한 내용은 Partytown의 tradeoffs 문서를 참고하세요.

There are a number of trade-offs that need to be considered when loading a third-party script in a web worker. Please see Partytown's tradeoffs documentation for more information.

Inline ScriptsInline script

inline script, 즉 외부 파일에서 로드하지 않는 script도 Script component에서 지원됩니다. JavaScript를 중괄호 안에 넣어 작성할 수 있습니다:

Inline scripts, or scripts not loaded from an external file, are also supported by the Script component. They can be written by placing the JavaScript within curly braces:

<Script id="show-banner">
  {`document.getElementById('banner').classList.remove('hidden')`}
</Script>

또는 dangerouslySetInnerHTML property를 사용할 수도 있습니다:

Or by using the dangerouslySetInnerHTML property:

<Script
  id="show-banner"
  dangerouslySetInnerHTML={{
    __html: `document.getElementById('banner').classList.remove('hidden')`,
  }}
/>
Warning

Next.js가 script를 추적하고 최적화하려면 inline script에 id property를 반드시 지정해야 합니다.

An id property must be assigned for inline scripts in order for Next.js to track and optimize the script.

Executing Additional Code추가 코드 실행하기

Script component에 event handler를 사용하면 특정 event가 발생한 뒤 추가 코드를 실행할 수 있습니다:

Event handlers can be used with the Script component to execute additional code after a certain event occurs:

  • onLoad: script 로딩이 끝난 뒤 코드를 실행합니다.
  • onReady: script 로딩이 끝난 뒤, 그리고 component가 mount될 때마다 코드를 실행합니다.
  • onError: script 로드에 실패하면 코드를 실행합니다.
  • onLoad: Execute code after the script has finished loading.
  • onReady: Execute code after the script has finished loading and every time the component is mounted.
  • onError: Execute code if the script fails to load.

이 handler들은 next/script를 Client Component 안에서 import하고 사용할 때만 동작합니다. client entry point를 만들려면 파일 맨 위, 모든 import보다 앞에 "use client"를 추가하세요:

These handlers will only work when next/script is imported and used inside of a Client Component. To create a client entry point, add "use client" at the top of the file, before any imports:

TSJSapp/page.tsx
'use client'

import Script from 'next/script'

export default function Page() {
  return (
    <>
      <Script
        src="https://example.com/script.js"
        onLoad={() => {
          console.log('Script has loaded')
        }}
      />
    </>
  )
}
'use client'

import Script from 'next/script'

export default function Page() {
  return (
    <>
      <Script
        src="https://example.com/script.js"
        onLoad={() => {
          console.log('Script has loaded')
        }}
      />
    </>
  )
}

각 event handler에 대해 더 알아보고 예제를 보려면 next/script API reference를 참고하세요.

Refer to the next/script API reference to learn more about each event handler and view examples.

Additional Attributes추가 attribute

nonce나 custom data attribute처럼, Script component가 사용하지 않지만 <script> element에 지정할 수 있는 DOM attribute가 많이 있습니다. 추가 attribute를 포함하면 HTML에 들어가는 최종 최적화된 <script> element로 자동으로 전달됩니다.

There are many DOM attributes that can be assigned to a <script> element that are not used by the Script component, like nonce or custom data attributes. Including any additional attributes will automatically forward it to the final, optimized <script> element that is included in the HTML.

TSJSapp/page.tsx
import Script from 'next/script'

export default function Page() {
  return (
    <>
      <Script
        src="https://example.com/script.js"
        id="example-script"
        nonce="XUENAJFW"
        data-test="script"
      />
    </>
  )
}
import Script from 'next/script'

export default function Page() {
  return (
    <>
      <Script
        src="https://example.com/script.js"
        id="example-script"
        nonce="XUENAJFW"
        data-test="script"
      />
    </>
  )
}
