serverExternalPackagesserverExternalPackages

Server Components와 Route Handlers 안에서 사용하는 dependency는 Next.js가 자동으로 bundle합니다.

Dependencies used inside Server Components and Route Handlers will automatically be bundled by Next.js.

dependency가 Node.js 전용 기능을 사용한다면, 특정 dependency를 Server Component bundling에서 제외(opt-out)하고 native Node.js require를 사용하도록 선택할 수 있습니다.

If a dependency is using Node.js specific features, you can choose to opt-out specific dependencies from the Server Components bundling and use native Node.js require.

JSnext.config.js
/** @type {import('next').NextConfig} */
const nextConfig = {
  serverExternalPackages: ['@acme/ui'],
}

module.exports = nextConfig
