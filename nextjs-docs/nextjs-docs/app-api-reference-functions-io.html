ioio

Cache Components가 활성화되어 있으면, Next.js는 new Date()나 Math.random() 같은 synchronous 값을 한 번 capture해서 모든 방문자에게 재사용할지, 아니면 request마다 새로 생성할지를 여러분이 결정하도록 요구합니다.

When Cache Components is enabled, Next.js needs you to decide whether to capture a synchronous value like new Date() or Math.random() once and reuse it for every visitor, or produce it fresh for each request.

값을 static shell에 capture하려면 "use cache"로 감싸세요. static shell에서 제외하려면 prerendering 중에 suspend되는 await io()를 사용하세요.

To capture the value in the static shell, wrap it in "use cache". To keep it out of the static shell, use await io(), which suspends during prerendering.

request 중, cache된 scope 안, 브라우저, 그리고 Cache Components를 사용하지 않는 앱(Pages Router 포함)에서는 io()를 호출하면 즉시 resolve됩니다.

During a request, inside cached scopes, in the browser, and apps without Cache Components (including the Pages Router), calling io() resolves immediately.

Usage사용법

io()를 호출해 뒤이어 IO 작업이 온다는 것을 Next.js에 알리세요.

Call io() to inform Next.js that an IO operation follows.

Server Component에서는 new Date(), Math.random(), crypto.randomUUID() 같은 값이나 node:sqlite 같은 synchronous database driver를 읽기 전에 await io()를 호출하세요:

In a Server Component, call await io() before reading a value like new Date(), Math.random(), crypto.randomUUID(), or a synchronous database driver such as node:sqlite:

TSJSapp/page.tsx
import { Suspense } from 'react'
import { io } from 'next/cache'

export default function Page() {
  return (
    <Suspense fallback={<p>Loading...</p>}>
      <CurrentTime />
    </Suspense>
  )
}

async function CurrentTime() {
  await io()
  return <p>{new Date().toISOString()}</p>
}
import { Suspense } from 'react'
import { io } from 'next/cache'

export default function Page() {
  return (
    <Suspense fallback={<p>Loading...</p>}>
      <CurrentTime />
    </Suspense>
  )
}

async function CurrentTime() {
  await io()
  return <p>{new Date().toISOString()}</p>
}

이 route에서 CurrentTime은 <Suspense> boundary로 감싸져 있으므로, prerender 중에 await io()가 suspend되고 fallback이 static shell에 담겨 전달됩니다. 만약 CurrentTime이 대신 "use cache" scope 안에서 render된다면 io()는 아무 일도 하지 않으며(no-op), 값은 static shell에 capture되고 <Suspense> boundary도 필요 없습니다.

In this route CurrentTime is wrapped in a <Suspense> boundary, during prerender, the await io() suspends and the fallback ships in the static shell. If CurrentTime were rendered inside a "use cache" scope instead, io() would be a no-op, the value is captured into the static shell and no <Suspense> boundary is required.

Client Component에서는 Date.now() 같은 synchronous source를 읽기 전에 React의 use hook과 함께 io()를 호출하세요. Client Component는 SSR 중에 server에서 prerender되므로, 그렇게 하지 않으면 읽은 값이 static shell에 포함됩니다:

In a Client Component, call io() with React's use hook before reading a synchronous source like Date.now(). Client Components prerender on the server during SSR, where the read would otherwise be included in the static shell:

TSJSapp/components.tsx
'use client'
import { use } from 'react'
import { io } from 'next/cache'

export function CurrentTime() {
  use(io())
  return <div>{Date.now()}</div>
}
'use client'
import { use } from 'react'
import { io } from 'next/cache'

export function CurrentTime() {
  use(io())
  return <div>{Date.now()}</div>
}

When you don't need io()io()가 필요 없는 경우

  • component가 이미 cookies()나 headers() 같은 Request-time API를 사용하고 있는 경우. request-time API 자체가 suspension 지점입니다.
  • 데이터가 <Suspense>로 감싼 await된 fetch나 async database query에서 오는 경우. await가 suspension 지점입니다.
  • The component already uses a Request-time API like cookies() or headers(). The request-time API is itself the suspension point.
  • The data comes from an awaited fetch or async database query wrapped in <Suspense>. The await is the suspension point.

How io() differs from connection()io()와 connection()의 차이

connection() 함수는 그 뒤에 오는 코드를 static shell에서 제외하지만, 실제 사용자 navigation이 server에 도달할 때까지 suspend된 상태로 남기 때문에 prefetch도 막습니다. io()는 다른 asynchronous 함수처럼 suspend되므로, 그 뒤의 코드를 "use cache"로 감싸서 client에서 prefetch하고 cache할 수 있습니다. connection()보다 io()를 우선 사용하고, 실제 사용자 request를 기다려야 할 때만 connection()을 사용하세요.

The connection() function excludes the code that follows it from the static shell, but it stays suspended until a full user navigation reaches the server, so it also blocks prefetches. io() suspends like any other asynchronous function, so the code after it can be wrapped in "use cache" and prefetched and cached on the client. Prefer io() over connection(), and reach for connection() only when you need to wait for a real user request.

Reference

Type

function io(): Promise<void>

Parameters

  • 이 함수는 parameter를 받지 않습니다.
  • The function does not accept any parameters.

Returns

Promise<void>를 반환합니다. Cache Components가 활성화되어 있으면 이 promise를 await할 때 prerendering이 멈추므로, 뒤이은 코드는 prerender output에서 제외됩니다. 그 밖의 모든 context(실제 request, cache scope, generateStaticParams, 브라우저, Cache Components가 없는 route)에서는 즉시 resolve됩니다.

A Promise<void>. With Cache Components enabled, awaiting this promise stops prerendering so the code that follows is excluded from the prerender output. In every other context (real requests, cache scopes, generateStaticParams, the browser, and routes without Cache Components), it resolves immediately.
