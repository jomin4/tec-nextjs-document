Image Optimization이미지 최적화

Next.js <Image> component는 HTML <img> element를 확장해 다음 기능을 제공합니다:

The Next.js <Image> component extends the HTML <img> element to provide:

  • Size optimization: WebP 같은 최신 이미지 format을 사용해 기기마다 알맞은 크기의 이미지를 자동으로 제공합니다.
  • Visual stability: 이미지가 로딩될 때 layout shift를 자동으로 방지합니다.
  • Faster page loads: 브라우저 native lazy loading을 사용해 이미지가 viewport에 들어올 때만 로드하며, 선택적으로 blur-up placeholder를 사용할 수 있습니다.
  • Asset flexibility: remote server에 저장된 이미지까지도 on-demand로 크기를 조정합니다.
  • Size optimization: Automatically serving correctly sized images for each device, using modern image formats like WebP.
  • Visual stability: Preventing layout shift automatically when images are loading.
  • Faster page loads: Only loading images when they enter the viewport using native browser lazy loading, with optional blur-up placeholders.
  • Asset flexibility: Resizing images on-demand, even images stored on remote servers.

<Image>를 사용하려면 next/image에서 import한 뒤 component 안에서 render하세요.

To start using <Image>, import it from next/image and render it within your component.

TSJSapp/page.tsx
import Image from 'next/image'

export default function Page() {
  return <Image src="" alt="" />
}
import Image from 'next/image'

export default function Page() {
  return <Image src="" alt="" />
}

src property에는 로컬 이미지나 remote 이미지를 지정할 수 있습니다.

The src property can be a local or remote image.

Local images로컬 이미지

이미지나 font 같은 static 파일은 root directory의 public 폴더 아래에 저장할 수 있습니다. public 안의 파일은 코드에서 base URL(/)부터 시작하는 경로로 참조할 수 있습니다.

You can store static files, like images and fonts, under a folder called public in the root directory. Files inside public can then be referenced by your code starting from the base URL (/).

TSJSapp/page.tsx
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}

이미지를 static import하면 Next.js가 고유한(intrinsic) width와 height를 자동으로 알아냅니다. 이 값은 이미지 비율을 결정하고, 이미지가 로딩되는 동안 Cumulative Layout Shift를 방지하는 데 사용됩니다.

If the image is statically imported, Next.js will automatically determine the intrinsic width and height. These values are used to determine the image ratio and prevent Cumulative Layout Shift while your image is loading.

TSJSapp/page.tsx
import Image from 'next/image'
import ProfileImage from './profile.png'

export default function Page() {
  return (
    <Image
      src={ProfileImage}
      alt="Picture of the author"
      // width={500} automatically provided
      // height={500} automatically provided
      // blurDataURL="data:..." automatically provided
      // placeholder="blur" // Optional blur-up while loading
    />
  )
}
import Image from 'next/image'
import ProfileImage from './profile.png'

export default function Page() {
  return (
    <Image
      src={ProfileImage}
      alt="Picture of the author"
      // width={500} automatically provided
      // height={500} automatically provided
      // blurDataURL="data:..." automatically provided
      // placeholder="blur" // Optional blur-up while loading
    />
  )
}

Images without static importsstatic import 없이 이미지 사용하기

이미지에 static import를 사용할 수 없다면, Server Component에서 dynamic import()를 사용해도 width, height, blurDataURL을 자동으로 얻을 수 있습니다:

If you can't use a static import for your images, you can use a dynamic import() in a Server Component to still get automatic width, height, and blurDataURL:

TSJSapp/blog/[slug]/page.tsx
import Image from 'next/image'

async function PostImage({
  imageFilename,
  alt,
}: {
  imageFilename: string
  alt: string
}) {
  const { default: image } = await import(
    `../content/blog/images/${imageFilename}`
  )
  // image contains width, height, and blurDataURL
  return <Image src={image} alt={alt} />
}
import Image from 'next/image'

async function PostImage({ imageFilename, alt }) {
  const { default: image } = await import(
    `../content/blog/images/${imageFilename}`
  )
  // image contains width, height, and blurDataURL
  return <Image src={image} alt={alt} />
}

path alias(예: @/)를 설정해 두었다면 상대 경로 대신 사용할 수 있습니다:

If you have a path alias configured (e.g. @/), you can use it instead of a relative path:

const { default: image } = await import(
  `@/content/blog/images/${imageFilename}`
)

경로에는 static prefix(예: ../content/blog/images/)가 포함되어야 합니다. 그 prefix와 일치하는 모든 파일이 bundle되므로 가능한 한 구체적으로 지정하세요. 지정한 directory 안의 파일만 포함되므로, 외부 입력이 그 바깥에 접근할 수는 없습니다.

The path must include a static prefix (like ../content/blog/images/). Be as specific as possible, since all files matching that prefix are bundled. Only files in your specified directory are included, so external input cannot reach outside of it.

Remote imagesRemote 이미지

remote 이미지를 사용하려면 src property에 URL 문자열을 지정하면 됩니다.

To use a remote image, you can provide a URL string for the src property.

TSJSapp/page.tsx
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="https://s3.amazonaws.com/my-bucket/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="https://s3.amazonaws.com/my-bucket/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}

Next.js는 build 과정에서 remote 파일에 접근할 수 없으므로 width, height, 그리고 선택적으로 blurDataURL props를 직접 지정해야 합니다. width와 height는 이미지의 올바른 종횡비를 추론하고, 이미지가 로딩되면서 생기는 layout shift를 피하는 데 사용됩니다. 또는 fill property를 사용해 이미지가 부모 element의 크기를 채우도록 할 수도 있습니다.

Since Next.js does not have access to remote files during the build process, you'll need to provide the width, height and optional blurDataURL props manually. The width and height are used to infer the correct aspect ratio of image and avoid layout shift from the image loading in. Alternatively, you can use the fill property to make the image fill the size of the parent element.

remote server의 이미지를 안전하게 허용하려면 next.config.js에 지원할 URL pattern 목록을 정의해야 합니다. 악의적인 사용을 막기 위해 가능한 한 구체적으로 지정하세요. 예를 들어 다음 configuration은 특정 AWS S3 bucket의 이미지만 허용합니다:

To safely allow images from remote servers, you need to define a list of supported URL patterns in next.config.js. Be as specific as possible to prevent malicious usage. For example, the following configuration will only allow images from a specific AWS S3 bucket:

TSJSnext.config.ts
import type { NextConfig } from 'next'

const config: NextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 's3.amazonaws.com',
        port: '',
        pathname: '/my-bucket/**',
        search: '',
      },
    ],
  },
}

export default config
module.exports = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 's3.amazonaws.com',
        port: '',
        pathname: '/my-bucket/**',
        search: '',
      },
    ],
  },
}
