pageExtensionspageExtensions

Next.js가 사용하는 기본 page 확장자(.tsx, .ts, .jsx, .js)를 확장할 수 있습니다. next.config.js 안에 pageExtensions config를 추가하세요:

You can extend the default Page extensions (.tsx, .ts, .jsx, .js) used by Next.js. Inside next.config.js, add the pageExtensions config:

JSnext.config.js
module.exports = {
  pageExtensions: ['mdx', 'md', 'jsx', 'js', 'tsx', 'ts'],
}

이 값을 바꾸면 다음을 포함한 Next.js의 모든 page에 영향을 줍니다:

Changing these values affects all Next.js pages, including the following:

  • proxy.js
  • instrumentation.js
  • pages/_document.js
  • pages/_app.js
  • pages/api/
  • proxy.js
  • instrumentation.js
  • pages/_document.js
  • pages/_app.js
  • pages/api/

예를 들어 .ts page 확장자를 .page.ts로 다시 설정하면, proxy.page.ts, instrumentation.page.ts, _app.page.ts처럼 page 이름을 바꿔야 합니다.

For example, if you reconfigure .ts page extensions to .page.ts, you would need to rename pages like proxy.page.ts, instrumentation.page.ts, _app.page.ts.

Including non-page files in the pages directorypages directory에 page가 아닌 파일 포함하기

test 파일이나 component가 사용하는 다른 파일을 pages directory에 함께 둘(colocate) 수 있습니다. next.config.js 안에 pageExtensions config를 추가하세요:

You can colocate test files or other files used by components in the pages directory. Inside next.config.js, add the pageExtensions config:

JSnext.config.js
module.exports = {
  pageExtensions: ['page.tsx', 'page.ts', 'page.jsx', 'page.js'],
}

그런 다음 page의 파일 확장자에 .page가 포함되도록 이름을 바꾸세요(예: MyPage.tsx를 MyPage.page.tsx로). 위에서 언급한 파일을 포함해 Next.js의 모든 page 이름을 바꿔야 합니다.

Then, rename your pages to have a file extension that includes .page (e.g. rename MyPage.tsx to MyPage.page.tsx). Ensure you rename all Next.js pages, including the files mentioned above.
