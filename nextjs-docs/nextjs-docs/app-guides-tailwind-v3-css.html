How to install Tailwind CSS v3 in your Next.js applicationNext.js 애플리케이션에 Tailwind CSS v3 설치하기

이 가이드는 Next.js 애플리케이션에 Tailwind CSS v3를 설치하는 방법을 안내합니다.

This guide will walk you through how to install Tailwind CSS v3 in your Next.js application.

Good to know

최신 Tailwind 4 setup은 Tailwind CSS 설정 안내를 참고하세요.

For the latest Tailwind 4 setup, see the Tailwind CSS setup instructions.

Installing Tailwind v3Tailwind v3 설치하기

Tailwind CSS와 peer dependency를 설치한 다음, init command를 실행해 tailwind.config.js와 postcss.config.js 파일을 모두 생성하세요:

Install Tailwind CSS and its peer dependencies, then run the init command to generate both tailwind.config.js and postcss.config.js files:

pnpm add -D tailwindcss@^3 postcss autoprefixer
npx tailwindcss init -p
npm install -D tailwindcss@^3 postcss autoprefixer
npx tailwindcss init -p
yarn add -D tailwindcss@^3 postcss autoprefixer
npx tailwindcss init -p
bun add -D tailwindcss@^3 postcss autoprefixer
bunx tailwindcss init -p

Configuring Tailwind v3Tailwind v3 설정하기

tailwind.config.js 파일에서 template 경로를 설정하세요:

Configure your template paths in your tailwind.config.js file:

JStailwind.config.js
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    './app/**/*.{js,ts,jsx,tsx,mdx}',
    './pages/**/*.{js,ts,jsx,tsx,mdx}',
    './components/**/*.{js,ts,jsx,tsx,mdx}',
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}

global CSS 파일에 Tailwind directive를 추가하세요:

Add the Tailwind directives to your global CSS file:

app/globals.css
@tailwind base;
@tailwind components;
@tailwind utilities;

root layout에서 CSS 파일을 import하세요:

Import the CSS file in your root layout:

TSJSapp/layout.tsx
import './globals.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
import './globals.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}

Using classesclass 사용하기

Tailwind CSS를 설치하고 global style을 추가했다면, 애플리케이션에서 Tailwind의 utility class를 사용할 수 있습니다.

After installing Tailwind CSS and adding the global styles, you can use Tailwind's utility classes in your application.

TSJSapp/page.tsx
export default function Page() {
  return <h1 className="text-3xl font-bold underline">Hello, Next.js!</h1>
}
export default function Page() {
  return <h1 className="text-3xl font-bold underline">Hello, Next.js!</h1>
}

Usage with TurbopackTurbopack과 함께 사용하기

Next.js 13.1부터 Tailwind CSS와 PostCSS는 Turbopack에서 지원됩니다.

As of Next.js 13.1, Tailwind CSS and PostCSS are supported with Turbopack.
