favicon, icon, and apple-iconfavicon, icon, apple-icon

favicon, icon, apple-icon file convention을 사용하면 애플리케이션의 아이콘을 설정할 수 있습니다.

The favicon, icon, or apple-icon file conventions allow you to set icons for your application.

웹 브라우저 tab, 휴대폰 홈 화면, 검색 엔진 결과 같은 곳에 표시되는 앱 아이콘을 추가할 때 유용합니다.

They are useful for adding app icons that appear in places like web browser tabs, phone home screens, and search engine results.

앱 아이콘을 설정하는 방법은 두 가지입니다:

There are two ways to set app icons:

  • 이미지 파일 사용 (.ico, .jpg, .png)
  • 코드로 아이콘 생성 (.js, .ts, .tsx)
  • Using image files (.ico, .jpg, .png)
  • Using code to generate an icon (.js, .ts, .tsx)

Image files (.ico, .jpg, .png)이미지 파일 (.ico, .jpg, .png)

/app directory 안에 favicon, icon, apple-icon 이미지 파일을 두어 이미지 파일로 앱 아이콘을 설정합니다. favicon 이미지는 app/의 최상위에만 둘 수 있습니다.

Use an image file to set an app icon by placing a favicon, icon, or apple-icon image file within your /app directory. The favicon image can only be located in the top level of app/.

Next.js는 파일을 평가해 앱의 <head> element에 적절한 tag를 자동으로 추가합니다.

Next.js will evaluate the file and automatically add the appropriate tags to your app's <head> element.

favicon

root /app route segment에 favicon.ico 이미지 파일을 추가하세요.

Add a favicon.ico image file to the root /app route segment.

<head> output
<link rel="icon" href="/favicon.ico" sizes="any" />

Add an apple-icon.(jpg|jpeg|png) image file.

Good to know
  • 파일 이름에 숫자 suffix를 붙여 여러 아이콘을 설정할 수 있습니다. 예를 들어 icon1.png, icon2.png 등입니다. 번호가 붙은 파일은 사전순(lexical)으로 정렬됩니다.
  • Favicon은 root /app segment에서만 설정할 수 있습니다. 더 세밀하게 설정해야 한다면 icon을 사용하세요.
  • 적절한 <link> tag와 rel, href, type, sizes 같은 attribute는 평가된 파일의 아이콘 type과 metadata에 따라 결정됩니다.
  • 예를 들어 32x32px .png 파일에는 type="image/png"와 sizes="32x32" attribute가 붙습니다.
  • 확장자가 .svg이거나 파일의 이미지 크기를 알 수 없으면 아이콘에 sizes="any"가 추가됩니다. 자세한 내용은 이 favicon handbook을 참고하세요.
  • You can set multiple icons by adding a number suffix to the file name. For example, icon1.png, icon2.png, etc. Numbered files will sort lexically.
  • Favicons can only be set in the root /app segment. If you need more granularity, you can use icon.
  • The appropriate <link> tags and attributes such as rel, href, type, and sizes are determined by the icon type and metadata of the evaluated file.
  • For example, a 32 by 32px .png file will have type="image/png" and sizes="32x32" attributes.
  • sizes="any" is added to icons when the extension is .svg or the image size of the file is not determined. More details in this favicon handbook.

Generate icons using code (.js, .ts, .tsx)코드로 아이콘 생성하기 (.js, .ts, .tsx)

실제 이미지 파일을 사용하는 것 외에도, 코드로 아이콘을 프로그래밍 방식으로 생성할 수 있습니다.

In addition to using literal image files, you can programmatically generate icons using code.

함수를 default export하는 icon 또는 apple-icon route를 만들어 앱 아이콘을 생성합니다.

Generate an app icon by creating an icon or apple-icon route that default exports a function.

File convention지원 파일 형식
icon.js, .ts, .tsx
apple-icon.js, .ts, .tsx
File conventionSupported file types
icon.js, .ts, .tsx
apple-icon.js, .ts, .tsx

아이콘을 생성하는 가장 쉬운 방법은 next/og의 ImageResponse API를 사용하는 것입니다.

The easiest way to generate an icon is to use the ImageResponse API from next/og.

TSJSapp/icon.tsx
import { ImageResponse } from 'next/og'

// Image metadata
export const size = {
  width: 32,
  height: 32,
}
export const contentType = 'image/png'

// Image generation
export default function Icon() {
  return new ImageResponse(
    (
      // ImageResponse JSX element
      <div
        style={{
          fontSize: 24,
          background: 'black',
          width: '100%',
          height: '100%',
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
          color: 'white',
        }}
      >
        A
      </div>
    ),
    // ImageResponse options
    {
      // For convenience, we can re-use the exported icons size metadata
      // config to also set the ImageResponse's width and height.
      ...size,
    }
  )
}
import { ImageResponse } from 'next/og'

// Image metadata
export const size = {
  width: 32,
  height: 32,
}

// Image generation

    ),

      // config to also set the ImageResponse's width and height.
      ...size,
    }
  )
}
<head> output
<link rel="icon" href="/icon?<generated>" type="image/png" sizes="32x32" />
Good to know
  • 기본적으로 생성된 아이콘은 Request-time API나 cache되지 않은 데이터를 사용하지 않는 한 statically optimized 됩니다(build 시점에 생성되고 cache됨).
  • generateImageMetadata를 사용하면 같은 파일에서 여러 아이콘을 생성할 수 있습니다.
  • favicon 아이콘은 생성할 수 없습니다. 대신 icon이나 favicon.ico 파일을 사용하세요.
  • 앱 아이콘은 특수한 Route Handler로, Request-time API나 dynamic config option을 사용하지 않는 한 기본적으로 cache됩니다.
  • By default, generated icons are statically optimized (generated at build time and cached) unless they use Request-time APIs or uncached data.
  • You can generate multiple icons in the same file using generateImageMetadata.
  • You cannot generate a favicon icon. Use icon or a favicon.ico file instead.
  • App icons are special Route Handlers that are cached by default unless they use a Request-time API or dynamic config option.

Props

default export 함수는 다음 props를 받습니다:

The default export function receives the following props:

params (optional)

root segment부터 icon 또는 apple-icon이 함께 위치한(colocated) segment까지의 dynamic route parameter 객체를 담은 객체로 resolve되는 promise입니다.

A promise that resolves to an object containing the dynamic route parameters object from the root segment down to the segment icon or apple-icon is colocated in.

Good to know

generateImageMetadata를 사용하면 함수는 id prop도 받습니다. 이 prop은 generateImageMetadata가 반환한 항목 중 하나의 id 값으로 resolve되는 promise입니다.

If you use generateImageMetadata, the function will also receive an id prop that is a promise resolving to the id value from one of the items returned by generateImageMetadata.

TSJSapp/shop/[slug]/icon.tsx
export default async function Icon({
  params,
}: {
  params: Promise<{ slug: string }>
}) {
  const { slug } = await params
  // ...
}
export default async function Icon({ params }) {
  const { slug } = await params
  // ...
}

Returns

default export 함수는 Blob | ArrayBuffer | TypedArray | DataView | ReadableStream | Response를 반환해야 합니다.

The default export function should return a Blob | ArrayBuffer | TypedArray | DataView | ReadableStream | Response.

Good to know

ImageResponse는 이 return type을 만족합니다.

ImageResponse satisfies this return type.

선택적으로 icon 또는 apple-icon route에서 size와 contentType 변수를 export해 아이콘의 metadata를 설정할 수 있습니다.

Route Segment Config

icon과 apple-icon은 특수한 Route Handler로, Page 및 Layout과 같은 route segment configuration option을 사용할 수 있습니다.

icon and apple-icon are specialized Route Handlers that can use the same route segment configuration options as Pages and Layouts.
