HeadHead

page의 head에 element를 추가하기 위한 built-in component를 제공합니다:

We expose a built-in component for appending elements to the head of the page:

import Head from 'next/head'

function IndexPage() {
  return (
    <div>
      <Head>
        <title>My page title</title>
      </Head>
      <p>Hello world!</p>
    </div>
  )
}

export default IndexPage

Avoid duplicated tags중복 tag 피하기

head에 tag가 중복되지 않도록 하려면 key property를 사용할 수 있습니다. 다음 예제처럼 이 property를 사용하면 tag가 한 번만 render됩니다:

To avoid duplicate tags in your head you can use the key property, which will make sure the tag is only rendered once, as in the following example:

import Head from 'next/head'

function IndexPage() {
  return (
    <div>
      <Head>
        <title>My page title</title>
        <meta property="og:title" content="My page title" key="title" />
      </Head>
      <Head>
        <meta property="og:title" content="My new title" key="title" />
      </Head>
      <p>Hello world!</p>
    </div>
  )
}

export default IndexPage

이 경우 두 번째 <meta property="og:title" />만 render됩니다. key attribute가 중복된 meta tag는 자동으로 처리됩니다.

In this case only the second <meta property="og:title" /> is rendered. meta tags with duplicate key attributes are automatically handled.

Good to know

<title>과 <base> tag는 Next.js가 자동으로 중복을 확인하므로, 이 tag들에는 key를 사용할 필요가 없습니다.

<title> and <base> tags are automatically checked for duplicates by Next.js, so using key is not necessary for these tags.

component가 unmount되면 head의 내용이 지워집니다. 따라서 다른 page에서 무엇을 추가했는지 가정하지 말고, 각 page가 head에 필요한 것을 완전히 정의하도록 하세요.

The contents of head get cleared upon unmounting the component, so make sure each page completely defines what it needs in head, without making assumptions about what other pages added.

Use minimal nestingnesting 최소화하기

title, meta 또는 다른 element(예: script)는 Head element의 직접적인(direct) children으로 들어가거나, 최대 한 단계의 <React.Fragment> 또는 배열로 감싸야 합니다 — 그렇지 않으면 client-side navigation에서 tag가 올바르게 반영되지 않습니다.

title, meta or any other elements (e.g. script) need to be contained as direct children of the Head element, or wrapped into maximum one level of <React.Fragment> or arrays—otherwise the tags won't be correctly picked up on client-side navigations.

Use next/script for scriptsscript에는 next/script 사용하기

next/head에서 <script>를 직접 만드는 대신 component에서 next/script를 사용하는 것을 권장합니다.

We recommend using next/script in your component instead of manually creating a <script> in next/head.

No html or body tagshtml, body tag 사용 불가

<Head>로 <html>이나 <body> tag에 attribute를 설정할 수 없습니다. 그렇게 하면 next-head-count is missing error가 발생합니다. next/head는 HTML <head> tag 안의 tag만 처리할 수 있습니다.

You cannot use <Head> to set attributes on <html> or <body> tags. This will result in an next-head-count is missing error. next/head can only handle tags inside the HTML <head> tag.
