generateImageMetadatagenerateImageMetadata

generateImageMetadata를 사용하면 하나의 이미지를 여러 버전으로 생성하거나, 하나의 route segment에 대해 여러 이미지를 반환할 수 있습니다. icon처럼 metadata 값을 hard-coding하지 않으려는 경우에 유용합니다.

You can use generateImageMetadata to generate different versions of one image or return multiple images for one route segment. This is useful for when you want to avoid hard-coding metadata values, such as for icons.

Parameters

generateImageMetadata 함수는 다음 parameter를 받습니다:

generateImageMetadata function accepts the following parameters:

params (optional)

root segment부터 generateImageMetadata가 호출되는 segment까지의 dynamic route parameters object를 담은 object입니다.

An object containing the dynamic route parameters object from the root segment down to the segment generateImageMetadata is called from.

TSJSicon.tsx
export function generateImageMetadata({
  params,
}: {
  params: { slug: string }
}) {
  // ...
}
export function generateImageMetadata({ params }) {
  // ...
}

Returns

generateImageMetadata 함수는 alt, size 같은 이미지 metadata를 담은 object의 array를 반환해야 합니다. 또한 각 항목에는 반드시 id 값이 포함되어야 하며, 이 값은 이미지 생성 함수의 props에 promise로 전달됩니다.

The generateImageMetadata function should return an array of objects containing the image's metadata such as alt and size. In addition, each item must include an id value which will be passed as a promise to the props of the image generating function.

import { ImageResponse } from 'next/og'

export function generateImageMetadata() {
  return [
    {
      contentType: 'image/png',
      size: { width: 48, height: 48 },
      id: 'small',
    },
    {
      contentType: 'image/png',
      size: { width: 72, height: 72 },
      id: 'medium',
    },
  ]
}

export default async function Icon({ id }: { id: Promise<string | number> }) {

}

Image generation function props이미지 생성 함수의 props

generateImageMetadata를 사용할 때, default export된 이미지 생성 함수는 다음 props를 받습니다:

When using generateImageMetadata, the default export image generation function receives the following props:

id

generateImageMetadata가 반환한 항목 중 하나의 id 값으로 resolve되는 promise입니다. id는 generateImageMetadata가 반환한 값에 따라 string 또는 number가 됩니다.

A promise that resolves to the id value from one of the items returned by generateImageMetadata. The id will be a string or number depending on what was returned from generateImageMetadata.

TSJSicon.tsx
export default async function Icon({ id }: { id: Promise<string | number> }) {
  const iconId = await id
  // Use iconId to generate the image
}
export default async function Icon({ id }) {
  const iconId = await id
  // Use iconId to generate the image
}

params (optional)

root segment부터 이미지가 함께 위치한(colocated) segment까지의 dynamic route parameters를 담은 object로 resolve되는 promise입니다.

A promise that resolves to an object containing the dynamic route parameters from the root segment down to the segment the image is colocated in.

TSJSicon.tsx
export default async function Icon({
  params,
}: {
  params: Promise<{ slug: string }>
}) {
  const { slug } = await params
  // Use slug to generate the image
}
export default async function Icon({ params }) {
  const { slug } = await params
  // Use slug to generate the image
}

Examples예제

Using external data외부 데이터 사용하기

이 예제는 params object와 외부 데이터를 사용해 하나의 route segment에 대해 여러 Open Graph 이미지를 생성합니다.

This example uses the params object and external data to generate multiple Open Graph images for a route segment.

TSJSapp/products/[id]/opengraph-image.tsx
import { ImageResponse } from 'next/og'
import { getCaptionForImage, getOGImages } from '@/app/utils/images'

export async function generateImageMetadata({
  params,
}: {
  params: { id: string }
}) {
  const images = await getOGImages(params.id)

  return images.map((image, idx) => ({
    id: idx,
    size: { width: 1200, height: 600 },
    alt: image.text,
    contentType: 'image/png',
  }))
}

export default async function Image({
  params,
  id,
}: {
  params: Promise<{ id: string }>
  id: Promise<number>
}) {
  const productId = (await params).id
  const imageId = await id
  const text = await getCaptionForImage(productId, imageId)

  return new ImageResponse(
    (
      <div
        style={
          {
            // ...
          }
        }
      >
        {text}
      </div>
    )
  )
}
