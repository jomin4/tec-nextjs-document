robots.txtrobots.txt

app directory의 root에 Robots Exclusion Standard에 맞는 robots.txt 파일을 추가하거나 생성해서, 검색 엔진 crawler에게 사이트에서 접근할 수 있는 URL을 알려 주세요.

Add or generate a robots.txt file that matches the Robots Exclusion Standard in the root of app directory to tell search engine crawlers which URLs they can access on your site.

Static robots.txt

>_app/robots.txt
User-Agent: *
Allow: /
Disallow: /private/

Sitemap: https://acme.com/sitemap.xml

Generate a Robots fileRobots 파일 생성하기

Robots 객체를 반환하는 robots.js 또는 robots.ts 파일을 추가하세요.

Add a robots.js or robots.ts file that returns a Robots object.

Good to know

robots.js는 특수한 Route Handler로, Request-time API나 dynamic config option을 사용하지 않는 한 기본적으로 cache됩니다.

robots.js is a special Route Handler that is cached by default unless it uses a Request-time API or dynamic config option.

TSJSapp/robots.ts
import type { MetadataRoute } from 'next'

export default function robots(): MetadataRoute.Robots {
  return {
    rules: {
      userAgent: '*',
      allow: '/',
      disallow: '/private/',
    },
    sitemap: 'https://acme.com/sitemap.xml',
  }
}
export default function robots() {
  return {
    rules: {
      userAgent: '*',
      allow: '/',
      disallow: '/private/',
    },
    sitemap: 'https://acme.com/sitemap.xml',
  }
}

출력:

Output:

User-Agent: *
Allow: /
Disallow: /private/

Sitemap: https://acme.com/sitemap.xml

Customizing specific user agents특정 user agent 맞춤 설정하기

rules property에 user agent 배열을 전달하면 개별 검색 엔진 bot이 사이트를 crawl하는 방식을 맞춤 설정할 수 있습니다. 예를 들면 다음과 같습니다:

You can customize how individual search engine bots crawl your site by passing an array of user agents to the rules property. For example:

TSJSapp/robots.ts
import type { MetadataRoute } from 'next'

export default function robots(): MetadataRoute.Robots {
  return {
    rules: [
      {
        userAgent: 'Googlebot',
        allow: ['/'],
        disallow: '/private/',
      },
      {
        userAgent: ['Applebot', 'Bingbot'],
        disallow: ['/'],
      },
    ],
    sitemap: 'https://acme.com/sitemap.xml',
  }
}
export default function robots() {
  return {
    rules: [
      {
        userAgent: 'Googlebot',
        allow: ['/'],
        disallow: ['/private/'],
      },
      {
        userAgent: ['Applebot', 'Bingbot'],
        disallow: ['/'],
      },
    ],
    sitemap: 'https://acme.com/sitemap.xml',
  }
}

출력:

Output:

User-Agent: Googlebot
Allow: /
Disallow: /private/

User-Agent: Applebot
Disallow: /

User-Agent: Bingbot
Disallow: /

Sitemap: https://acme.com/sitemap.xml

Non-standard directives비표준 directive

일부 검색 엔진은 Request-Rate(Seznam)나 Clean-param(Yandex)처럼 Robots Exclusion Standard에 속하지 않는 directive를 지원합니다. 이런 directive는 rule의 other field로 전달하세요. key는 대소문자가 그대로 유지되고, 배열 값은 항목마다 한 줄씩 출력되며, 해당 rule의 User-Agent block 범위에 속합니다.

Some search engines support directives that aren't part of the Robots Exclusion Standard, such as Request-Rate (Seznam) or Clean-param (Yandex). Pass these through the other field on a rule. Keys preserve their casing and array values emit one line per entry, scoped to the rule's User-Agent block.

TSJSapp/robots.ts
import type { MetadataRoute } from 'next'

export default function robots(): MetadataRoute.Robots {
  return {
    rules: [
      { userAgent: '*', allow: '/' },
      {
        userAgent: 'SeznamBot',
        allow: '/',
        other: {
          'Request-Rate': '10/1m',
        },
      },
    ],
  }
}
export default function robots() {
  return {
    rules: [
      { userAgent: '*', allow: '/' },
      {
        userAgent: 'SeznamBot',
        allow: '/',
        other: {
          'Request-Rate': '10/1m',
        },
      },
    ],
  }
}

출력:

Output:

User-Agent: *
Allow: /

User-Agent: SeznamBot
Allow: /
Request-Rate: 10/1m
Good to know

other의 값은 그대로(verbatim) 전달됩니다. Next.js는 directive 이름이나 값을 검증하지 않으므로, 정확한 문법은 대상 검색 엔진의 문서를 참고하세요.

Values in other are passed through verbatim. Next.js does not validate directive names or values, so refer to the target search engine's documentation for the exact syntax.

Robots objectRobots 객체

type Robots = {
  rules:
    | {
        userAgent?: string | string[]
        allow?: string | string[]
        disallow?: string | string[]
        crawlDelay?: number
        other?: Record<string, string | number | Array<string | number>>
      }
    | Array<{
        userAgent: string | string[]
        allow?: string | string[]
        disallow?: string | string[]
        crawlDelay?: number
        other?: Record<string, string | number | Array<string | number>>
      }>
  sitemap?: string | string[]
  host?: string
}
