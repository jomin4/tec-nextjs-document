DirectivesDirective

Directive는 compiler와 bundler에게 주변 코드를 어떻게 처리할지 알려 주는 문자열 리터럴입니다. directive 자체는 평범한 문자열처럼 보이지만, Next.js와 React는 이를 자신이 적용되는 코드를 변환하라는 지시로 읽습니다. directive는 client entry point나 Server Function을 만들거나, 함수 또는 component의 출력을 cache할 수 있습니다.

Directives are string literals that tell the compiler and bundler how to treat the code around them. On their own, directives look like plain strings, but Next.js and React read them as instructions that transform the code they cover. A directive can create a client entry point or a Server Function, or cache a function's or component's output.

Directive정의한 곳효과
'use client'ReactServer Component에서 client entry point를 만듭니다
'use server'React서버 측 함수를 Server Function으로 노출합니다
'use cache'Next.js코드의 입력을 기준으로 출력을 cache하고 재사용합니다
DirectiveDefined byEffect
'use client'ReactCreates a client entry point from Server Components
'use server'ReactExposes server-side functions as Server Functions
'use cache'Next.jsCaches and reuses output based on the code's inputs

'use cache' directive에는 'use cache: remote'와 'use cache: private' 변형도 있습니다. cache된 항목이 저장되는 위치를 제어하려면 커스텀 cache handler를 설정하세요.

The 'use cache' directive also has 'use cache: remote' and 'use cache: private' variants. Configure custom cache handlers to control where cached entries are stored.

Good to know

Next.js는 development와 production 모두에서 compile 중에 directive를 적용합니다.

error overlay, indicator, stack trace는 생성된 출력이 아니라 여러분의 소스 파일과 줄을 가리킵니다.

Next.js applies directives during compilation in both development and production.

The error overlay, indicators, and stack traces point to your source file and line rather than the generated output.

Where to place a directiveDirective를 둘 위치

'use client' directive는 파일 맨 위, 모든 import보다 앞에 와야 합니다. 이 directive는 모듈 전체에 적용되며, 모듈이 bundle되어 브라우저로 전송되기 때문에 파일 전체 범위의 boundary를 정의합니다. 'use client'는 inline으로 사용할 수 없습니다.

The 'use client' directive must appear at the top of a file, before any imports. It applies to the entire module and defines a file-wide boundary because the module is bundled and shipped to the browser. You cannot use 'use client' inline.

'use server'나 'use cache'를 파일 맨 위에 두면 모든 export에 directive가 적용됩니다. 둘 중 하나를 함수 맨 위에 두면 해당 함수에만 적용됩니다.

Place 'use server' or 'use cache' at the top of a file to apply the directive to every export. Place either directive at the top of a function to apply it only to that function.

TSJSapp/data.ts
// File-level: applies to every export
'use cache'

export async function getUser(id: string) {
  return { id }
}
// File-level: applies to every export
'use cache'

export async function getUser(id) {
  return { id }
}
TSJSapp/user.tsx
// Function-level: applies to this function only
export async function User() {
  'use cache'
  return <p>User</p>
}
// Function-level: applies to this function only
export async function User() {
  'use cache'
  return <p>User</p>
}

'use server'와 'use cache'는 'use client' 모듈이 아니라 서버 모듈에서 선언하세요.

Declare 'use server' and 'use cache' in server modules, not in a 'use client' module.

'use server'나 'use cache' 함수를 Client Component로 import하려면 서버 모듈의 맨 위에 directive를 두세요. Client Component는 서버에서 함수를 호출하는 reference를 받습니다.

To import a 'use server' or 'use cache' function into a Client Component, place the directive at the top of the server module. The Client Component receives a reference that invokes the function on the server.

directive를 해당 함수나 component에만 적용해야 할 때는 함수 안에 두세요. 여러 export 함수에 적용해야 할 때는 반복하지 말고 파일 맨 위에 두세요.

Place the directive inside a function when it should apply only to that function or component. When it should apply to several exported functions, place it at the top of the file instead of repeating it.

파일 수준 'use server' 또는 'use cache' directive가 적용되는 모든 export 함수는 async여야 합니다.

Every exported function covered by a file-level 'use server' or 'use cache' directive must be async.

What each directive requires각 directive의 요구 사항

directive는 자신이 적용되는 코드에 규칙을 부과합니다:

A directive imposes rules on the code it covers:

  • 'use client' 는 export를 server와 client 사이의 boundary로 표시합니다. boundary를 넘는 Client Component props는 serializable해야 합니다. event handler 같은 일반 함수는 넘을 수 없지만, Server Function은 reference로 넘을 수 있습니다.
  • 'use server' 는 자신이 적용되는 함수를 Server Function으로 표시합니다. Server Function은 async여야 합니다. Client Component에서 호출되면 인자와 반환값이 네트워크를 통해 serialize됩니다. Client Component는 함수의 코드가 아니라, 서버에서 함수를 호출하는 reference를 받습니다.
  • 'use cache' 는 자신이 적용되는 함수나 component의 출력을 입력 기준으로 cache합니다. cache되는 함수와 component는 async여야 합니다. 인자와 반환값은 serializable해야 하며, 예외적으로 cache된 코드가 내용을 검사하지 않고 그대로 전달하기만 하는 non-serializable 값은 허용됩니다. cache된 코드는 cookies(), headers(), searchParams 같은 request-time API를 직접 읽을 수 없습니다.
  • 'use client' marks its exports as the boundary between server and client. Client Component props that cross the boundary must be serializable. Ordinary functions, such as event handlers, cannot cross, but Server Functions can cross as references.
  • 'use server' marks the functions it covers as Server Functions. Server Functions must be async. When invoked from a Client Component, their arguments and return values are serialized across the network. The Client Component receives a reference that invokes the function on the server, not the function's code.
  • 'use cache' caches the output of the functions or components it covers based on their inputs. Cached functions and components must be async. Their arguments and return values must be serializable, except for non-serializable values that the cached code passes through without inspecting. Cached code cannot read request-time APIs like cookies(), headers(), or searchParams directly.

page나 layout 파일 맨 위에 'use cache'가 있으면 generateMetadata, generateStaticParams 같은 export 함수는 async여야 합니다.

With 'use cache' at the top of a page or layout file, exported functions such as generateMetadata and generateStaticParams must be async.

Placement decides what you cache위치가 cache 대상을 결정합니다

'use cache'에서는 위치가 cache 항목의 범위를 결정합니다. page 맨 위의 directive는 page의 출력과 page가 import하는 component를 cache합니다. 같은 directive를 데이터 함수 안에 두면 그 함수의 결과만 cache합니다. 비용이 큰 작업을 하나의 데이터 request가 수행한다면, page 대신 그 함수를 cache하세요.

With 'use cache', placement determines the scope of a cache entry. A directive at the top of a page caches the page's output and the components it imports. The same directive inside a data function caches only that function's result. When one data request performs the expensive work, cache that function instead of the page.

'use cache: remote'를 사용하면 remote cache handler가 항목을 저장합니다. 항목이 클수록 스토리지와 네트워크 비용이 늘어날 수 있습니다.

With 'use cache: remote', a remote cache handler stores entries. Larger entries can increase storage and network costs.
