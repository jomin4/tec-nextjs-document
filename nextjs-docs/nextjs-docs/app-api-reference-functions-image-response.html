ImageResponseImageResponse

ImageResponse constructor를 사용하면 JSX와 CSS로 dynamic 이미지를 생성할 수 있습니다. Open Graph 이미지, Twitter card 같은 social media 이미지를 생성할 때 유용합니다.

The ImageResponse constructor allows you to generate dynamic images using JSX and CSS. This is useful for generating social media images such as Open Graph images, Twitter cards, and more.

Reference

Parameters

ImageResponse에서 사용할 수 있는 parameter는 다음과 같습니다:

The following parameters are available for ImageResponse:

import { ImageResponse } from 'next/og'

new ImageResponse(
  element: ReactElement,
  options: {
    width?: number = 1200
    height?: number = 630
    emoji?: 'twemoji' | 'blobmoji' | 'noto' | 'openmoji' = 'twemoji',
    fonts?: {
      name: string,
      data: ArrayBuffer,
      weight: number,
      style: 'normal' | 'italic'
    }[]
    debug?: boolean = false

    // Options that will be passed to the HTTP response
    status?: number = 200
    statusText?: string
    headers?: Record<string, string>
  },
)

예시는 Vercel OG Playground에서 볼 수 있습니다.

Examples are available in the Vercel OG Playground.

Supported HTML and CSS features지원되는 HTML 및 CSS 기능

ImageResponse는 flexbox와 absolute positioning, custom font, text wrapping, 가운데 정렬, 중첩 이미지 등 일반적인 CSS property를 지원합니다.

ImageResponse supports common CSS properties including flexbox and absolute positioning, custom fonts, text wrapping, centering, and nested images.

지원되는 HTML 및 CSS 기능 목록은 Satori 문서를 참고하세요.

Please refer to Satori’s documentation for a list of supported HTML and CSS features.

Behavior동작 방식

  • ImageResponse는 @vercel/og, Satori, Resvg를 사용해 HTML과 CSS를 PNG로 변환합니다.
  • flexbox와 CSS property의 일부만 지원됩니다. 고급 layout(예: display: grid)은 동작하지 않습니다.
  • 최대 bundle 크기는 500KB입니다. bundle 크기에는 JSX, CSS, font, 이미지 및 기타 모든 asset이 포함됩니다. 한도를 넘는다면 asset 크기를 줄이거나 runtime에 fetch하는 방법을 고려하세요.
  • ttf, otf, woff font format만 지원됩니다. font parsing 속도를 최대화하려면 woff보다 ttf나 otf를 사용하는 것이 좋습니다.
  • ImageResponse uses @vercel/og, Satori, and Resvg to convert HTML and CSS into PNG.
  • Only flexbox and a subset of CSS properties are supported. Advanced layouts (e.g. display: grid) will not work.
  • Maximum bundle size of 500KB. The bundle size includes your JSX, CSS, fonts, images, and any other assets. If you exceed the limit, consider reducing the size of any assets or fetching at runtime.
  • Only ttf, otf, and woff font formats are supported. To maximize the font parsing speed, ttf or otf are preferred over woff.

Examples예시

Route Handlers

ImageResponse는 Route Handler에서 request 시점에 dynamic하게 이미지를 생성하는 데 사용할 수 있습니다.

ImageResponse can be used in Route Handlers to generate images dynamically at request time.

JSapp/api/route.js
import { ImageResponse } from 'next/og'

export async function GET() {
  try {
    return new ImageResponse(
      (
        <div
          style={{
            height: '100%',
            width: '100%',
            display: 'flex',
            flexDirection: 'column',
            alignItems: 'center',
            justifyContent: 'center',
            backgroundColor: 'white',
            padding: '40px',
          }}
        >
          <div
            style={{
              fontSize: 60,
              fontWeight: 'bold',
              color: 'black',
              textAlign: 'center',
            }}
          >
            Welcome to My Site
          </div>
          <div
            style={{
              fontSize: 30,
              color: '#666',
              marginTop: '20px',
            }}
          >
            Generated with Next.js ImageResponse
          </div>
        </div>
      ),
      {
        width: 1200,
        height: 630,
      }
    )
  } catch (e) {
    console.log(`${e.message}`)
    return new Response(`Failed to generate the image`, {
      status: 500,
    })
  }
}

File-based Metadata파일 기반 Metadata

opengraph-image.tsx 파일에서 ImageResponse를 사용해 build 시점 또는 request 시점에 dynamic하게 Open Graph 이미지를 생성할 수 있습니다.

You can use ImageResponse in a opengraph-image.tsx file to generate Open Graph images at build time or dynamically at request time.

TSapp/opengraph-image.tsx
import { ImageResponse } from 'next/og'

// Image metadata
export const alt = 'My site'
export const size = {
  width: 1200,
  height: 630,
}

export const contentType = 'image/png'

// Image generation
export default async function Image() {
  return new ImageResponse(
    (
      // ImageResponse JSX element
      <div
        style={{
          fontSize: 128,
          background: 'white',
          width: '100%',
          height: '100%',
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
        }}
      >
        My site
      </div>
    ),
    // ImageResponse options
    {
      // For convenience, we can re-use the exported opengraph-image
      // size config to also set the ImageResponse's width and height.
      ...size,
    }
  )
}

Custom fontsCustom font

option에 fonts 배열을 제공하면 ImageResponse에서 custom font를 사용할 수 있습니다. font는 request 데이터에 의존하지 않으므로 module scope에서 한 번만 읽으세요. Predictable values를 참고하세요.

You can use custom fonts in your ImageResponse by providing a fonts array in the options. The font doesn't depend on request data, so read it once at module scope. See Predictable values.

TSapp/opengraph-image.tsx
import { ImageResponse } from 'next/og'
import { readFile } from 'node:fs/promises'
import { join } from 'node:path'

// Image metadata
export const alt = 'My site'
export const size = {
  width: 1200,
  height: 630,
}

export const contentType = 'image/png'

const interSemiBold = await readFile(
  join(process.cwd(), 'assets/Inter-SemiBold.ttf')
)

// Image generation
export default async function Image() {
  return new ImageResponse(
    (
      // ...
    ),
    // ImageResponse options
    {
      // For convenience, we can re-use the exported opengraph-image
      // size config to also set the ImageResponse's width and height.
      ...size,
      fonts: [
        {
          name: 'Inter',
          data: interSemiBold,
          style: 'normal',
          weight: 400,
        },
      ],
    }
  )
}
